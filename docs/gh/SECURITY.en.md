## Supported Versions

> **This project is currently in active development and has no stable release yet.** All versions
> should be considered experimental and may contain security issues.

| Version | Supported      |
| ------- | -------------- |
| 0.x.x   | ⚠️ Best-effort |

## Reporting a Vulnerability

To report a security vulnerability, please send an email to:

**Email:** `Woyerpa@outlook.com`

### What to expect

1. We will acknowledge your report within **72 hours**.
2. We'll keep you updated on our progress.
3. If the vulnerability is confirmed, we'll release a fix as soon as possible.

### Scope

We consider security issues in:

- Code execution vulnerabilities
- Memory safety issues
- Input validation flaws
- Dependency vulnerabilities

### Out of scope

- Social engineering attacks
- Physical security
- Issues in third-party tools we use
