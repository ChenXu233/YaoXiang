# Accepted Design Proposals

> Status: Active. Maintainer: YaoXiang Language Design Team. Last Updated: 2026-02-12

Design proposals that have been reviewed and entered the implementation phase.

This directory contains RFCs whose status is "Accepted". **The authoritative complete list is the
[RFC Tracking Table](../TRACKING.md)** — that file is generated automatically in CI by
`scripts/rfc/check_tracking.py` based on each RFC's location; for a readable index grouped by
status, see the [RFC Index](../index.md).

The files under this directory are the full set of accepted proposals; there is no need to maintain
a duplicate list here.
