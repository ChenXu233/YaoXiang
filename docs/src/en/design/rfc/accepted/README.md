# Accepted Design Proposals

> Status: Accepted Maintainers: YaoXiang Language Design Team Last updated: 2026-02-12

Design proposals that have passed review and entered the implementation phase.

This directory contains RFCs whose status is "Accepted". **The complete list is maintained in the
[RFC Tracking Table](../TRACKING.md)** — that file is auto-generated by
`scripts/rfc/check_tracking.py` in CI based on the directory each RFC lives in; a readable index
grouped by status is available at the [RFC Index](../index.md).

The files in this directory are the complete set of accepted proposals; there is no need to maintain
a duplicate list here.
