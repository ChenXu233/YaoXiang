# Error Code Reference

This page is generated by `scripts/docs/gen-error-code-docs.py` from the `define_codes!` registry in
`src/util/diagnostic/codes/` and `locales/zh.json`; do not edit by hand. To change wording, edit
`locales/*.json`; to change the code list, edit `define_codes!`; then rerun
`python scripts/docs/gen-error-code-docs.py`.

Every diagnostic in YaoXiang carries a stable code number (such as `E1001`), which makes it easy to
search, reference in issues, and filter by code in CI. The user-visible text of a diagnostic (title
/ template / help) is provided by `locales/*.json`, and can be viewed in the terminal with
`yx explain <code>`.

## Code Numbering System

A code number consists of a prefix (family) and a four-digit serial; the family corresponds to a
compiler phase:

| Family Prefix | Category           | Meaning                                                        | Registered Codes |
| ------------- | ------------------ | -------------------------------------------------------------- | ---------------- |
| `E0xxx`       | `Lexer` / `Parser` | Lexical and syntactic analysis errors                          | 11               |
| `E1xxx`       | `TypeCheck`        | Type check errors                                              | 57               |
| `E2xxx`       | `Semantic`         | Semantic analysis errors                                       | 23               |
| `E3xxx`       | `Codegen`          | Code generation errors (including IR-layer consistency checks) | 13               |
| `E4xxx`       | `Generic`          | Generics, traits, and constant evaluation errors               | 14               |
| `E5xxx`       | `Module`           | Module and import errors                                       | 8                |
| `E6xxx`       | `Runtime`          | Runtime errors (VM and std native functions)                   | 7                |
| `E7xxx`       | `Io`               | I/O and system errors                                          | 4                |
| `E8xxx`       | `Internal`         | Internal compiler errors (defects in the compiler itself)      | 3                |
| `W1xxx`       | `Warning`          | Warnings (do not block compilation)                            | 10               |

The `E3xxx` family was previously not listed in any documentation and has now been merged into this
page; its codes are produced during IR generation and entry-point checking.

- `define_codes!` registry: **150** entries (140 `E` codes + 10 `W` codes).

- **155** diagnostic codes in total.

## Marker Legend

- **span-exempt**: when `true`, the diagnostic is allowed to have no source location (e.g., internal
  errors, runtime diagnostics). Non-exempt codes are rejected when there is neither an explicit
  `.at()` nor a walk context (panic in debug builds, fall through to `E8001` in release).
- **Emission Sites ⚠ Not yet emitted**: the code is reserved in the registry, but there is no call
  site in non-test code at present, so users cannot trigger it. Code numbers are not recycled, to
  prevent diagnostics in old artifacts from being reused with a different meaning.
- **std-layer runtime codes**: see the previous section; not counted in the registry statistics.

use yaoxiang::util::diagnostic::{ErrorCodeDefinition, I18nRegistry};

let i18n = I18nRegistry::default();

}
