# Warning Codes

This page is generated by `scripts/docs/gen-error-code-docs.py` from the `define_codes!` registry in
`src/util/diagnostic/codes/` and `locales/zh.json`. Please do not edit it manually. To change
wording, edit `locales/*.json`; to change the code table, edit `define_codes!`, then re-run
`python scripts/docs/gen-error-code-docs.py`.

Warning codes start with `W` and do not prevent compilation, but indicate potential issues in the
code. The current registry contains **10** warning codes. For the complete index, see the
[Error Codes Index](../error-code/index.md).

## Configuration

You can configure dead-code warnings via `yaoxiang.toml`:

```toml
[lint]
# Dead code warning level: off | warn | deny
dead-code = "warn"
```

- `off`: disable warnings
- `warn`: show warnings (default)
- `deny`: treat warnings as errors and prevent compilation

## Warning Levels

| `deny` | Treat warnings as errors and prevent compilation |

## Differences from Error Codes

- **Errors (`E` prefix)**: Prevent compilation, must be fixed.
- **Warnings (`W` prefix)**: Indicate potential issues, optionally fixable.

## Criteria for Dead-Code Warnings

`W1001`–`W1005` report **unused private** (non-`pub`) functions / types / variables / methods. `pub`
declarations are external interfaces, and the compiler has no way of knowing whether external
consumers exist, so these warnings are never triggered (decision B of #321). If you see an "unused"
warning, simply remove the corresponding `pub` to eliminate it; conversely, retain `pub` for
declarations that need to be called externally.
