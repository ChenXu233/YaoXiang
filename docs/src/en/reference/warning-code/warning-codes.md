# Warning Codes

This page is generated by `scripts/docs/gen-error-code-docs.py` from the `define_codes!` registry in
`src/util/diagnostic/codes/` and `locales/zh.json`. Do not edit manually. To change text, modify
`locales/*.json`; to change the code table, modify `define_codes!`, then re-run
`python scripts/docs/gen-error-code-docs.py`.

Warning codes start with `W` and do not prevent compilation, but indicate potential issues in the
code. The current registry contains **10** warning codes. See the complete index at the
[Error Code Home](../error-code/index.md).

## Configuration

The behavior of dead code warnings can be configured via `yaoxiang.toml`:

```toml
[lint]
# Dead code warning level: off | warn | deny
dead-code = "warn"
```

- `off`: Disable the warning
- `warn`: Show the warning (default)
- `deny`: Treat the warning as an error and prevent compilation

## Warning Levels

| Level  | Effect                                                |
| ------ | ----------------------------------------------------- |
| `off`  | Completely disable this category of warnings          |
| `warn` | Show the warning but continue compilation (default)   |
| `deny` | Treat the warning as an error and prevent compilation |

## Difference from Error Codes

- **Errors (`E` prefix)**: Prevent compilation and must be fixed.
- **Warnings (`W` prefix)**: Indicate potential issues and can be optionally fixed.

## Dead Code Warning Criteria

`W1001`–`W1005` report **unused private** (non-`pub`) functions / types / variables / methods. `pub`
declarations are part of the public interface, and the compiler has no way of knowing whether there
are external consumers, so these warnings are never triggered for them (decision B of #321). If you
see an "unused" warning, simply remove the corresponding `pub` to silence it; conversely, keep `pub`
for declarations that need to be called externally.
