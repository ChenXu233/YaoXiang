# Warning Codes

This page is generated by `scripts/docs/gen-error-code-docs.py` from the `define_codes!` registry in
`src/util/diagnostic/codes/` and `locales/en.json`; do not edit it manually. To change the wording,
edit `locales/*.json`; to change the code table, edit `define_codes!`, then rerun
`python scripts/docs/gen-error-code-docs.py`.

Warning codes start with `W` and indicate potential problems in the code; their default emission
level is `warn`, which does not prevent compilation. Exception: `W1090` has an emission level of
`error` (the same code was promoted to E by the user ruling of 2026-10-13; see its entry for
details); when triggered, it counts toward error_count, changes the exit code, and prevents
compilation. The current registry contains **12** warning codes; see the
[error code index](../error-code/index.md) for the complete index.

## Configuration

You can configure dead-code warning behavior through `yaoxiang.toml`:

```toml
[lint]
# Dead code warning level: off | warn | deny
dead-code = "warn"
```

- `off`: Disable the warning
- `warn`: Display the warning (default)
- `deny`: Treat the warning as an error and block compilation

### W1006: Local module shadows dependency package

- **Category**: `Warning`
- **span exemption**: No
- **Template**: `Local module '{module}' shadows dependency package '{dependency}'`
- **Help**: Local module resolution has the highest priority (RFC-014): './src/{module}' overrides
  the dependency package '{dependency}' in .yaoxiang/vendor/. If the shadowing is unintended, rename
  the local module; use --deny-shadowing to promote it to an error.
- **Emission site**: `src/driver/arms.rs:653`, `src/util/diagnostic/command.rs:78`

### W1007: Module import cycle

- **Category**: `Warning`
- **span exemption**: No
- **Template**:
  `Module import cycle {cycle}: initialization order within the cycle cannot be determined; ordering within the cycle follows only a deterministic convention based on lexicographic path order (not a semantic guarantee)`
- **Help**: Initialization order is determined by the topological order of use dependencies.
  Ordering within a cycle follows only the deterministic convention of "lexicographic order of paths
  within the cycle" and is not a semantic guarantee. Breaking the cycle (moving one use declaration
  in the cycle out of the cycle, or changing it to deferred evaluation inside a function body) makes
  the initialization order determinable. Division of responsibility with E3019: E3019 detects
  initialization cycles between top-level bindings within a unit, whereas this code detects import
  cycles between modules.
- **Emission site**: `src/driver/arms.rs:1752`

- **Help**: This is a defect in the compiler's internal stage contract, not an error in your

  the field name and file path as an issue, and attach a minimal reproducer. This code belongs to

  defect actually occurs.
- **Emission site**: `src/driver/obligations.rs:105`, `src/driver/obligations.rs:535`

## Warning Levels

| Level  | Effect                                                 |
| ------ | ------------------------------------------------------ |
| `off`  | Completely disable warnings of this category           |

| `deny` | Treat the warning as an error and block compilation    |

## Differences from Error Codes

- **Error (`E` prefix)**: Blocks compilation and must be fixed.
- **Warning (`W` prefix)**: Indicates a potential problem; the default emission level is `warn`, and
  fixing it is optional. Exception: `W1090` has an emission level of `error`; when triggered, it
  counts toward error_count, changes the exit code, blocks compilation, and must be fixed (see its
  entry for details).

## Dead-Code Warning Criteria

`W1001`–`W1005` report **unused private** (non-`pub`) functions / types / variables / methods. A
`pub` declaration is an external interface, and the compiler cannot know whether an external
consumer exists, so it never emits these warnings (#321, finalized decision B). If you see an
"unused" warning, remove the corresponding `pub` to eliminate it; conversely, retain `pub` for
declarations that need to be called externally.
