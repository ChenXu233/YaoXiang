# Warning Codes

This page is generated by `scripts/docs/gen-error-code-docs.py` from the `define_codes!` registry in
`src/util/diagnostic/codes/` and `locales/zh.json`. Do not edit it manually. To change the wording,
edit `locales/*.json`; to change the code table, edit `define_codes!`, then rerun
`python scripts/docs/gen-error-code-docs.py`.

Warning codes start with `W` and do not block compilation, but indicate possible issues in the code.
The current registry has **8** warning codes; see the [error code index](../error-code/index.md) for
the full listing.

## Configuration

The behavior of dead code warnings can be configured via `yaoxiang.toml`:

```toml
[lint]
# Dead code warning level: off | warn | deny
dead-code = "warn"
```

- `off`: Disable warnings
- `warn`: Show warnings (default)
- `deny`: Treat warnings as errors, blocking compilation

## Warning Levels

| Level  | Effect                                           |
| ------ | ------------------------------------------------ |
| `off`  | Completely disable this category of warnings     |
| `warn` | Show warnings but continue compilation (default) |
| `deny` | Treat warnings as errors, blocking compilation   |

## Difference from Error Codes

- **Errors (`E` prefix)**: Block compilation, must be fixed.
- **Warnings (`W` prefix)**: Indicate potential issues, optional to fix.

## Dead Code Warning Judgment Criteria

`W1001`–`W1005` report **unused private** (non-`pub`) functions / types / variables / methods. `pub`
declarations are external interfaces, and the compiler has no way to know whether there are external
consumers, so these warnings are never triggered (decision B of #321). If you see an "unused"
warning, removing the corresponding `pub` will eliminate it; conversely, keep `pub` for declarations
that need to be called externally.
