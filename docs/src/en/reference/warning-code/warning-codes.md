# Warning Codes

This page is generated by `scripts/docs/gen-error-code-docs.py` from the `define_codes!` registry in
`src/util/diagnostic/codes/` and `locales/zh.json`. Please do not edit it manually. To change the
text, edit `locales/*.json`; to change the code table, edit `define_codes!`, and then re-run
`python scripts/docs/gen-error-code-docs.py`.

Warning codes start with `W` and do not prevent compilation, but indicate possible issues in the
code. The current registry contains **10** warning codes; for the complete index see the
[Error Codes Index](../error-code/index.md).

## Configuration

You can configure the behavior of dead code warnings via `yaoxiang.toml`:

```toml
[lint]
# Dead code warning level: off | warn | deny
dead-code = "warn"
```

- `off`: Disable the warning
- `warn`: Show the warning (default)
- `deny`: Treat the warning as an error and prevent compilation

| `deny` | Treat the warning as an error and prevent compilation |

## Difference from Error Codes

- **Error (`E` prefix)**: Prevents compilation; must be fixed.
- **Warning (`W` prefix)**: Indicates a potential issue; can be optionally fixed.

## Dead Code Warning Criteria

`W1001`–`W1005` report **unused private** (non-`pub`) functions / types / variables / methods. A
`pub` declaration is an external interface; the compiler has no way of knowing whether there are
external consumers, so these warnings are never triggered (#321, decision B). If you see an "unused"
warning, removing the corresponding `pub` will suppress it; conversely, for declarations that need
to be called externally, keep `pub`.
