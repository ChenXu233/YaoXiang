# Welcome to the YaoXiang Universe!

> "Wuji gives rise to Taiji. When Taiji moves, it generates Yang; when it rests, it generates Yin."
> — Zhou Dunyi, _Explanation of the Diagram of the Supreme Ultimacy_

This is the heart of the YaoXiang universe.

In Eastern philosophy, "Yao" (爻) is the basic symbol composing hexagrams, where the transformations
of Yin and Yang are fully contained. "Xiang" (象) is the external manifestation of the essence of
things; all phenomena in the universe follow discernible patterns.

**The YaoXiang programming language** is an attempt to integrate this ancient wisdom into the modern
type system.

## What is YaoXiang?

Imagine building with LEGO bricks:

| Concept       | LEGO          | YaoXiang             |
| ------------- | ------------- | -------------------- |
| Basic unit    | Brick         | **Type**             |
| Composition   | Connection    | **Function mapping** |
| Finished work | Airplane, car | **Program**          |

In the world of YaoXiang, **everything is a type**:

- Numbers are types, text is a type
- A type itself is also a type (meta type)
- A function is a bridge from one type to another

## Core Features

| Feature                  | YaoXiang                                  | Examples in Other Languages |
| ------------------------ | ----------------------------------------- | --------------------------- |
| Type system              | Dependent types + parametric polymorphism | TypeScript                  |
| Memory management        | Ownership model (no GC)                   | Rust                        |
| Asynchronous programming | Spawn model (seamless concurrency)        | async/await                 |
| Syntax style             | Python style                              | Python                      |

**Summary in one sentence**: As fluid as writing Python, as safe as Rust.

## Who is YaoXiang for?

- ✅ Explorers interested in programming language design
- ✅ Fans of functional programming
- ✅ Practitioners interested in type systems
- ✅ Developers who want to experience "seamless concurrency"
- ❌ Teams needing to immediately ship production projects (the language is still experimental)

> "The Tao that can be spoken is not the eternal Tao." — YaoXiang is still in an early exploration
> stage; every pioneer is shaping its future.
