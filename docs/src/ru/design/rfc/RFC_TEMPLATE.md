#### Правила управления обсуждениями

| Этап         | Действие                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------- |
| В обсуждении | Записать в приложение, оставить открытым                                                 |
| Решено       | Обновить решение, отметить статус, **обновить соответствующий контент в основной части** |
| Отклонено    | Отметить причину отклонения, сохранить запись для справки                                |

> **Важно**: После завершения обсуждения необходимо обновить соответствующий контент в основной
> части! Записи обсуждения можно сохранить как историческую справку.
