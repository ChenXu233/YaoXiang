## Жизненный цикл RFC

```
Черновик → На рассмотрении → Принято → Устаревший (заменён)
                       ↓
              Отклонено (не прошло)
```

### Описание статусов

| Статус              | Расположение      | Описание                                              |
| ------------------- | ----------------- | ----------------------------------------------------- |
| **Черновик**        | `rfc/draft/`      | Авторский проект, ожидает подачи на рассмотрение      |
| **На рассмотрении** | `rfc/review/`     | Открыто для обсуждения сообщества и получения отзывов |
| **Устаревший**      | `rfc/deprecated/` | Было принято, заменено новым дизайном                 |
| **Отклонено**       | `rfc/rejected/`   | Документация RFC, которая была отклонена              |

## Подача RFC

1. Прочитайте [RFC_TEMPLATE.md](RFC_TEMPLATE.md), чтобы ознакомиться с требованиями к формату
2. Обратитесь к [EXAMPLE_full_feature_proposal.md](EXAMPLE_full_feature_proposal.md) для изучения
   стиля написания
3. Создайте новый файл с именем `порядковый номер-описательное название.md`
4. Поместите файл в каталог `docs/src/design/rfc/draft/`
5. Обновите этот индексный файл, добавив новую запись RFC
6. Отправьте PR для прохождения процесса рассмотрения
