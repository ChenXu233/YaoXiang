## Жизненный цикл RFC

```
Черновик → На рассмотрении → Принят → Устарел (заменён)
                              ↓
                          Отклонён (не прошёл)
```

### Описание статусов

| Статус | Расположение | Описание |
|------|------|------|
| **Черновик** | `rfc/draft/` | Черновик автора, ожидает отправки на рассмотрение |
| **На рассмотрении** | `rfc/review/` | Открыто для обсуждения сообществом и получения обратной связи |
| **Устарел** | `rfc/deprecated/` | Ранее принят, заменён новым дизайном |
| **Отклонён** | `rfc/rejected/` | Документ RFC, который был отклонён |

## Подача RFC

1. Прочтите [RFC_TEMPLATE.md](RFC_TEMPLATE.md), чтобы узнать требования к формату
2. Обратитесь к [EXAMPLE_full_feature_proposal.md](EXAMPLE_full_feature_proposal.md), чтобы изучить стиль написания
3. Создайте новый файл с именем `номер-описательное-название.md`
4. Поместите файл в каталог `docs/src/design/rfc/draft/`
5. Обновите этот индексный файл, добавив запись о новом RFC
6. Отправьте PR для входа в процесс рассмотрения
