## Жизненный цикл RFC

```
Черновик → На рассмотрении → Принят → Устарел (заменён)
                              ↓
                           Отклонён (не прошёл)
```

### Описание статусов

| Статус              | Расположение  | Описание                                           |
| ------------------- | ------------- | -------------------------------------------------- |
| **Черновик**        | `rfc/draft/`  | Авторский черновик, ожидает подачи на рассмотрение |
| **На рассмотрении** | `rfc/review/` | Открытое обсуждение сообществом и обратная связь   |

| **Устарел** | `rfc/deprecated/` | Ранее был принят, заменён новым дизайном | | **Отклонён** |
`rfc/rejected/` | Документы отклонённых RFC |

## Подача RFC

1. Прочитайте [RFC_TEMPLATE.md](RFC_TEMPLATE.md), чтобы узнать требования к формату
2. Изучите [EXAMPLE_full_feature_proposal.md](EXAMPLE_full_feature_proposal.md) для понимания стиля
   написания
3. Создайте новый файл с именем `номер-описательный-заголовок.md`
4. Поместите файл в директорию `docs/src/design/rfc/draft/`
5. Обновите этот индексный файл, добавив новую запись RFC
6. Отправьте PR для входа в процесс рассмотрения
