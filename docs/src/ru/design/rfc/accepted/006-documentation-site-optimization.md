# RFC-006: Создание сайта документации

> **Справка**: См. [Шаблон RFC](../RFC_TEMPLATE.md) для ознакомления со спецификацией RFC.

## Резюме

Создать сайт документации YaoXiang, объединить разрозненные документы, обеспечить поддержку поиска,
навигации, многоязычности и переключения версий.

## Мотивация

### Зачем нужна эта функция?

В настоящее время документация разбросана по нескольким каталогам и отображается только через GitHub
Readme. Новым пользователям трудно найти нужную информацию, невозможно выполнить поиск, документация
на китайском и английском языках не синхронизирована.

### Текущие проблемы

```
docs/
├── README.md              # Главный указатель (ограниченное содержимое)
├── tutorial/              # Учебные пособия
├── guides/               # Руководства
├── architecture/          # Документация по архитектуре
├── design/               # Проектная документация
├── examples/             # Примеры
├── plans/                # Планы внедрения
├── implementation/       # Документация по реализации
├── maintenance/          # Документация по сопровождению
└── archived/             # Архив
```

Проблемы:

1. Нет единой точки входа, только GitHub Readme
2. Невозможно выполнить поиск
3. Нет переключения версий, пользователи могут читать устаревшую документацию
4. .obsidian попадает в систему контроля версий

│       ├── zh.ts

│

│   ├── index.md               # Главная страница (китайский)
│   ├── getting-started.md

│   ├── reference/

### Спецификация URL-путей (основное проектирование)

| Сценарий                        | Формат URL                  | Описание                            |
| ------------------------------- | --------------------------- | ----------------------------------- |
| Актуальная версия на китайском  | `/zh/getting-started/`      | Перенаправление на последнюю версию |
| Актуальная версия на английском | `/en/getting-started/`      | Перенаправление на последнюю версию |
| Указанная версия                | `/v0.5/zh/getting-started/` | Префикс номера версии               |
| Главная страница                | `/zh/` или `/en/`           | Языковая главная страница           |

**Дизайн переключения версий**:

```
Выпадающее меню переключения версий:
├── v0.6 (latest)
├── v0.5
├── v0.4
└── v0.3
```

**Спецификация путей версий** (ключевое решение, сложно изменить позже):

- Актуальная версия: `/zh/xxx/` → перенаправление на последнюю версию
- Указанная версия: `/v0.5/zh/xxx/` → фиксированная версия
- Переключение версий в навигации: переключение комбинации `/v0.5/` и `/zh/`

### Спецификация боковой панели

```typescript
// docs/.vitepress/sidebar/zh.ts
export default {
  '/zh/tutorial/': [
    {
      text: '教程',
      items: [
        { text: '快速开始', link: '/zh/getting-started' },
        { text: '基础', link: '/zh/tutorial/basics' },
      ],
    },
  ],
  '/zh/reference/': [
    {
      text: '参考',
      items: [{ text: '内置函数', link: '/zh/reference/builtins' }],
    },
  ],
};
```

### Интеграция CI/CD

```yaml
# .github/workflows/docs-deploy.yml
name: Deploy Docs

on:
  push:
    branches: [main]
    paths: ['docs/**', '!.obsidian/**']

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm ci
        working-directory: docs
      - run: npm run build
      - uses: actions/deploy-pages@v4
        with:
          build_dir: docs/.vitepress/dist
```

## Подробное проектирование

### Конфигурация навигации

```typescript
// docs/.vitepress/navbar.ts
export default [
  { text: '开始', link: '/zh/getting-started' },
  { text: '教程', link: '/zh/tutorial/' },
  { text: '参考', link: '/zh/reference/' },
  { text: '设计', link: '/zh/design/' },
  { text: 'GitHub', link: 'https://github.com/yaoxiang-lang/yaoxiang' },
];
```

### Конфигурация сайта

```typescript
// docs/.vitepress/config.mts
import { defineConfig } from 'vitepress';
import starlight from '@astrojs/starlight';

export default defineConfig({
  title: 'YaoXiang',
  description: '一门面向未来的编程语言',

  locales: {
    root: { label: '中文', lang: 'zh-CN', link: '/zh/' },
    en: { label: 'English', lang: 'en-US', link: '/en/' },
  },

  // 本地搜索
  plugins: [
    starlight({
      title: 'YaoXiang',
      localSearch: {},
    }),
  ],

  // 编辑链接
  editLink: {
    pattern: 'https://github.com/yaoxiang-lang/yaoxiang/edit/main/docs/:path',
  },
});
```

## Компромиссы

### Преимущества

- Профессиональный сайт документации повышает имидж проекта
- Пользователи быстро находят нужную информацию
- Локального поиска достаточно и он бесплатен
- Поддержка многоязычности для международного сообщества
- Переключение версий предотвращает чтение устаревшей документации

### Недостатки

- Затраты на сопровождение: необходимо поддерживать конфигурацию сайта
- Введение технологического стека: Node.js

## Альтернативы

| Вариант       | Почему не выбран                       |
| ------------- | -------------------------------------- |
| GitHub Wiki   | Плохой поиск, низкая кастомизируемость |
| Только README | Нет поиска, нет навигации              |
| Docusaurus    | Более тяжёлый, медленный запуск        |
