# RFC-006: Создание сайта документации

> **参考**: 查看 [RFC 模板](../RFC_TEMPLATE.md) 了解 RFC 规范。

## Резюме

Создание сайта документации YaoXiang, объединение разрозненной документации, поддержка поиска, навигации, многоязычности и переключения версий.

## Мотивация

### Зачем нужен этот функционал?

Текущая документация разбросана по нескольким каталогам, представлена только через GitHub Readme, новым пользователям сложно найти нужную информацию, отсутствует поиск, китайская и английская документация не синхронизированы.

### Текущие проблемы

```
docs/
├── README.md              # Основной индекс (ограниченное содержимое)
├── tutorial/              # Учебные пособия
├── guides/               # Руководства
├── architecture/          # Документация по архитектуре
├── design/               # Проектная документация
├── examples/             # Примеры
├── plans/                # Планы реализации
├── implementation/       # Документация по реализации
├── maintenance/          # Документация по обслуживанию
└── archived/             # Архив
```

Проблемы:

1. Нет единой точки входа, только GitHub Readme
2. Отсутствует поиск
3. Нет переключения версий, пользователи могут читать устаревшую документацию
4. .obsidian смешан с контролем версий

### Спецификация URL-путей (основной дизайн)

| Сценарий          | Формат URL                    | Описание             |
| ----------------- | ----------------------------- | -------------------- |
| Последняя версия, китайский | `/zh/getting-started/`      | Перенаправление на последнюю версию |
| Последняя версия, английский | `/en/getting-started/`    | Перенаправление на последнюю версию |
| Указанная версия  | `/v0.5/zh/getting-started/`   | Префикс с номером версии |
| Главная страница  | `/zh/` или `/en/`             | Языковая главная страница |

**Дизайн переключения версий**:

```
Выпадающее меню переключения версий:
├── v0.6 (latest)
├── v0.5
├── v0.4
└── v0.3
```

**Спецификация путей версий** (ключевое решение, сложно изменить позже):

- Последняя версия: `/zh/xxx/` → перенаправление на последнюю версию
- Указанная версия: `/v0.5/zh/xxx/` → фиксированная версия
- Переключение версий в навигационной панели: переключение комбинаций `/v0.5/` и `/zh/`

### Спецификация боковой панели

```typescript
// docs/.vitepress/sidebar/zh.ts
export default {
  '/zh/tutorial/': [
    {
      text: 'Учебные пособия',
      items: [
        { text: 'Быстрый старт', link: '/zh/getting-started' },
        { text: 'Основы', link: '/zh/tutorial/basics' },
      ],
    },
  ],
  '/zh/reference/': [
    {
      text: 'Справочник',
      items: [{ text: 'Встроенные функции', link: '/zh/reference/builtins' }],
    },
  ],
};
```

### Интеграция CI/CD

```yaml
# .github/workflows/docs-deploy.yml
name: Deploy Docs

on:
  push:
    branches: [main]
    paths: ['docs/**', '!.obsidian/**']

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - run: npm ci
        working-directory: docs
      - run: npm run build
      - uses: actions/deploy-pages@v4
        with:
          build_dir: docs/.vitepress/dist
```


### Конфигурация сайта

```typescript
// docs/.vitepress/config.mts
import { defineConfig } from 'vitepress';
import starlight from '@astrojs/starlight';

export default defineConfig({
  title: 'YaoXiang',
  description: 'Язык программирования для будущего',

  locales: {
    root: { label: '中文', lang: 'zh-CN', link: '/zh/' },
    en: { label: 'English', lang: 'en-US', link: '/en/' },
  },

  // Локальный поиск
  plugins: [
    starlight({
      title: 'YaoXiang',
      localSearch: {},
    }),
  ],

  // Ссылка для редактирования
  editLink: {
    pattern: 'https://github.com/yaoxiang-lang/yaoxiang/edit/main/docs/:path',
  },
});
```

## Компромиссы

### Преимущества

- Профессиональный сайт документации улучшает имидж проекта
- Пользователи быстро находят нужную информацию
- Локальный поиск бесплатен и достаточен
- Поддержка нескольких языков обслуживает международное сообщество
- Переключение версий предотвращает чтение устаревшей документации

### Недостатки

- Затраты на обслуживание: требуется поддержка конфигурации сайта
- Введение технологического стека: Node.js

## Альтернативные решения

| Решение       | Почему не выбрано              |
| ------------- | ------------------------------ |
| GitHub Wiki   | Плохой поиск, низкая настройка |
| Только README | Нет поиска, нет навигации      |
| Docusaurus    | Тяжеловесный, медленный запуск |
