# Обработка ошибок

---

## §E1 Ошибки форматирования

**§E1.1 Синтаксические ошибки.** Когда исходный код содержит синтаксические ошибки, форматтер
должен:

1. Использовать функцию `parse()` для синтаксического разбора
2. Если при разборе возникли ошибки, напрямую вернуть информацию об ошибке
3. Не вставлять никаких заглушек

**§E1.2 Ошибки конфигурации.** Если файл конфигурации имеет неверный формат, должна возвращаться
понятная информация об ошибке.

---

## §E2 Коды выхода

| Код выхода | Значение                                                |
| ---------- | ------------------------------------------------------- |
| 0          | Успех                                                   |
| 1          | В режиме `--check` обнаружены неотформатированные файлы |
| 2          | Файл не найден или ошибка конфигурации                  |

---

## §E3 Обработка ошибок

**§E3.1 Отчёт об ошибках.** Форматтер использует функцию `parse()` для разбора исходного кода. Если
в процессе разбора возникают ошибки, форматтер напрямую возвращает информацию об ошибке, не выполняя
форматирование.

**§E3.2 Без заглушек.** Форматтер не вставляет никаких заглушек (например, `/* error */`) в места
ошибок. При обнаружении синтаксической ошибки форматтер напрямую сообщает об ошибке и завершает
работу.
