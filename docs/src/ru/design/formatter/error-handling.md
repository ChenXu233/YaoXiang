# Обработка ошибок

---

## §E1 Ошибки форматирования

**§E1.1 Синтаксические ошибки.** Когда исходный код содержит синтаксические ошибки, форматировщик
должен:

1. Использовать функцию `parse()` для разбора
2. При наличии ошибок разбора напрямую вернуть сообщение об ошибке
3. Не вставлять никаких заполнителей

**§E1.2 Ошибки конфигурации.** При неправильном формате файла конфигурации следует вернуть чёткое
сообщение об ошибке.

---

## §E2 Коды завершения

| Код завершения | Значение                                            |
| -------------- | --------------------------------------------------- |
| 0              | Успех                                               |
| 1              | Режим `--check`: обнаружены неформатированные файлы |
| 2              | Файл не найден или ошибка конфигурации              |

---

## §E3 Обработка ошибок

**§E3.1 Отчёт об ошибках.** Форматировщик использует функцию `parse()` для разбора исходного кода.
Если в процессе разбора возникает ошибка, форматировщик напрямую возвращает сообщение об ошибке без
выполнения форматирования.

**§E3.2 Без заполнителей.** Форматировщик не вставляет никаких заполнителей (например,
`/* error */`) в места ошибок. При обнаружении синтаксической ошибки форматировщик сообщает об
ошибке и завершает работу.
