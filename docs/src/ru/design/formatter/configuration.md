# Параметры конфигурации

---

## Формат конфигурационного файла

Конфигурационный файл использует формат TOML, имя файла — `yaoxiang.toml`.

```toml
[fmt]
# Ограничение ширины строки (по умолчанию 120)
line_width = 120

# Ширина отступа (по умолчанию 4)
indent_width = 4

# Использовать ли tab для отступа (по умолчанию false)
use_tabs = false

# Использовать ли одинарные кавычки (по умолчанию false)
single_quote = false

# Сортировать ли инструкции импорта (по умолчанию true)
sort_imports = true
```

---

## Приоритет конфигурации

Цепочка приоритетов конфигурации (от высокого к низкому):

1. **Параметры CLI** — параметры командной строки имеют наивысший приоритет
2. **Конфигурация уровня проекта** — `yaoxiang.toml` в текущей директории
3. **Конфигурация уровня пользователя** — `~/.config/yaoxiang/config.toml`
4. **Значения по умолчанию** — встроенные значения по умолчанию

---

## Значения по умолчанию

| Параметр       | По умолчанию | Описание                          |
| -------------- | ------------ | --------------------------------- |
| `line_width`   | 120          | Максимальная ширина строки        |
| `indent_width` | 4            | Количество пробелов отступа       |
| `use_tabs`     | false        | Использовать ли tab               |
| `single_quote` | false        | Использовать ли одинарные кавычки |
| `sort_imports` | true         | Сортировать ли импорт             |
