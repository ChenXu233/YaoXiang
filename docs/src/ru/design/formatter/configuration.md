# Параметры конфигурации

---

## Формат файла конфигурации

Файл конфигурации использует формат TOML и называется `yaoxiang.toml`.

```toml
[fmt]
# 行宽限制（默认 120）
line_width = 120

# 缩进宽度（默认 4）
indent_width = 4

# 是否使用 tab 缩进（默认 false）
use_tabs = false

# 是否使用单引号（默认 false）
single_quote = false

# 是否排序导入语句（默认 true）
sort_imports = true
```

---

## Приоритет конфигурации

Цепочка приоритетов конфигурации (от высокого к низкому):

1. **Параметры CLI** — параметры командной строки имеют наивысший приоритет
2. **Конфигурация уровня проекта** — `yaoxiang.toml` в текущем каталоге
3. **Конфигурация уровня пользователя** — `~/.config/yaoxiang/config.toml`
4. **Значения по умолчанию** — встроенные значения по умолчанию

---

## Значения по умолчанию

| Параметр         | По умолчанию | Описание                      |
| ---------------- | ------------ | ----------------------------- |
| `line_width`     | 120          | Максимальная ширина строки    |
| `indent_width`   | 4            | Количество пробелов отступа   |
| `use_tabs`       | false        | Использовать табуляцию        |
| `single_quote`   | false        | Использовать одинарные кавычки|
| `sort_imports`   | true         | Сортировать импорты           |
