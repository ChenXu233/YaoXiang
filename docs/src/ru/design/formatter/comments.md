# Сохранение комментариев

---

## §C1 Типы комментариев

**§C1.1 Однострочные комментарии.** Начинаются с `//`, должны сохраняться.

```
// 这是单行注释
let x = 1;  // 这是行末注释
```

**§C1.2 Многострочные комментарии.** Обрамляются `/* ... */`, поддерживают вложенность, должны
сохраняться.

```
/* 这是多行注释 */
/* 嵌套 /* 注释 */ */
```

**§C1.3 Документирующие комментарии.** Начинаются с `///`, должны сохраняться.

```
/// 这是文档注释
fn foo() { ... }
```

---

## §C2 Расположение комментариев

**§C2.1 Комментарии в начале файла.** Комментарии в начале файла должны сохраняться в начале файла.

**§C2.2 Комментарии между инструкциями.** Комментарии между инструкциями должны сохраняться на
исходном месте.

**§C2.3 Концевые комментарии.** Концевые комментарии должны сохраняться в конце соответствующей
строки.

---

## §C3 Сохранение пустых строк

**§C3.1 Сохранение пустых строк.** Пустые строки в исходном коде должны сохраняться для разделения
логических блоков.
