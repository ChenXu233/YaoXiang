# Особые правила синтаксиса

---

## §13 F-String

**§13.1 Формат F-String.** F-String использует формат `f"..."`, интерполяция выполняется через
`{expr}`.

```
// ✅ Правильно
let msg = f"Hello, {name}!";
let msg = f"Result: {x + y}";
```

**§13.2 Спецификации форматирования.** F-String поддерживает спецификации форматирования
`{expr:spec}`.

```
// ✅ Правильно
let msg = f"{value:.2f}";
```

## §14 Инструкции импорта

**§14.1 Сортировка импорта.** Когда `sort_imports = true`, инструкции импорта сортируются в
следующем порядке:

1. Стандартная библиотека (`std`, `core`, `alloc`)
2. Внешние crate
3. Относительные пути (начинающиеся с `.` или `..`)

**§14.2 Сортировка внутри группы.** Импорты внутри одной группы сортируются в алфавитном порядке.

```
// До сортировки
use z_crate;
use std::collections;
use a_crate;
use ./local;

// После сортировки
use std::collections;
use a_crate;
use z_crate;
use ./local;
```

## §17 Обработка ошибок

**§17.1 Оператор Try.** Используется формат `expr?`.

```
// ✅ Правильно
let x = foo()?;

// ❌ Неправильно
let x = foo() ?;
```

---

## §18 Блоки Unsafe

**§18.1 Формат Unsafe.** Используется формат `unsafe { ... }`.

```
// ✅ Правильно
let x = unsafe { dangerous_function() };

// ❌ Неправильно
let x = unsafe{ dangerous_function() };
```
