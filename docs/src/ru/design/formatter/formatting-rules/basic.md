# Основные правила форматирования

---

## §1 Отступы

**§1.1 Ширина отступа.** По умолчанию используется отступ в 4 пробела. Можно изменить с помощью
параметра конфигурации `indent_width`.

```
// 默认缩进（4 空格）
fn foo() {
    let x = 1;
    if x > 0 {
        print(x);
    }
}

// 2 空格缩进（indent_width = 2）
fn foo() {
  let x = 1;
  if x > 0 {
    print(x);
  }
}
```

**§1.2 Отступы табуляцией.** Когда `use_tabs = true`, для отступов используются символы табуляции.
По умолчанию `false`.

**§1.3 Согласованность отступов.** В пределах одного файла запрещается смешивать табуляцию и
пробелы.

## §2 Ширина строки

**§2.1 Максимальная ширина строки.** По умолчанию максимальная ширина строки составляет 120
символов. Можно изменить с помощью параметра конфигурации `line_width`.

**§2.2 Стратегия переноса строк.** Когда строка превышает максимальную ширину, необходимо выполнить
перенос в подходящем месте. Приоритет мест переноса:

1. После операторов низкого приоритета (`+`, `-`, `or`, `and`, `=`)
2. В списке аргументов функции
3. На элементах списка/словаря
4. После операторов высокого приоритета (`*`, `/`, `%`, `==`, `!=`)

**§2.3 Отступ при переносе.** Содержимое после переноса строки должно иметь дополнительный уровень
отступа.

```
// 超过行宽时换行
let result = very_long_variable_name + another_long_name + yet_another_long_name;

// 格式化后
let result = very_long_variable_name
    + another_long_name
    + yet_another_long_name;
```

## §3 Операторы

**§3.1 Пробелы вокруг операторов.** Бинарные операторы должны быть окружены пробелами с обеих
сторон.

```
// ✅ 正确
let x = 1 + 2;
let y = a == b;

// ❌ 错误
let x = 1+2;
let y = a==b;
```

**§3.2 Унарные операторы.** Между унарным оператором и операндом пробел не ставится.

```
// ✅ 正确（not 是关键字运算符，需空格）
let x = -1;
let y = not flag;
let z = *ptr;

// ❌ 错误
let x = - 1;
let y = not(flag);
```

**§3.3 Перенос строк для операторов низкого приоритета.** Когда выражение превышает ширину строки,
операторы низкого приоритета помещаются в начало новой строки.

```
// 超过行宽时
let result = first_value + second_value + third_value + fourth_value;

// 格式化后
let result = first_value
    + second_value
    + third_value
    + fourth_value;
```

**§3.4 Перенос строк для операторов высокого приоритета.** Операторы высокого приоритета помещаются
в начало новой строки.

```
// 超过行宽时
let result = first_value * second_value / third_value % fourth_value;

// 格式化后
let result = first_value
    * second_value
    / third_value
    % fourth_value;
```

---

## §3.5 Ссылки на переменные

**§3.5.1 Имена переменных.** При ссылке на переменную выводится её имя без дополнительных пробелов.

```
// ✅ 正确
let x = my_variable;
let y = camelCaseName;

// ❌ 错误
let x = my_variable ;  // 多余空格
let y = "camelCaseName";  // 不应加引号
```

## §6 Блоки кода

**§6.1 Формат блоков кода.** Блоки кода заключаются в фигурные скобки `{}`, перед открывающей
скобкой ставится один пробел.

```
// ✅ 正确
fn foo() {
    let x = 1;
}

// ❌ 错误
fn foo(){
    let x = 1;
}
fn foo()
{
    let x = 1;
}
```

**§6.2 Однострочные блоки кода.** Когда блок кода состоит из одной строки и его общая длина не
превышает ширины строки, допускается однострочный формат.

```
// ✅ 单行格式
fn foo() { 1 }

// ✅ 多行格式
fn foo() {
    let x = 1;
    let y = 2;
    x + y
}
```

**§6.3 Пустые блоки кода.** Пустые блоки кода записываются как `{}`.

```
// ✅ 正确
fn foo() {}

// ❌ 错误
fn foo() {
}
```
