# Документ проектирования команды check

`yaoxiang check` — это инструмент статической проверки компилятора YaoXiang, предоставляющий
возможности проверки типов, межфайлового анализа и инкрементальной проверки.

## Принципы проектирования

1. **Нулевой уровень ложных срабатываний**: каждая сообщаемая ошибка должна быть реальной ошибкой
2. **Межфайловая осведомлённость**: корректное обнаружение межмодульных ошибок типов и
   неопределённых ссылок
3. **Приоритет инкрементальности**: в режиме watch повторно проверяются только затронутые файлы
4. **Самодокументирование**: коды ошибок, шаблоны сообщений и текст справки управляются через i18n

## Границы с другими системами

| Система                         | Обязанности                                                   | Отношение с check                             |
| ------------------------------- | ------------------------------------------------------------- | --------------------------------------------- |
| Компилятор (`yaoxiang build`)   | Полная компиляция (парсинг → проверка типов → генерация кода) | check выполняет только первые два шага        |
| LSP                             | Интеграция с редактором (дополнение, переход, диагностика)    | Диагностика check может быть переиспользована |
| Форматирование (`yaoxiang fmt`) | Стиль кода                                                    | Независимо, используется параллельно в CI     |
