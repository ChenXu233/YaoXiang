# Документ проектирования команды check

`yx check` — это инструмент статической проверки компилятора YaoXiang, предоставляющий проверку
типов, межфайловый анализ и функции инкрементальной проверки.

## Принципы проектирования

1. **Нулевой уровень ложных срабатываний**: каждая сообщаемая ошибка должна быть реальной ошибкой
2. **Межфайловая осведомлённость**: корректное обнаружение ошибок типов между модулями и
   неопределённых ссылок
3. **Приоритет инкрементальности**: режим watch повторно проверяет только затронутые файлы
4. **Самодокументирование**: коды ошибок, шаблоны сообщений и текст справки управляются через i18n

## Границы с другими системами

| Система                      | Обязанности                                                   | Связь с check                                 |
| ---------------------------- | ------------------------------------------------------------- | --------------------------------------------- |
| Компилятор (`yx build`)      | Полная компиляция (парсинг → проверка типов → генерация кода) | check выполняет только первые два этапа       |
| LSP                          | Интеграция с редактором (дополнение, переход, диагностика)    | Диагностика check может быть переиспользована |
| Форматирование (`yx format`) | Стиль кода                                                    | Независим, используется параллельно в CI      |
