# yx check

Выполняет статическую проверку (проверку типов, проверку владения) исходного кода YaoXiang без
генерации какого-либо кода.

## Использование

```
yx check [OPTIONS] [PATH]...
```

## Аргументы

| Аргумент | Описание                                                                                      |
| -------- | --------------------------------------------------------------------------------------------- |
| `PATH`   | Один или несколько путей к файлам или каталогам. Если не указано, проверяется текущий проект. |

## Опции

| Опция              | Описание                                                     | По умолчанию |
| ------------------ | ------------------------------------------------------------ | ------------ |
| `--json`           | Вывод диагностической информации в формате JSON              | нет          |
| `-w`, `--watch`    | Отслеживание изменений файлов с автоматической перепроверкой | нет          |
| `--color <MODE>`   | Режим цветного вывода: `auto`, `always`, `never`             | `auto`       |
| `--exclude <PATH>` | Исключить указанный путь (можно использовать несколько раз)  | нет          |
| `--no-progress`    | Подавить сообщения о прогрессе и сводке                      | нет          |

## Коды завершения

| Код завершения | Описание                       |
| -------------- | ------------------------------ |
| `0`            | Ошибки отсутствуют             |
| `1`            | При проверке обнаружены ошибки |
| `2`            | Файлы `.yx` не найдены         |

## Межфайловый анализ

`yx check` поддерживает межфайловую проверку типов. При проверке нескольких файлов:

1. Параллельно разбираются все `.yx` файлы
2. Строится граф зависимостей модулей
3. Обнаруживаются циклические зависимости (сообщается об ошибке)
4. Проверка выполняется в порядке топологической сортировки
5. Используется общее окружение типов для корректного обнаружения межфайловых ссылок

```bash
# Проверить весь проект (автоматическое обнаружение межфайловых ссылок)
yx check src/

# Проверить указанные файлы
yx check src/main.yx src/lib.yx
```

## Инкрементальная проверка (режим watch)

Используйте `-w` или `--watch` для включения режима отслеживания файлов. При изменении файлов
проверка запускается автоматически.

```bash
yx check --watch
```

## Формат вывода JSON

При использовании `--json` формат вывода следующий:

```json
{
  "error_count": 0,
  "warning_count": 0,
  "diagnostics": [
    {
      "file": "src/main.yx",
      "severity": "error",
      "code": "E1001",
      "message": "Unknown variable: 'x'",
      "line": 5,
      "column": 3,
      "end_line": 5,
      "end_column": 4,
      "lsp": { ... }
    }
  ]
}
```

## Примеры

```bash
# Проверить текущий проект
yx check

# Проверить указанный файл
yx check src/main.yx

# Проверить каталог и вывести JSON
yx check src/ --json

# Режим отслеживания
yx check --watch

# Режим CI (без цвета, без прогресса)
yx check --color never --no-progress

# Исключить каталог тестов
yx check src/ --exclude tests/
```

## Интеграция с CI

```yaml
# GitHub Actions
- name: Type check
  run: yx check --color never --no-progress
```

Подробную конфигурацию CI смотрите в [Руководстве по интеграции с CI](../guide/ci-integration.md).
