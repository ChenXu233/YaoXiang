# Спецификация языка

Спецификация синтаксиса и семантики языка yaoxiang.

## Содержание

- [Синтаксис](./syntax.md) — лексическая структура, синтаксические правила, приоритет операторов
- [Система типов](./type-system.md) — базовые типы, составные типы, дженерики, trait
- [Модульная система](./modules.md) — определение модулей, импорт и экспорт, области видимости
- [Модель параллелизма](./concurrency.md) — семантика блоков {}, примитив параллелизма spawn,
  обработка ошибок, типы ресурсов
- [Стандартная библиотека](./stdlib.md) — ядро, библиотека ввода-вывода, математическая библиотека

## Обзор

Данная спецификация определяет основной синтаксис и семантику языка программирования YaoXiang. Она
является авторитетным справочником по языку, ориентированным на разработчиков компиляторов и
инструментов.

### Структура спецификации

1. **Синтаксис** — определяет лексическую структуру языка, синтаксические правила и приоритет
   операторов
2. **Система типов** — определяет систему типов языка, включая базовые типы, составные типы,
   дженерики и trait
3. **Модульная система** — определяет модульную систему языка, включая определение модулей, импорт,
   экспорт и области видимости
4. **Модель параллелизма** — определяет модель параллелизма языка, включая асинхронное
   программирование, примитивы параллелизма и модель памяти
5. **Стандартная библиотека** — определяет стандартную библиотеку языка, включая ядро, библиотеку
   ввода-вывода и математическую библиотеку
