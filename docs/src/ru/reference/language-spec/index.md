# Спецификация языка

Документ с описанием синтаксиса и семантики языка yaoxiang.

## Содержание

- [Спецификация синтаксиса](./syntax.md) - лексическая структура, синтаксические правила, приоритет операторов
- [Система типов](./type-system.md) - базовые типы, составные типы, generics, trait
- [Система модулей](./modules.md) - определение модулей, импорт/экспорт, области видимости
- [Модель конкурентности](./concurrency.md) - семантика блоков {}, примитивы конкурентности spawn, обработка ошибок, типы ресурсов
- [Стандартная библиотека](./stdlib.md) - основная библиотека, IO-библиотека, математическая библиотека

## Обзор

В данной спецификации определены основные синтаксис и семантика языка программирования YaoXiang. Она служит авторитетным справочником по языку для разработчиков компиляторов и инструментов.

### Структура спецификации

1. **Спецификация синтаксиса**: определяет лексическую структуру языка, синтаксические правила и приоритет операторов
2. **Система типов**: определяет систему типов языка, включая базовые типы, составные типы, generics и trait
3. **Система модулей**: определяет систему модулей языка, включая определение модулей, импорт/экспорт и области видимости
4. **Модель конкурентности**: определяет модель конкурентности языка, включая асинхронное программирование, примитивы конкурентности и модель памяти
5. **Стандартная библиотека**: определяет стандартную библиотеку языка, включая основную библиотеку, IO-библиотеку и математическую библиотеку
