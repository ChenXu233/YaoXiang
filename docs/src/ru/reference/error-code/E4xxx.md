# E4xxx：Обобщения и трейты

> Автоматически сгенерировано из `src/util/diagnostic/codes/`

## Список ошибок

## E4001：Нарушение ограничения обобщения

**Категория**: Generic

**Сообщение**: Тип не удовлетворяет ограничению обобщения

**Помощь**: Убедитесь, что тип удовлетворяет всем необходимым ограничениям трейта

---

## E4002：Трейт не найден

**Категория**: Generic

**Сообщение**: Указанный трейт не существует

**Помощь**: Проверьте имя трейта или импортируйте корректный трейт

---

## E4003：Отсутствует реализация трейта

**Категория**: Generic

**Сообщение**: Тип не реализует необходимый трейт

**Помощь**: Добавьте реализацию трейта для этого типа

---

## E4004：Конфликтующие реализации трейта

**Категория**: Generic

**Сообщение**: Несколько реализаций трейта конфликтуют

**Помощь**: Устраните конфликтующие реализации
