## E6008：Ключ не найден

**Категория**: Runtime (Время выполнения)

**Сообщение**: Ключ не найден

**Справка**: Используйте `dict.has` для проверки наличия ключа перед индексацией

---

> #299 §4：Отсутствующий ключ в Dict и выход индекса за границы (E6003) относятся к разным
> семантическим категориям — ключ отсутствует против превышения порядкового номера, поэтому они
> выделены в отдельные коды для сохранения диагностической информации. Для безопасного доступа
> используйте `dict.has` для предварительной проверки перед извлечением.
