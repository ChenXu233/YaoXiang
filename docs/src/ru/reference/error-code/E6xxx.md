# E6xxx: Ошибки времени выполнения

> Автоматически сгенерировано из `src/util/diagnostic/codes/`

## Список ошибок

## E6001: Деление на ноль

**Категория**: Runtime

**Сообщение**: Попытка деления на ноль

**Справка**: Добавьте проверку для предотвращения деления на ноль

---

## E6003: Выход индекса массива за границы

**Категория**: Runtime

**Сообщение**: Индекс массива выходит за границы во время выполнения

**Справка**: Убедитесь, что индекс находится в пределах границ массива

---

## E6004: Переполнение стека

**Категория**: Runtime

**Сообщение**: Глубина рекурсии превысила лимит стека

**Справка**: Уменьшите глубину рекурсии или используйте итерацию

---

## E6005: Утверждение не выполнено

**Категория**: Runtime

**Сообщение**: Утверждение не выполнено во время выполнения

**Справка**: Исправьте условие утверждения или предоставьте корректные входные данные

---
