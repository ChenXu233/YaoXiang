# E6xxx: Ошибки времени выполнения

> Автоматически сгенерировано из `src/util/diagnostic/codes/`

## Список ошибок

## E6001: Деление на ноль

**Категория**: Runtime

**Сообщение**: Попытка деления на ноль

**Помощь**: Добавьте проверку для предотвращения деления на ноль

---

## E6003: Индекс массива за пределами допустимого диапазона

**Категория**: Runtime

**Сообщение**: Индекс массива выходит за пределы допустимого диапазона во время выполнения

**Помощь**: Убедитесь, что индекс находится в пределах допустимого диапазона массива

---

## E6004: Переполнение стека

**Категория**: Runtime

**Сообщение**: Глубина рекурсии превысила лимит стека

**Помощь**: Уменьшите глубину рекурсии или используйте итерацию

---

## E6005: Утверждение не выполнено

**Категория**: Runtime

**Сообщение**: Утверждение не выполнено во время выполнения

**Помощь**: Исправьте условие утверждения или предоставьте корректные входные данные

---

## E6008: Ключ не найден

**Категория**: Runtime

**Сообщение**: Ключ не найден

**Помощь**: Используйте `dict.has` для проверки существования ключа перед индексацией

---

> #299 §4: Отсутствие ключа в Dict и выход индекса за пределы (E6003) относятся к разным
> семантическим категориям — ключ не существует vs превышение порядкового номера, независимые коды
> сохраняют диагностическую информацию. Для безопасного доступа используйте `dict.has` для
> предварительной проверки перед извлечением.
