# Формат yaoxiang.lock

`yaoxiang.lock` — это файл блокировки зависимостей YaoXiang, в котором записывается точная
информация о версиях всех зависимостей.

## Обзор

- **Автоматически генерируется**: создаётся и обновляется командами `yx install` и `yx update`
- **Не редактируйте вручную**: этот файл автоматически поддерживается менеджером пакетов
- **Должен быть зафиксирован в системе контроля версий**: чтобы обеспечить использование одинаковых
  версий зависимостей участниками команды и при сборках CI

## Структура файла

```toml
# 由 YaoXiang 包管理器自动生成

[package]
version = 1

[package.依赖名]
version = "版本号"
source = "来源类型"
checksum = "校验和（可选）"
```

## Описание полей

### Секция `[package]`

| Поле      | Тип     | Описание                                  |
| --------- | ------- | ----------------------------------------- |
| `version` | integer | Версия формата файла блокировки, сейчас 1 |

### Секция `[package.<имя>]`

| Поле       | Тип    | Описание                                        |
| ---------- | ------ | ----------------------------------------------- |
| `version`  | string | Точный разрешённый номер версии                 |
| `source`   | string | Источник зависимости: `registry`, `git`, `path` |
| `checksum` | string | Контрольная сумма SHA-256 (необязательно)       |

## Пример

```toml
# 由 YaoXiang 包管理器自动生成
# 2024-01-15 10:30:00

[package]
version = 1

[package.http]
version = "1.0.0"
source = "registry"
checksum = "abc123..."

[package.json]
version = "2.0.0"
source = "registry"

[package.utils]
version = "0.1.0"
source = "path"

[package.bleeding]
version = "main"
source = "git"
```

## Типы источников

| Тип        | Описание                        | Пример конфигурации       |
| ---------- | ------------------------------- | ------------------------- |
| `registry` | Получение из удалённого реестра | `http = "1.0.0"`          |
| `git`      | Получение из Git-репозитория    | `{ git = "https://..." }` |
| `path`     | Получение из локального пути    | `{ path = "./lib" }`      |

## Связь с манифестом

```
yaoxiang.toml          yaoxiang.lock
     │                       │
     │   yx install    │
     ├──────────────────────►│
     │                       │
     │   声明 "http = *>"   │ 锁定 "http = 1.0.0"
     │                       │
```

- `yaoxiang.toml`: объявляет **желаемые** зависимости (можно использовать диапазоны)
- `yaoxiang.lock`: фиксирует **фактически установленные** версии (точные версии)
