# Менеджер пакетов

Встроенный менеджер пакетов YaoXiang предоставляет функции инициализации проекта, управления
зависимостями, фиксации версий и другие возможности.

## Обзор

Менеджер пакетов YaoXiang (сокращённо YPM) использует концепцию дизайна, аналогичную Cargo:

- **Декларативные зависимости**: необходимые зависимости объявляются в `yaoxiang.toml`
- **Детерминированная сборка**: версии фиксируются через `yaoxiang.lock`, что обеспечивает
  воспроизводимые сборки
- **Локальный кэш**: зависимости загружаются в каталог `vendor`, поддерживается автономная работа

## Быстрый старт

```bash
# 1. Создать новый проект
yx init my-project

# 2. Добавить зависимость
cd my-project
yx add http

# 3. Установить зависимости
yx install

# 4. Запустить проект
yx run src/main.yx
```

## Список команд

| Команда                               | Описание                     |
| ------------------------------------- | ---------------------------- |
| [`yx init`](./commands#yx-init)       | Инициализация нового проекта |
| [`yx add`](./commands#yx-add)         | Добавить зависимость         |
| [`yx rm`](./commands#yx-rm)           | Удалить зависимость          |
| [`yx install`](./commands#yx-install) | Установить зависимости       |
| [`yx update`](./commands#yx-update)   | Обновить зависимости         |
| [`yx list`](./commands#yx-list)       | Список зависимостей          |

## Структура проекта

```
my-project/
├── yaoxiang.toml      # Манифест проекта (обязательно)
├── yaoxiang.lock      # Файл блокировки зависимостей (генерируется автоматически)
├── vendor/            # Каталог хранения зависимостей (генерируется автоматически)
└── src/
    └── main.yx       # Файл точки входа
```
