# Менеджер пакетов

Встроенный менеджер пакетов YaoXiang предоставляет функции инициализации проекта, управления
зависимостями, фиксации версий и другие возможности.

## Обзор

Менеджер пакетов YaoXiang (сокращённо YPM) использует дизайн-концепцию, аналогичную Cargo:

- **Декларативные зависимости**: объявляйте необходимые зависимости в `yaoxiang.toml`
- **Детерминированная сборка**: фиксация версий через `yaoxiang.lock` обеспечивает воспроизводимые
  сборки
- **Локальный кэш**: зависимости загружаются в каталог `vendor`, поддерживается автономное
  использование

## Быстрый старт

```bash
# 1. Создание нового проекта
yx init my-project

# 2. Добавление зависимости
cd my-project
yx add http

# 3. Установка зависимостей
yx install

# 4. Запуск проекта
yx run src/main.yx
```

## Список команд

| Команда                               | Описание                     |
| ------------------------------------- | ---------------------------- |
| [`yx init`](./commands#yx-init)       | Инициализация нового проекта |
| [`yx add`](./commands#yx-add)         | Добавление зависимости       |
| [`yx rm`](./commands#yx-rm)           | Удаление зависимости         |
| [`yx install`](./commands#yx-install) | Установка зависимостей       |
| [`yx update`](./commands#yx-update)   | Обновление зависимостей      |
| [`yx list`](./commands#yx-list)       | Список зависимостей          |

## Структура проекта

```
my-project/
├── yaoxiang.toml      # Манифест проекта (обязательно)
├── yaoxiang.lock      # Файл фиксации зависимостей (генерируется автоматически)
├── vendor/            # Каталог хранения зависимостей (генерируется автоматически)
└── src/
    └── main.yx       # Точка входа
```
