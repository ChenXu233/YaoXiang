# Коды ошибок

В этом документе перечислены ошибки, которые может возвращать менеджер пакетов YaoXiang, и способы
их обработки.

## Список ошибок

### E0100: Проект уже существует

```
Error: Project already exists: <path>
```

**Причина**: каталог проекта, который вы пытаетесь создать, уже существует.

**Способ устранения**:

1. Выберите другое имя проекта.
2. Удалите или переместите существующий каталог.

---

### E0101: Не является допустимым проектом

```
Error: Not a YaoXiang project: yaoxiang.toml not found
```

**Причина**: в текущем или указанном каталоге отсутствует файл `yaoxiang.toml`.

**Способ устранения**:

1. Убедитесь, что команда выполняется в каталоге проекта.
2. Используйте `yx init` для создания нового проекта.

---

### E0102: Зависимость не найдена

```
Error: Dependency not found: <name>
```

**Причина**: попытка выполнить операцию с несуществующей зависимостью.

**Способ устранения**:

1. Проверьте правильность написания имени зависимости.
2. Используйте `yx list` для просмотра существующих зависимостей.

---

### E0103: Зависимость уже существует

```
Error: Dependency already exists: <name>
```

**Причина**: попытка добавить уже существующую зависимость.

**Способ устранения**:

1. Если требуется обновить версию, сначала удалите её с помощью `yx rm`.
2. Либо используйте существующую зависимость напрямую.

---

### E0104: Неверный формат manifest

```
Error: Invalid yaoxiang.toml format: <details>
```

**Причина**: неверный формат файла `yaoxiang.toml`.

**Способ устранения**:

1. Проверьте корректность синтаксиса TOML.
2. Убедитесь в наличии всех обязательных полей.
3. Проверьте наличие синтаксических ошибок (например, отсутствие кавычек, запятых и т. д.).

---

### E0105: Ошибка ввода-вывода

```
Error: IO error: <details>
```

**Причина**: сбой при чтении или записи файла.

**Распространённые причины**:

- недостаточно места на диске;
- недостаточно прав;
- файл занят другой программой.

**Способ устранения**:

1. Проверьте свободное место на диске.
2. Проверьте права доступа к файлу.
3. Закройте другие программы, которые могут занимать файл.

---

### E0106: Ошибка разбора TOML

```
Error: TOML parse error: <details>
```

**Причина**: неверный формат файла TOML.

**Способ устранения**:

1. Проверьте синтаксис TOML.
2. Убедитесь в правильном экранировании специальных символов.

---

## Часто задаваемые вопросы

### В: Что делать, если установка зависимостей завершилась неудачно?

1. Проверьте сетевое подключение.
2. Убедитесь в правильности имени и версии зависимости.
3. Попробуйте выполнить `yx update` для обновления.

### В: Что делать при конфликте версий?

Проверьте, нет ли в `yaoxiang.toml` несовместимых требований к версиям зависимостей.

### В: Что делать, если каталог vendor повреждён?

Удалите каталог `vendor` и повторно выполните `yx install`.
