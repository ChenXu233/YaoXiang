# Интерфейс командной строки

## yx init

Инициализировать новый проект YaoXiang.

### Использование

```bash
yx init <имя_проекта>
```

### Параметры

| Параметр    | Описание           |
| ----------- | ------------------ |
| имя_проекта | Имя нового проекта |

### Опции

| Опция    | Описание         |
| -------- | ---------------- |
| `--help` | Показать справку |

### Примеры

```bash
# Создание нового проекта
yx init my-project

# Результат:
# ✨ Проект создан: my-project
#   my-project/yaoxiang.toml
#   my-project/yaoxiang.lock
#   my-project/src/main.yx
#   my-project/.gitignore
```

## yx add

Добавить зависимость в проект.

### Использование

```bash
yx add <имя_пакета> [версия]
yx add <имя_пакета> --dev
```

### Параметры

| Параметр   | Описание                                       |
| ---------- | ---------------------------------------------- |
| имя_пакета | Имя добавляемой зависимости                    |
| версия     | Номер версии (необязательно, по умолчанию `*`) |

### Опции

| Опция         | Описание                                |
| ------------- | --------------------------------------- |
| `--dev`, `-D` | Добавить как зависимость для разработки |

### Примеры

```bash
# Добавление последней версии
yx add http

# Добавление указанной версии
yx add http 1.0.0

# Добавление диапазона версий
yx add json ">=2.0.0"

# Добавление зависимости для разработки
yx add test-utils --dev
yx add benchmark -D
```

## yx rm

Удалить зависимость из проекта.

### Использование

```bash
yx rm <имя_пакета>
yx rm <имя_пакета> --dev
```

### Параметры

| Параметр   | Описание                  |
| ---------- | ------------------------- |
| имя_пакета | Имя удаляемой зависимости |

### Опции

| Опция         | Описание                           |
| ------------- | ---------------------------------- |
| `--dev`, `-D` | Удалить зависимость для разработки |

### Примеры

```bash
# Удаление обычной зависимости
yx rm http

# Удаление зависимости для разработки
yx rm test-utils --dev
```

## yx install

Установить зависимости проекта.

### Использование

```bash
yx install
```

### Описание

- Читает объявления зависимостей из `yaoxiang.toml`
- Загружает все зависимости в каталог `vendor`
- Создаёт/обновляет файл блокировки `yaoxiang.lock` для фиксации версий
- Обнаруживает конфликты версий зависимостей

### Примеры

```bash
# Установка всех зависимостей
yx install

# Пример вывода:
# 📦 Разрешение зависимостей...
#   http (1.0.0) [установлено]
#   json (2.0.0) [из кэша]
# ✅ Зависимости установлены, файл блокировки обновлён
```

## yx update

Обновить зависимости проекта.

### Использование

```bash
yx update
yx update <имя_пакета>
```

### Параметры

| Параметр   | Описание                                              |
| ---------- | ----------------------------------------------------- |
| имя_пакета | Конкретная зависимость для обновления (необязательно) |

### Описание

- Без параметров: обновить все зависимости
- С параметром: обновить только указанную зависимость

### Примеры

```bash
# Обновление всех зависимостей
yx update

# Пример вывода:
# 📦 Обновление зависимостей...
1.0.#   http (0 → 1.1.0)
# ✅ Обновлена 1 зависимость, файл блокировки обновлён

# Обновление одной зависимости
yx update http
```

## yx list

Показать все зависимости проекта.

### Использование

```bash
yx list
```

### Описание

Отображает все runtime-зависимости и зависимости для разработки, а также их версии и источники.

### Примеры

```bash
# Список зависимостей
yx list

# Пример вывода:
# 📦 Зависимости проекта
#
# Runtime-зависимости:
#   http        1.0.0    registry
#   json        2.0.0    registry
#
# Зависимости для разработки:
#   test-utils  0.5.0    registry
```
