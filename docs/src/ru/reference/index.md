## Встроенные типы

### Примитивные типы

| Тип      | Описание                        | Пример          |
| -------- | ------------------------------- | --------------- |
| `Void`   | void/без возвращаемого значения | `()`            |
| `Bool`   | Логическое значение             | `true`, `false` |
| `Int`    | Целое число                     | `42`, `-10`     |
| `Float`  | Число с плавающей точкой        | `3.14`, `-0.5`  |
| `Char`   | Символ                          | `'a'`, `'中'`   |
| `String` | Строка                          | `"hello"`       |

### Составные типы

| Тип                  | Описание                     | Пример         |
| -------------------- | ---------------------------- | -------------- |
| `Tuple(T1, T2, ...)` | Кортеж разнородных элементов | `(1, "hello")` |
| `(Args) -> Ret`      | Функциональный тип           | `(Int) -> Int` |

> #299: Контейнерные типы (`List(T)` / `Array(T, N)` / `Dict(K, V)`) не являются встроенными
> примитивами — это конструкторы дженерик-типов, обрабатываемые наравне с пользовательскими
> дженериками через единый путь инстанцирования. Синтаксис литералов (`[...]` / `{...}`) сохранён в
> ядре, конкретный выбор определяется контекстным выводом. Тип `Set` исключён (#300), подробности
> см. в [спецификации языка](language-spec/syntax.md).

### Пользовательские типы

```yaoxiang
// Записевой тип (структура)
Point: Type = { x: Float, y: Float }

// Тип-перечисление
Result: (T: Type, E: Type) -> Type = { ok: (T) -> Result(T, E), err: (E) -> Result(T, E) }

// Интерфейсный тип (все поля — функции)
Callable: Type = { call: (String) -> Void }
```

## Встроенные функции

### Вывод

```yaoxiang
print(value)           // Печать без перевода строки

```

```yaoxiang

```

### Проверка типов

```yaoxiang

```

## Краткий справочник по синтаксису

### Объявление переменных

```yaoxiang
// Неизменяемая переменная (по умолчанию)
x: Int = 42
y = 42                 // Вывод типа

// Изменяемая переменная
mut count: Int = 0
count = count + 1
```

### Определение функций

```yaoxiang
// Обычная функция
add: (a: Int, b: Int) -> Int = a + b

// Spawn-функция (автоматическая конкурентность)
fetch: (url: String) -> JSON spawn = HTTP.get(url).json()

// Дженерик-функция
identity: [T](x: T) -> T = x
```

### Управление потоком

```yaoxiang
// Условие
if x > 0 {
    print("positive")
} else if x < 0 {
    print("negative")
} else {
    print("zero")
}

// Сопоставление с образцом
match result {
    ok(value) => print("success: " + value),
    err(error) => print("error: " + error),
}

// Цикл
for i in 0..10 {
    print(i)
}
```

### Обработка ошибок

```yaoxiang
// Оператор ? для распространения ошибки
data = fetch_file(path)?
```

## Полный пример

```yaoxiang
// Вычисление чисел Фибоначчи
fib: (n: Int) -> Int = if n <= 1 {
    n
} else {
    fib(n - 1) + fib(n - 2)
}

// Главная функция
main: () -> Void = {
    print("Fibonacci(10) = " + fib(10).to_string())
}
```
