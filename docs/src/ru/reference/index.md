## Встроенные типы

### Примитивные типы

| Тип      | Описание                                   | Пример          |
| -------- | ------------------------------------------ | --------------- |
| `Void`   | Пустое значение/нет возвращаемого значения | `()`            |
| `Bool`   | Логическое значение                        | `true`, `false` |
| `Int`    | Целое число                                | `42`, `-10`     |
| `Float`  | Число с плавающей точкой                   | `3.14`, `-0.5`  |
| `Char`   | Символ                                     | `'a'`, `'中'`   |
| `String` | Строка                                     | `"hello"`       |

### Составные типы

| Тип                  | Описание                     | Пример         |
| -------------------- | ---------------------------- | -------------- |
| `List(T)`            | Список однотипных элементов  | `[1, 2, 3]`    |
| `Tuple(T1, T2, ...)` | Кортеж разнотипных элементов | `(1, "hello")` |
| `Dict(K, V)`         | Отображение ключ-значение    | `{"a": 1}`     |
| `(Args) -> Ret`      | Тип функции                  | `(Int) -> Int` |

### Пользовательские типы

```yaoxiang
// Тип записи (структура)
Point: Type = { x: Float, y: Float }

// Перечисление (enum)
Result: (T: Type, E: Type) -> Type = { ok: (T) -> Result(T, E), err: (E) -> Result(T, E) }

// Интерфейсный тип (все поля — функции)
Callable: Type = { call: (String) -> Void }
```

## Встроенные функции

### Вывод

```yaoxiang
print(value)           // Печать без перевода строки
println(value)         // Печать с переводом строки
```

### Преобразование

```yaoxiang
to_string(value)       // Преобразовать в строку
to_int(value)          // Преобразовать в целое число
to_float(value)        // Преобразовать в число с плавающей точкой
```

### Проверка типов

```yaoxiang
typeof(value)         // Возвращает имя типа
is_type(value, type)  // Проверить тип
```

## Краткая справка по синтаксису

### Объявление переменных

```yaoxiang
// Неизменяемая переменная (по умолчанию)
x: Int = 42
y = 42                 // Вывод типа

// Изменяемая переменная
mut count: Int = 0
count = count + 1
```

### Определение функций

```yaoxiang
// Обычная функция
add: (a: Int, b: Int) -> Int = a + b

// 并作 функция (автоматический параллелизм)
fetch: (url: String) -> JSON spawn = HTTP.get(url).json()

// Обобщённая функция
identity: [T](x: T) -> T = x
```

### Управление потоком выполнения

```yaoxiang
// Условие
if x > 0 {
    print("positive")
} else if x < 0 {
    print("negative")
} else {
    print("zero")
}

// Сопоставление с образцом
match result {
    ok(value) => print("success: " + value),
    err(error) => print("error: " + error),
}

// Цикл
for i in 0..10 {
    print(i)
}
```

### Обработка ошибок

```yaoxiang
// Оператор ? распространяет ошибку
data = fetch_file(path)?
```

## Полный пример

```yaoxiang
// Вычисление чисел Фибоначчи
fib: (n: Int) -> Int = if n <= 1 {
    n
} else {
    fib(n - 1) + fib(n - 2)
}

// Главная функция
main: () -> Void = {
    print("Fibonacci(10) = " + fib(10).to_string())
}
```
