## Встроенные типы

### Примитивные типы

| Тип      | Описание                       | Пример          |
| -------- | ------------------------------ | --------------- |
| `Void`   | Пустое значение / без возврата | `()`            |
| `Bool`   | Логическое значение            | `true`, `false` |
| `Int`    | Целое число                    | `42`, `-10`     |
| `Float`  | Число с плавающей точкой       | `3.14`, `-0.5`  |
| `Char`   | Символ                         | `'a'`, `'中'`   |
| `String` | Строка                         | `"hello"`       |

### Составные типы

| Тип                  | Описание                     | Пример         |
| -------------------- | ---------------------------- | -------------- |
| `Tuple(T1, T2, ...)` | Кортеж разнородных элементов | `(1, "hello")` |
| `(Args) -> Ret`      | Функциональный тип           | `(Int) -> Int` |

> #299: Типы-контейнеры (`List(T)` / `Vec(T)` / `Array(T, N)` / `Dict(K, V)`) не являются
> встроенными примитивами — это конструкторы обобщённых (generic) типов, которые рассматриваются так
> же, как пользовательские дженерики, и обрабатываются через единый механизм инстанцирования
> дженериков. Синтаксис литералов (`[...]` / `{...}`) остаётся в ядре, конкретный тип определяется
> контекстной аннотацией. Set исключён (#300), подробности см. в
> [языковой спецификации](language-spec/syntax.md).
>
> Три концепции контейнеров различаются по принадлежности информации о длине: `Array(T, N)` — длина
> в типе (фиксированная), `Vec(T)` — длина является значением времени выполнения (примитив
> необработанного буфера), `List(T)` — тип стандартной библиотеки (`{ data: Vec(T), length: Int }`,
> вся стратегия — в библиотеке).

### Пользовательские типы

```yaoxiang
// 记录类型（结构体）
Point: Type = { x: Float, y: Float }

// 枚举类型
Result: (T: Type, E: Type) -> Type = { ok: (T) -> Result(T, E), err: (E) -> Result(T, E) }

// 接口类型（所有字段为函数）
Callable: Type = { call: (String) -> Void }
```

## Краткий справочник по синтаксису

### Объявление переменных

```yaoxiang
// 不可变变量（默认）
x: Int = 42
y = 42                 // 类型推断

// 可变变量
mut count: Int = 0
count = count + 1
```

### Определение функций

```yaoxiang
// 普通函数
add: (a: Int, b: Int) -> Int = a + b

// 并作函数（自动并发）
fetch: (url: String) -> JSON spawn = HTTP.get(url).json()

// 泛型函数
identity: [T](x: T) -> T = x
```

### Управление потоком

```yaoxiang
// 条件
if x > 0 {
    print("positive")
} else if x < 0 {
    print("negative")
} else {
    print("zero")
}

// 模式匹配
match result {
    ok(value) => print("success: " + value),
    err(error) => print("error: " + error),
}

// 循环
for i in 0..10 {
    print(i)
}
```

### Обработка ошибок

```yaoxiang
// ? 运算符传播错误
data = fetch_file(path)?
```

## Приоритет операторов

| Приоритет  | Оператор                                                                                                                                                                            |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Наивысший  | `( )` вызов функции                                                                                                                                                                 |
|            | `.` доступ к полю                                                                                                                                                                   |
|            | `[ ]` индексация                                                                                                                                                                    |
|            | `unary -` унарный минус                                                                                                                                                             |
|            | `* / %` умножение, деление, остаток от деления                                                                                                                                      |
|            | (Приоритет и ассоциативность операторов зафиксированы в языке; семантика `+ - * / %` `== !=` `[]` может быть перегружена типами, реализующими соответствующий интерфейс (RFC-011b)) |
|            | `+ -` сложение и вычитание                                                                                                                                                          |
|            | `== != < > <= >=` сравнение                                                                                                                                                         |
|            | `and or` логические операции                                                                                                                                                        |
| Наименьший | `=` присваивание                                                                                                                                                                    |

## Полный пример

```yaoxiang
use std.convert
use std.io

// 计算斐波那契数列
fib: (n: Int) -> Int = if n <= 1 {
    n
} else {
    fib(n - 1) + fib(n - 2)
}

// 主函数
main: () -> Void = {
    io.println("Fibonacci(10) = " + convert.to_string(fib(10)))
}
```
