## Встроенные типы

### Примитивные типы

| Тип      | Описание                              | Пример          |
| -------- | ------------------------------------- | --------------- |
| `Void`   | Пустое значение / отсутствие возврата | `()`            |
| `Bool`   | Логическое значение                   | `true`, `false` |
| `Int`    | Целое число                           | `42`, `-10`     |
| `Float`  | Число с плавающей точкой              | `3.14`, `-0.5`  |
| `Char`   | Символ                                | `'a'`, `'中'`   |
| `String` | Строка                                | `"hello"`       |

### Составные типы

| Тип                  | Описание                     | Пример         |
| -------------------- | ---------------------------- | -------------- |
| `Tuple(T1, T2, ...)` | Кортеж разнородных элементов | `(1, "hello")` |
| `(Args) -> Ret`      | Тип функции                  | `(Int) -> Int` |

> #299: Контейнерные типы (`List(T)` / `Array(T, N)` / `Dict(K, V)`) не являются встроенными
> примитивами — это конструкторы обобщённых типов, обрабатываемые наравне с пользовательскими
> дженериками через единый механизм инстанцирования. Синтаксис литералов (`[...]` / `{...}`)
> сохраняется в ядре; привязка определяется контекстным выводом. Set удалён (#300), подробности см.
> в [спецификации языка](language-spec/syntax.md).

### Пользовательские типы

```yaoxiang
// 记录类型（结构体）
Point: Type = { x: Float, y: Float }

// 枚举类型
Result: (T: Type, E: Type) -> Type = { ok: (T) -> Result(T, E), err: (E) -> Result(T, E) }

// 接口类型（所有字段为函数）
Callable: Type = { call: (String) -> Void }
```

## Встроенные функции

### Вывод

```yaoxiang
print(value)           // 打印，无换行
```


## Краткий справочник по синтаксису

### Объявление переменных

```yaoxiang
// 不可变变量（默认）
x: Int = 42
y = 42                 // 类型推断

// 可变变量
mut count: Int = 0
count = count + 1
```

### Определение функций

```yaoxiang
// 普通函数
add: (a: Int, b: Int) -> Int = a + b

// 并作函数（自动并发）
fetch: (url: String) -> JSON spawn = HTTP.get(url).json()

// 泛型函数
identity: [T](x: T) -> T = x
```

### Управление потоком

```yaoxiang
// 条件
if x > 0 {
    print("positive")
} else if x < 0 {
    print("negative")
} else {
    print("zero")
}

// 模式匹配
match result {
    ok(value) => print("success: " + value),
    err(error) => print("error: " + error),
}

// 循环
for i in 0..10 {
    print(i)
}
```

### Обработка ошибок

```yaoxiang
// ? 运算符传播错误
data = fetch_file(path)?
```

## Полный пример

```yaoxiang
// 计算斐波那契数列
fib: (n: Int) -> Int = if n <= 1 {
    n
} else {
    fib(n - 1) + fib(n - 2)
}

// 主函数
main: () -> Void = {
    print("Fibonacci(10) = " + fib(10).to_string())
}
```

1. Выберите модуль (например, `std.io`, `std.net`).
2. Реализуйте функции в `src/std/`.
3. Добавьте документационные комментарии.
4. Отправьте PR.
