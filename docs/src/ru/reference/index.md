## Встроенные типы

### Примитивные типы

| Тип      | Описание                       | Пример          |
| -------- | ------------------------------ | --------------- |
| `Void`   | Пустое значение / без возврата | `()`            |
| `Bool`   | Логическое значение            | `true`, `false` |
| `Int`    | Целое число                    | `42`, `-10`     |
| `Float`  | Число с плавающей точкой       | `3.14`, `-0.5`  |
| `Char`   | Символ                         | `'a'`, `'中'`   |
| `String` | Строка                         | `"hello"`       |

### Составные типы

| Тип                  | Описание                     | Пример         |
| -------------------- | ---------------------------- | -------------- |
| `Tuple(T1, T2, ...)` | Кортеж разнородных элементов | `(1, "hello")` |
| `(Args) -> Ret`      | Функциональный тип           | `(Int) -> Int` |

> #299: типы-контейнеры (`List(T)` / `Array(T, N)` / `Dict(K, V)`) не являются встроенными
> примитивами — это конструкторы обобщённых типов, которые рассматриваются наравне с
> пользовательскими дженериками и обрабатываются через единый путь инстанцирования дженериков.
> Литеральный синтаксис (`[...]` / `{...}`) остаётся в ядре; конкретный тип определяется контекстной
> аннотацией. Set удалён (#300), подробности см. в [Спецификации языка](language-spec/syntax.md).

### Пользовательские типы

```yaoxiang
// Тип записи (структура)
Point: Type = { x: Float, y: Float }

// Тип перечисления
Result: (T: Type, E: Type) -> Type = { ok: (T) -> Result(T, E), err: (E) -> Result(T, E) }

// Тип интерфейса (все поля — функции)
Callable: Type = { call: (String) -> Void }
```

## Встроенные функции

### Вывод

```yaoxiang
print(value)           // печать без перевода строки
println(value)         // печать с переводом строки
```

### Преобразование

```yaoxiang
to_string(value)       // преобразует в строку
to_int(value)          // преобразует в целое число
to_float(value)        // преобразует в число с плавающей точкой
```

### Проверка типов

```yaoxiang
typeof(value)         // возвращает имя типа
is_type(value, type)  // проверяет тип
```

## Краткий справочник по синтаксису

### Объявление переменных

```yaoxiang
// Неизменяемая переменная (по умолчанию)
x: Int = 42
y = 42                 // вывод типа

// Изменяемая переменная
mut count: Int = 0
count = count + 1
```

### Определение функций

```yaoxiang
// Обычная функция
add: (a: Int, b: Int) -> Int = a + b

// spawn-функция (автоматический параллелизм)
fetch: (url: String) -> JSON spawn = HTTP.get(url).json()

// Обобщённая функция
identity: [T](x: T) -> T = x
```

### Управление потоком

```yaoxiang
// Условие
if x > 0 {
    print("positive")
} else if x < 0 {
    print("negative")
} else {
    print("zero")
}

// Сопоставление с образцом
match result {
    ok(value) => print("success: " + value),
    err(error) => print("error: " + error),
}

// Цикл
for i in 0..10 {
    print(i)
}
```

### Обработка ошибок

```yaoxiang
// Оператор ? распространяет ошибку
data = fetch_file(path)?
```

## Полный пример

```yaoxiang
// Вычисление чисел Фибоначчи
fib: (n: Int) -> Int = if n <= 1 {
    n
} else {
    fib(n - 1) + fib(n - 2)
}

// Главная функция
main: () -> Void = {
    print("Fibonacci(10) = " + fib(10).to_string())
}
```
