# std.weak

Модуль слабых ссылок, используется совместно с `Arc` для разрыва циклических ссылок.

```yaoxiang
use std.weak
```

> Данный модуль зависит от атомарного подсчёта ссылок и **не экспортируется** на целевой платформе
> `wasm32`.

## Обзор функций

| --------- | -------------------------------------------- |
| `new`     | `(T: Type)(arc: Arc(T)) -> Weak(T)`          |

## Функции

### new

<!-- stdlib:sig:weak.new start -->

```yaoxiang
new: (T: Type)(arc: Arc(T)) -> Weak(T)
```

<!-- stdlib:sig:weak.new end -->

Создаёт слабую ссылку, соответствующую `Arc`.

- `arc` — значение с сильной ссылкой; передаётся по значению, после вызова **перемещается**.

Возвращает: дескриптор `Weak`, указывающий на тот же блок памяти, **не увеличивая** счётчик сильных
ссылок.

```yaoxiang
use std.assert
use std.weak

main = {
    // ref создаёт Arc[Int]
    p = ref 42

    // Arc → Weak регистрация
    w = weak.new(p)
    assert(true)
}
```

### upgrade

<!-- stdlib:sig:weak.upgrade start -->

```yaoxiang
upgrade: (T: Type)(weak: Weak(T)) -> Option(Arc(T))
```

<!-- stdlib:sig:weak.upgrade end -->

Пытается повысить слабую ссылку до сильной.

- `weak` — дескриптор слабой ссылки.

Возвращает: `Option.some(Arc)`, если блок памяти ещё жив, и `Option.none()`, если он уже освобождён.
**Не сигнализирует об ошибке** — `Option` используется для выражения факта «жив ли целевой объект».

```yaoxiang
use std.assert
use std.weak

main = {
    p = ref 42
    w = weak.new(p)

    // Цель жива: получаем вариант some
    u = weak.upgrade(w)
    assert(true)
}
```

> **Ограничение синтаксиса**: деструктуризация вариантов `Option` (вроде `match some(v)`) ещё не
> реализована, поэтому в настоящий момент можно лишь убедиться в успешности вызова, но нельзя
> выполнить ветвление по `some` / `none` в исходном коде. См. пояснения в
> `src/std/tests/weak_ops.yx`.

## Семантика

Слабая ссылка **не владеет** объектом: наличие `Weak` не препятствует освобождению целевого объекта.
Типичное применение — разрыв циклических ссылок: родительский узел хранит `Arc` на дочерний, а
дочерний хранит лишь `Weak` обратно на родительский, и цикл разрывается.
