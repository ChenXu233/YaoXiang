# std.assert

Модуль утверждений. Самый часто используемый инструмент в тестах и примерах.

```yaoxiang
use std.assert
```

## Функции

### assert

<!-- stdlib:sig:assert.assert start -->

```yaoxiang
assert: (cond: Bool, ?msg: String) -> Never
```

<!-- stdlib:sig:assert.assert end -->

Проверяет, что `cond` истинно.

- `cond` — булево выражение для проверки
- `msg` — необязательное сообщение, `?` означает, что его можно опустить; при невыполнении условия
  выводится вместе с диагностикой

Возврат: при выполнении условия возвращает `Void`, выполнение не прерывается. Ошибка: при ложном
условии выбрасывает `E6005` (сбой утверждения), программа завершается с ненулевым кодом.

```yaoxiang
use std.assert

main: () -> Void = {
    assert(1 > 0)
    assert(1 > 0, "这个字面断言必然成立")
}
```

Утверждения — **основной способ проверки в тестовом материале** — файлы `src/std/tests/*.yx` и
`tests/yaoxiang/**` работают так, что сбой `assert` приводит к ошибке процесса:

```yaoxiang
use std.assert
use std.list

main: () -> Void = {
    list.len([1, 2, 3]) == 3
    assert(list.len([1, 2, 3]) == 3, "len == 3")
}
```
