# std.assert

Модуль утверждений. Наиболее часто используемый инструмент в тестах и примерах.

```yaoxiang

```

## Функции

### assert

<!-- stdlib:sig:assert.assert start -->

```yaoxiang
assert: (cond: Bool, ?msg: String) -> Void
```

<!-- stdlib:sig:assert.assert end -->

Утверждает, что `cond` истинно.

- `cond` —— логическое выражение для проверки
- `msg` —— необязательное сообщение, `?` означает опциональность; выводится вместе с диагностикой при нарушении условия

Возвращает: `Void` при выполнении условия, без прерывания выполнения. Ошибка: при ложном условии выбрасывает
`E6005` (сбой утверждения), программа завершается с ненулевым кодом.

```yaoxiang
use std.assert

main: () -> Void = {
    assert(1 > 0)
    assert(1 > 0, "этот литерал утверждения всегда истинен")
}
```

Утверждения являются **основным средством проверки в тестовых корпусах** — `src/std/tests/*.yx` и `tests/yaoxiang/**` работают
по принципу: сбой `assert` приводит к ошибке процесса:

```yaoxiang
use std.assert
use std.list

main: () -> Void = {
    list.len([1, 2, 3]) == 3
    assert(list.len([1, 2, 3]) == 3, "len == 3")
}
```
