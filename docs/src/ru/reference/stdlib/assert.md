# std.assert

Модуль утверждений. Самый часто используемый инструмент в тестах и примерах.

```yaoxiang
use std.assert
```

## Функции

### assert

<!-- stdlib:sig:assert.assert start -->

```yaoxiang
assert: (cond: Bool, ?msg: String) -> Void
```

<!-- stdlib:sig:assert.assert end -->

Проверяет, что `cond` истинно.

- `cond` — проверяемое булево выражение
- `msg` — необязательное сообщение, `?` означает, что его можно опустить; выводится вместе с
  диагностикой при невыполнении условия

Возвращает: при выполнении условия возвращает `Void`, не прерывая выполнение. Ошибка: при ложном
условии выбрасывает `E6005` (ошибка утверждения), программа завершается с ненулевым кодом.

```yaoxiang
use std.assert

main: () -> Void = {
    assert(1 > 0)
    assert(1 > 0, "это утверждение заведомо верно")
}
```

Утверждения являются **основным средством проверки в тестовом материале** — `src/std/tests/*.yx` и
`tests/yaoxiang/**` работают так, что ошибка `assert` приводит к ошибке процесса:

```yaoxiang
use std.assert
use std.list

main: () -> Void = {
    list.len([1, 2, 3]) == 3
    assert(list.len([1, 2, 3]) == 3, "len == 3")
}
```
