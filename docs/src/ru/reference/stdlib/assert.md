# std.assert

Модуль утверждений. Самый часто используемый инструмент в тестах и примерах.

```yaoxiang
use std.assert
```

## Функции

### assert

<!-- stdlib:sig:assert.assert start -->

```yaoxiang
assert: (cond: Bool, ?msg: String) -> Void
```

<!-- stdlib:sig:assert.assert end -->

Утверждает, что `cond` истинно.

- `cond` — булево выражение для проверки
- `msg` — необязательное сообщение, `?` означает, что его можно опустить; выводится вместе с
  диагностикой, если условие не выполнено

Возвращает: при выполнении условия возвращает `Void`, не прерывая выполнение. Ошибка: при ложном
условии выбрасывает `E6005` (сбой утверждения), программа завершается с ненулевым кодом.

```yaoxiang
use std.assert

main = {
    assert(1 > 0)
    assert(1 > 0, "этот литеральный assert заведомо выполняется")
}
```

Утверждения — это **основной способ проверки в тестовых материалах** — `src/std/tests/*.yx` и
`tests/yaoxiang/**` работают по принципу: сбой `assert` приводит к ошибке процесса:

```yaoxiang
use std.assert
use std.list

main = {
    list.len([1, 2, 3]) == 3
    assert(list.len([1, 2, 3]) == 3, "len == 3")
}
```
