# Модель владения

YaoXiang не использует сборку мусора (GC) и не требует аннотаций времён жизни. Её безопасность
памяти построена на **пяти концепциях и одном градиенте**.

## Пять концепций, один градиент

```
看一眼/原地改     拿走           共享持有         复制一份        系统级
    │              │              │              │              │
   &T            Move           ref          clone()        unsafe
  &mut T         零拷贝        编译器自动      显式深拷贝      *T
  零大小令牌       默认          选Rc/Arc                   用户负责
```

## Move: передача владения по умолчанию

В YaoXiang **присваивание = передача владения**. Это поведение по умолчанию, с нулевым копированием:

```yaoxiang
p = Point(1.0, 2.0)
p2 = p              // Move! p 的所有权转给 p2
                    // 此后不能再读 p

// 想要修改 p2？用 mut
mut p3 = Point(3.0, 4.0)
shift(p3, 1.0, 1.0)    // 原地修改
```

Передача параметров в функцию и возврат значения также являются Move:

```yaoxiang
// 参数：Move 传入
process: (p: Point) -> Point = {
    p.transform()
    p                  // Move 返回——零拷贝
}

// 调用
p = Point(1.0, 2.0)
result = process(p)    // p 被 Move 走了
```

## &T / &mut T: токены заимствования

Если вы не хотите забирать владение, а лишь временно «взглянуть» (`&T`) или «изменить на месте»
(`&mut T`), компилятор автоматически сгенерирует **токен заимствования нулевого размера**:

```yaoxiang
data = [1, 2, 3, 4, 5]

// 编译器自动传 &List(Int) 令牌——不拿走所有权
print(data.len())    // 5
print(data)          // ✅ data 还在，只是看了一眼
```

`&T` и `&mut T` — это **типы нулевого размера**: они существуют на этапе компиляции и исчезают во
время выполнения. Вам не нужно писать `&` вручную — компилятор сам решает, что выбрать, исходя из
контекста использования:

```yaoxiang
// 只读访问 → 自动 &T
print: (point: &Point) -> Void = {
    print("({point.x}, {point.y})")
}

// 可变修改 → 自动 &mut T
shift: (point: &mut Point, dx: Float, dy: Float) -> Void = {
    point.x = point.x + dx
    point.y = point.y + dy
}

mut p = Point(1.0, 2.0)
print(p)                // 传入 &Point
shift(p, 1.0, 1.0)      // 传入 &mut Point
```

**Ключевое различие**: `&T` — копируемый (разделяемое чтение), а `&mut T` — некопируемый
(исключительная мутация). Это не особое правило — это два свойства типа.

## ref: разделяемое владение между областями видимости

Когда вам нужно **одновременно владеть** значением в нескольких местах, используйте `ref`:

```yaoxiang
data = [1, 2, 3, 4, 5]

// ref 创建共享持有
shared = ref data

// 编译器自动选择引用计数器：
// - 不跨任务 → Rc（单线程引用计数）
// - 跨任务 → Arc（原子引用计数）
spawn {
    use(shared)    // 跨任务！编译器自动用 Arc
}

// 你不需要知道 Rc 和 Arc 的区别
// 编译器自动帮你选
```

## clone(): явное глубокое копирование

Когда нужна независимая копия, явно вызовите `clone()`:

```yaoxiang
original = [1, 2, 3]
backup = original.clone()   // 深拷贝——拥有独立的副本

// 各自独立
original[0] = 10
print(backup[0])    // 1——不受影响
```

`clone()` — это явная операция: вы намеренно запрашиваете копирование, в отличие от некоторых
языков, где копирование происходит по умолчанию.

## Без времён жизни

В YaoXiang нет времён жизни `'a`. Это дизайнерское решение основано на ключевом наблюдении:

> Проблема конфликтов заимствования по сути эквивалентна верификации утверждений Хоара. Достаточно
> передать её единому конвейеру доказательств в проверке типов — никакого отдельного механизма
> проверки заимствований не требуется.

Вам не нужно аннотировать `'a` и не нужно разбираться во временах жизни — компилятор автоматически
проверяет безопасность владения на этапе проверки типов.

## Без GC

Во всей модели владения сборка мусора отсутствует. Момент освобождения всей памяти определяется на
этапе компиляции:

- **После Move** → исходная переменная становится недоступной, RAII автоматически освобождает память
- **После ref** → память освобождается, когда счётчик ссылок достигает нуля
- **При выходе из области видимости** → стековые переменные освобождаются автоматически

Никаких пауз GC, никаких накладных расходов во время выполнения.

## Резюме

| Операция             | Ключевое слово / синтаксис | Копирование            | Когда использовать                         |
| -------------------- | -------------------------- | ---------------------- | ------------------------------------------ |
| Забрать владение     | Поведение по умолчанию     | Нулевое копирование    | Передача параметров, присваивание          |
| Взглянуть            | Автоматически `&T`         | Токен нулевого размера | Доступ только для чтения                   |
| Изменить на месте    | Автоматически `&mut T`     | Токен нулевого размера | Изменяемая модификация                     |
| Разделяемое владение | `ref`                      | Подсчёт ссылок         | Между областями видимости / между задачами |
| Явное копирование    | `.clone()`                 | Глубокое копирование   | Нужна независимая копия                    |
| Сырой указатель      | `unsafe` + `*T`            | Вручную                | Системные операции                         |

**Запомните**: Move — по умолчанию, ref — разделяемое владение, clone — исключение. Три правила — и
можно навсегда забыть про GC.
