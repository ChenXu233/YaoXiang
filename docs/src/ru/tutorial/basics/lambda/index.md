# Лямбда-выражения

Лямбда-выражение — это **анонимная функция, которую можно определить на месте**. В YaoXiang обычные
функции по сути являются именованными лямбда-выражениями.

## Синтаксис

Согласно грамматической спецификации:

```
Lambda      ::= '(' ParamList? ')' '=>' Expr
            |  '(' ParamList? ')' '=>' Block
```

Простейшее лямбда-выражение:

```yaoxiang
// Лямбда-выражение в форме выражения
double = (x) => x * 2

print(double(5))   // 10
print(double(10))  // 20
```

## Унификация лямбда-выражений и функций

Ключевая философия дизайна YaoXiang — унификация синтаксиса. **Функция — это лямбда-выражение,
связанное с именем**:

```yaoxiang
// Оба варианта полностью эквивалентны:

// Вариант с лямбда-выражением
add = (a, b) => a + b

// Вариант с функцией (синтаксический сахар)
add: (a: Int, b: Int) -> Int = a + b
```

Первая строка — это «присваивание лямбда-выражения переменной `add`», вторая — «объявление функции с
именем `add`». Компилятор обрабатывает их почти одинаково.

## Когда использовать лямбда-выражения

Лямбда-выражения лучше всего подходят для двух сценариев:

### 1. Функции высшего порядка — передача функций как параметров

```yaoxiang
// Применить операцию к каждому элементу списка
apply_to_all: (list: List(Int), op: (Int) -> Int) -> List(Int) = {
    mut result = []
    for item in list {
        result.append(op(item))
    }
    return result
}

numbers = [1, 2, 3, 4, 5]

// Передача лямбда-выражения
doubled = apply_to_all(numbers, (x) => x * 2)
squared = apply_to_all(numbers, (x) => x * x)

print(doubled)  // [2, 4, 6, 8, 10]
print(squared)  // [1, 4, 9, 16, 25]
```

### 2. Временные одноразовые операции

Не нужно определять отдельную функцию для логики, используемой только один раз:

```yaoxiang
// Сортировка — временное определение правила сортировки
students = [
    {"name": "Alice", "score": 90},
    {"name": "Bob", "score": 85},
    {"name": "Charlie", "score": 92},
]

sorted_students = students.sort_by((a, b) => a["score"].compare(b["score"]))
```

## Лямбда-выражения в форме блока

Когда лямбда-выражению нужна многострочная логика, используется форма блока:

```yaoxiang
// Блочное лямбда-выражение: может содержать несколько операторов
process = (data) => {
    cleaned = data.trim()
    lower = cleaned.lowercase()
    return lower
}

result = process("  Hello World  ")
print(result)  // "hello world"
```

Обратите внимание: блочная форма требует использования `return` для возврата значения, что полностью
соответствует поведению функций.

## Лямбда-выражения с несколькими параметрами

```yaoxiang
// Три параметра
add_three = (x, y, z) => x + y + z
print(add_three(1, 2, 3))  // 6

// Лямбда-выражение без параметров
greet = () => "Hello, YaoXiang!"
print(greet())  // "Hello, YaoXiang!"
```

## Вывод типов

Типы параметров лямбда-выражения могут быть выведены из контекста:

```yaoxiang
// Тип выводится из места использования — не нужно писать (x: Int) => x * 2
apply: (op: (Int) -> Int, value: Int) -> Int = op(value)

result = apply((x) => x + 10, 5)
print(result)  // 15
```

Компилятор знает, что тип `op` — `(Int) -> Int`, поэтому `x` в лямбда-выражении `(x) => x + 10`
автоматически выводится как `Int`.

> **Примечание**: согласно правилам определения функций, типы параметров должны быть указаны хотя бы
> в одном месте — в сигнатуре или в заголовке лямбда-выражения. Когда лямбда-выражение передается
> как параметр, тип обычно предоставляется сигнатурой вызывающей стороны.

## Резюме

| Пункт                   | Описание                                             |
| ----------------------- | ---------------------------------------------------- |
| Синтаксис               | `(params) => expr` или `(params) => { return ... }`  |
| Сущность                | Функция = именованное лямбда-выражение               |
| Функции высшего порядка | Лямбда-выражения можно передавать как параметры      |
| Блочная форма           | Многострочная логика через `{}` + `return`           |
| Вывод типов             | Типы параметров автоматически выводятся из контекста |

Лямбда-выражения — самый лаконичный способ выразить «временную логику» в YaoXiang. Освоив их, ваш
код станет более гибким и компактным.
