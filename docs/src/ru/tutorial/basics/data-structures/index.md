# Списки и словари

Структуры данных — это скелет программы. Коллекции в YaoXiang строятся послойно: `Vec(T)` — это
низкоуровневый буфер с длиной, определяемой в runtime, `List(T)` — тип стандартной библиотеки
(`{ data: Vec(T), length: Int }`), а словари основаны на том же послойном механизме. Пользователи
также могут определять собственные типы контейнеров — после реализации интерфейса `Index` (RFC-011b)
для них также поддерживается доступ через `[]`.

## Списки

Список — это **упорядоченная** последовательность значений, причём все элементы имеют один тип. Для
создания используется `[]`:

```yaoxiang
// Создание списков
numbers = [1, 2, 3, 4, 5]
names = ["Alice", "Bob", "Charlie"]
empty: List(Int) = []       // пустой список требует аннотации типа
```

### Доступ по индексу

Для доступа к элементу по позиции используется `[]`, индексация начинается с 0:

```yaoxiang
scores = [95, 87, 73, 91]

first = scores[0]    // 95
second = scores[1]   // 87
last = scores[3]     // 91
```

### Часто используемые операции

```yaoxiang
mut items = [1, 2, 3]

// Добавление элемента
items.append(4)       // [1, 2, 3, 4]

// Длина
count = items.len()   // 4

// Срез
slice = items[0..2]   // [1, 2]
```

### Генераторы списков

Генератор списков — мощный инструмент для создания новых списков на основе уже существующих:

```yaoxiang
// Простой генератор
squares = [x * x for x in [1, 2, 3, 4, 5]]
print(squares)  // [1, 4, 9, 16, 25]

// Генератор с условием фильтрации
evens = [x for x in [1, 2, 3, 4, 5, 6] if x % 2 == 0]
print(evens)  // [2, 4, 6]

// Преобразование типов
names = ["Alice", "Bob", "Charlie"]
lengths = [n.len() for n in names]
print(lengths)  // [5, 3, 7]
```

Синтаксис: `[выражение for переменная in список if условие]` — часть `if условие` является
необязательной.

## Словари

Словарь — это коллекция **пар ключ-значение**, где ключи — строки, а значения могут быть любого
типа. Для создания используется `{}`:

```yaoxiang
// Создание словарей
scores = {"Alice": 90, "Bob": 85, "Charlie": 92}
empty: Dict(Int) = {}          // пустой словарь требует аннотации типа
```

### Доступ по ключу

Для доступа к значению по ключу используется `[]`:

```yaoxiang
scores = {"Alice": 90, "Bob": 85}

alice = scores["Alice"]   // 90
bob = scores["Bob"]       // 85
```

### Изменение словаря

```yaoxiang
mut data = {"name": "Alice"}

// Добавление/обновление пары ключ-значение
data["age"] = 25
data["name"] = "Bob"

print(data)  // {"name": "Bob", "age": 25}
```

### Проверка наличия ключа

Для проверки наличия ключа используется `in`:

```yaoxiang
config = {"host": "localhost", "port": "8080"}

has_host = "host" in config    // true
has_user = "user" in config    // false
```

## Итоги

| Тип     | Синтаксис   | Упорядочен? | Допускает дубли? | Тип ключа            |
| ------- | ----------- | ----------- | ---------------- | -------------------- |
| Список  | `[1, 2, 3]` | ✅          | ✅               | целочисленный индекс |
| Словарь | `{"a": 1}`  | ✅          | ключи уникальны  | String               |

Список — ваш основной контейнер, а словарь хорошо подходит для поиска по ключу.
