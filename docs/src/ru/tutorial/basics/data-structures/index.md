# Списки и словари

Структуры данных — это скелет программы. YaoXiang предоставляет два встроенных типа коллекций:
списки и словари.

## Списки

Список — это **упорядоченная** последовательность значений, все элементы имеют одинаковый тип.
Создаётся с помощью `[]`:

```yaoxiang
// Создание списка
numbers = [1, 2, 3, 4, 5]
names = ["Alice", "Bob", "Charlie"]
empty: List(Int) = []       // Пустой список требует аннотации типа
```

### Доступ по индексу

Доступ к элементам по позиции осуществляется с помощью `[]`, индекс начинается с 0:

```yaoxiang
scores = [95, 87, 73, 91]

first = scores[0]    // 95
second = scores[1]   // 87
last = scores[3]     // 91
```

### Основные операции

```yaoxiang
mut items = [1, 2, 3]

// Добавление элемента
items.append(4)       // [1, 2, 3, 4]

// Длина
count = items.len()   // 4

// Срез
slice = items[0..2]   // [1, 2]
```

### List comprehension

List comprehension — мощный инструмент создания списков, позволяющий генерировать новый список из
существующего:

```yaoxiang
// Базовый генератор
squares = [x * x for x in [1, 2, 3, 4, 5]]
print(squares)  // [1, 4, 9, 16, 25]

// Генератор с фильтром
evens = [x for x in [1, 2, 3, 4, 5, 6] if x % 2 == 0]
print(evens)  // [2, 4, 6]

// Преобразование типов
names = ["Alice", "Bob", "Charlie"]
lengths = [n.len() for n in names]
print(lengths)  // [5, 3, 7]
```

Синтаксис: `[выражение for переменная in список if условие]` — часть `if условие` необязательна.

## Словари

Словарь — это коллекция **пар ключ-значение**, ключи являются строками, значения могут быть любого
типа. Создаётся с помощью `{}`:

```yaoxiang
// Создание словаря
scores = {"Alice": 90, "Bob": 85, "Charlie": 92}
empty: Dict(Int) = {}          // Пустой словарь требует аннотации типа
```

### Доступ по ключу

Доступ к значениям осуществляется с помощью `[]` по ключу:

```yaoxiang
scores = {"Alice": 90, "Bob": 85}

alice = scores["Alice"]   // 90
bob = scores["Bob"]       // 85
```

### Изменение словаря

```yaoxiang
mut data = {"name": "Alice"}

// Добавление/обновление пары ключ-значение
data["age"] = 25
data["name"] = "Bob"

print(data)  // {"name": "Bob", "age": 25}
```

### Проверка наличия

Проверка существования ключа с помощью `in`:

```yaoxiang
config = {"host": "localhost", "port": "8080"}

has_host = "host" in config    // true
has_user = "user" in config    // false
```

## Итоги

| Тип     | Синтаксис   | Упорядоченный? | Дубликаты?      | Тип ключа            |
| ------- | ----------- | -------------- | --------------- | -------------------- |
| Список  | `[1, 2, 3]` | ✅             | ✅              | Целочисленный индекс |
| Словарь | `{"a": 1}`  | ✅             | Ключи уникальны | String               |

Списки — ваш основной контейнер, словари подходят для поиска по ключу.
