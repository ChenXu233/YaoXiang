# Списки и словари

Структуры данных — это скелет программы. YaoXiang предоставляет два встроенных типа коллекций:
списки и словари.

## Список

Список — это **упорядоченная** последовательность значений одного типа. Создаётся с помощью `[]`:

```yaoxiang
// 创建列表
numbers = [1, 2, 3, 4, 5]
names = ["Alice", "Bob", "Charlie"]
empty: List(Int) = []       // 空列表需要类型注解
```

### Доступ по индексу

Используйте `[]` для доступа к элементу по позиции, индекс начинается с 0:

```yaoxiang
scores = [95, 87, 73, 91]

first = scores[0]    // 95
second = scores[1]   // 87
last = scores[3]     // 91
```

### Основные операции

```yaoxiang
mut items = [1, 2, 3]

// 添加元素
items.append(4)       // [1, 2, 3, 4]

// 长度
count = items.len()   // 4

// 切片
slice = items[0..2]   // [1, 2]
```

### Генератор списков

Генератор списков — это мощный инструмент для создания списков — генерация нового списка из
существующего:

```yaoxiang
// 基本推导式
squares = [x * x for x in [1, 2, 3, 4, 5]]
print(squares)  // [1, 4, 9, 16, 25]

// 带过滤条件的推导式
evens = [x for x in [1, 2, 3, 4, 5, 6] if x % 2 == 0]
print(evens)  // [2, 4, 6]

// 转换类型
names = ["Alice", "Bob", "Charlie"]
lengths = [n.len() for n in names]
print(lengths)  // [5, 3, 7]
```

Синтаксис: `[выражение for переменная in список if условие]` — часть `if условие` необязательна.

## Словарь

Словарь — это коллекция **пар ключ-значение**, где ключи являются строками, а значения могут быть
любого типа. Создаётся с помощью `{}`:

```yaoxiang
// 创建字典
scores = {"Alice": 90, "Bob": 85, "Charlie": 92}
empty: Dict(Int) = {}          // 空字典需要类型注解
```

### Доступ по ключу

Используйте `[]` для доступа к значению по ключу:

```yaoxiang
scores = {"Alice": 90, "Bob": 85}

alice = scores["Alice"]   // 90
bob = scores["Bob"]       // 85
```

### Изменение словаря

```yaoxiang
mut data = {"name": "Alice"}

// 添加/更新键值
data["age"] = 25
data["name"] = "Bob"

print(data)  // {"name": "Bob", "age": 25}
```

### Проверка наличия элемента

Используйте `in` для проверки наличия ключа:

```yaoxiang
config = {"host": "localhost", "port": "8080"}

has_host = "host" in config    // true
has_user = "user" in config    // false
```

## Резюме

| Тип     | Синтаксис   | Упорядочен? | Допускает дубликаты? | Тип ключа            |
| ------- | ----------- | ----------- | -------------------- | -------------------- |
| Список  | `[1, 2, 3]` | ✅          | ✅                   | Целочисленный индекс |
| Словарь | `{"a": 1}`  | ✅          | Ключи уникальны      | String               |

Список — ваш основной контейнер, словарь подходит для поиска по ключу.
