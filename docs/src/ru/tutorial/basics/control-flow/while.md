# Цикл while

`for` подходит для сценариев «обхода известной коллекции», тогда как `while` подходит для другой
ситуации — **вы не знаете, сколько раз нужно повторять, но знаете, когда нужно остановиться**.

## Базовый синтаксис

Определение оператора `while` в спецификации синтаксиса:

```
while Expr Block
```

Структура проста: после `while` идёт условное выражение, затем блок кода тела цикла. Пока условие
`true`, тело цикла продолжает выполняться.

```yaoxiang
mut count = 1

while count <= 5 {
    print(count)
    count = count + 1
}
// Вывод: 1 2 3 4 5
```

Обратите внимание, что мы объявляем переменную `mut count` — потому что `count` нужно изменять в
цикле. Если написать `count = 1` (неизменяемую), то `count = count + 1` в теле цикла вызовет ошибку.

## Поток выполнения `while`

Шаги выполнения цикла `while` следующие:

1. Проверить условное выражение
2. Если условие `true`, выполнить тело цикла, затем вернуться к шагу 1
3. Если условие `false`, завершить цикл и продолжить выполнение последующего кода

Условие проверяется **перед началом каждой итерации**. Если условие с самого начала `false`, тело
цикла не выполнится ни разу:

```yaoxiang
mut n = 0
while n > 0 {
    print("эта строка никогда не будет напечатана")
    n = n - 1
}
// Условие n > 0 с самого начала false, тело цикла сразу пропускается
```

## break: досрочный выход из цикла

Иногда вам нужно выйти из цикла преждевременно — например, когда найден искомый объект:

```yaoxiang
numbers = [3, 7, 2, 9, 5]
mut found = false
mut index = 0

while index < 5 {
    if numbers[index] == 9 {
        found = true
        break      // Найдено, нет необходимости продолжать поиск
    }
    index = index + 1
}

print("Нашли? " + found.to_string())  // "Нашли? true"
```

`break` заставляет программу немедленно выйти из текущего цикла и продолжить выполнение кода после
цикла.

## continue: пропуск текущей итерации

`continue` отличается от `break` — он не выходит из цикла, а пропускает оставшуюся часть текущей
итерации и сразу переходит к следующей проверке условия:

```yaoxiang
mut n = 0
while n < 5 {
    n = n + 1
    if n == 3 {
        continue   // Пропускает 3, не печатает
    }
    print(n)
}
// Вывод: 1 2 4 5
```

В этом коде, когда `n` равно 3, `continue` пропускает `print(n)` и сразу возвращается к
`while n < 5` для проверки условия.

## Как избежать бесконечных циклов

При использовании `while` нужно быть особенно внимательным — убедитесь, что условие цикла в конечном
итоге станет `false`, иначе программа зависнет навсегда:

```yaoxiang
// Опасно! Бесконечный цикл — условие всегда true
// mut x = 1
// while x > 0 {
//     x = x + 1     // x становится всё больше и больше, никогда не будет <= 0
// }

// Правильно — есть чёткое условие завершения
mut x = 1
while x <= 5 {
    print(x)
    x = x + 1        // x постепенно увеличивается, и когда x > 5, цикл завершается
}
```

## Использование `while` для чтения ввода

Классический сценарий использования `while` — обработка ввода неопределённой длины: вы не знаете,
сколько раз пользователь будет вводить данные, знаете только «остановиться, когда ввод пуст»:

```yaoxiang
// Пример псевдокода — демонстрация типичного использования while
// read_line возвращает пустую строку при чтении пустой строки
mut line = read_line()
while line != "" {
    process(line)
    line = read_line()
}
```

Этот шаблон «проверка условия → обработка данных → обновление условия» — основной шаблон
использования `while`.

## Резюме

| Ключевой момент     | Описание                                                                             |
| ------------------- | ------------------------------------------------------------------------------------ |
| Подходящий сценарий | Не знаете количество итераций, знаете только условие завершения                      |
| Синтаксис           | `while условие { ... }`                                                              |
| Поток выполнения    | Сначала проверяется условие, затем выполняется тело цикла                            |
| `break`             | Немедленный выход из цикла                                                           |
| `continue`          | Пропуск текущей итерации, возврат к проверке условия                                 |
| Примечания          | Убедитесь, что условие в конечном итоге станет `false`, избегайте бесконечных циклов |
