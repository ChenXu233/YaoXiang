# Поток управления

В предыдущей главе вы научились определять функции. Теперь давайте узнаем, как наделить код
способностью «принимать решения» и «повторять выполнение» — именно для этого существует **поток
управления**.

YaoXiang предоставляет пять структур управления потоком, каждая из которых выполняет свою задачу:

| Структура            | Назначение               | Краткое описание                               |
| -------------------- | ------------------------ | ---------------------------------------------- |
| `if-else-if-else`    | Условное ветвление       | Выбор пути выполнения по условию               |
| `for`                | Цикл обхода              | Последовательная обработка элементов коллекции |
| `while`              | Условный цикл            | Повторение, пока условие истинно               |
| `break` / `continue` | Управление циклом        | Досрочный выход или пропуск текущей итерации   |
| `match`              | Сопоставление с образцом | Ветвление по структуре значения                |

Краткий обзор:

```yaoxiang
// if — это выражение, возвращающее значение
status = if score >= 60 { "及格" } else { "不及格" }

// for — обход диапазона
for i in 0..5 {
    print(i)
}

// while — условный цикл
mut n = 3
while n > 0 {
    print(n)
    n = n - 1
}

// match — сопоставление с образцом
description = match number {
    0 => "零",
    1 => "一",
    _ => "其他",
}
```

Все эти структуры управления потоком могут использоваться как **выражения** — они способны вычислять
значение. Это важное отличие YaoXiang от многих традиционных языков.

В следующих разделах каждая структура потока управления будет рассмотрена подробно. Рекомендуется
читать их по порядку, поскольку между ними существует естественная последовательность.
