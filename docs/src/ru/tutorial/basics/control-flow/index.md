# Управление потоком

В предыдущей главе вы научились определять функции. Теперь мы изучим, как наделить код способностью
«принимать решения» и «повторно выполняться» — это и есть **управление потоком**.

YaoXiang предоставляет пять конструкций управления потоком, каждая со своим назначением:

| Управление потоком   | Назначение               | Краткое описание                     |
| -------------------- | ------------------------ | ------------------------------------ |
| `if-else-if-else`    | Условия                  | Выбор пути выполнения по условию     |
| `for`                | Итерация                 | Обработка каждого элемента коллекции |
| `while`              | Условный цикл            | Повторение, пока условие истинно     |
| `break` / `continue` | Управление циклом        | Досрочный выход или пропуск итерации |
| `match`              | Сопоставление с образцом | Ветвление по структуре значения      |

Быстрый пример:

```yaoxiang
// if является выражением, может возвращать значение
status = if score >= 60 { "прошёл" } else { "не прошёл" }

// for обходит диапазон
for i in 0..5 {
    print(i)
}

// while условный цикл
mut n = 3
while n > 0 {
    print(n)
    n = n - 1
}

// match сопоставление с образцом
description = match number {
    0 => "ноль",
    1 => "один",
    _ => "другое",
}
```

Все эти конструкции управления потоком могут использоваться как **выражения** — они могут вычислять
значение. Это важное отличие YaoXiang от многих традиционных языков.

В следующих главах мы подробно рассмотрим каждый тип управления потоком. Рекомендуется читать их по
порядку, поскольку между ними существует естественная прогрессия.
