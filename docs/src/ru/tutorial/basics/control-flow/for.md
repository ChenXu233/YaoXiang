# Цикл for

Когда вам нужно выполнить одно и то же действие с каждым элементом последовательности, цикл `for` —
это правильный инструмент. Цикл `for` в YaoXiang спроектирован просто и точно.

## Базовый синтаксис

Формальное определение оператора `for` в спецификации синтаксиса:

```
for 'mut'? Identifier 'in' Expr Block
```

Если перевести: начинается с `for`, может иметь необязательный `mut`, затем идёт имя переменной
цикла, потом `in` и выражение для обхода, и в конце — блок кода тела цикла.

## Обход числового диапазона

Самый распространённый способ — создать диапазон с помощью `..`, а затем обойти его через `for`:

```yaoxiang
// 从 0 到 4（不包括 5）
for i in 0..5 {
    print(i)
}
// 输出：0 1 2 3 4
```

`0..5` обозначает диапазон от 0 включительно до 5 не включительно. Это общепринятое соглашение в
области компьютерных наук — полуоткрытый интервал [a, b).

Вы также можете использовать переменные для определения начала и конца диапазона:

```yaoxiang
start = 10
end = 15
for n in start..end {
    print(n)
}
// 输出：10 11 12 13 14
```

## Обход списка

`for` может не только обходить числовые диапазоны, но и напрямую перебирать коллекции, такие как
списки, массивы и т.д.:

```yaoxiang
colors = ["红", "橙", "黄", "绿", "蓝"]

for color in colors {
    print("当前颜色: " + color)
}
// 输出：
// 当前颜色: 红
// 当前颜色: 橙
// ... 依此类推
```

## Уникальная семантика for: новое связывание на каждой итерации

Цикл `for` в YaoXiang имеет дизайн, отличный от других языков: **каждая итерация создаёт новое
связывание, а не изменяет одну и ту же переменную**.

Чтобы понять, рассмотрим таблицу:

| Итерация    | Что происходит                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------ |
| 1-я         | Создаётся новое связывание `i = 0`, выполняется тело цикла, затем связывание уничтожается              |
| 2-я         | Создаётся новое связывание `i = 1` (совершенно новое связывание), выполняется тело, затем уничтожается |
| 3-я         | Создаётся новое связывание `i = 2`, выполняется тело цикла, затем уничтожается                         |
| ...         | ...                                                                                                    |
| Конец цикла | Диапазон исчерпан, цикл завершается                                                                    |

Это означает, что переменная цикла на каждой итерации представляет собой независимое новое значение.
Это очень полезно для безопасности — вам не нужно беспокоиться о случайном изменении переменной
цикла:

```yaoxiang
for i in 1..5 {
    // i = i + 1   // 错误：默认不可变，不能修改 i
    print(i)
}
```

## for mut: явное объявление при необходимости изменения

Если вам действительно нужно изменить переменную цикла внутри тела цикла (например, в качестве
аккумулятора), используйте `for mut`:

```yaoxiang
// 用 for mut 允许在循环体内修改绑定
for mut i in 0..5 {
    i = i * 2
    print(i)
}
// 输出：0 2 4 6 8
```

Обратите внимание: даже при использовании `for mut`, каждая итерация по-прежнему является новым
связыванием. `for mut` лишь делает само новое связывание изменяемым и не переносит изменения
предыдущей итерации в следующую.

```yaoxiang
for mut i in 1..5 {
    i = i + 100
    print(i)        // 每次都打印 101, 102, 103, 104
}
// 每次迭代 i 都从范围值重新开始，上一次的修改不影响下一次
```

## Переменная цикла не может затенять внешнюю переменную

YaoXiang запрещает затенение переменных. Переменная цикла `for` не может иметь то же имя, что и
переменная во внешней области видимости:

```yaoxiang
// 错误示范
i = 10
// for i in 1..5 {     // 编译错误！i 已经在外层声明
//     print(i)
// }

// 正确写法——换个名字
i = 10
for j in 1..5 {
    print(j)
}
```

Это правило гарантирует, что вы никогда не запутаетесь в том, на какую именно переменную ссылается
текущий код.

## Сравнение с другими языками

| Язык     | Семантика переменной цикла for                        |
| -------- | ----------------------------------------------------- |
| YaoXiang | Новое связывание на каждой итерации                   |
| Rust     | Изменение одной и той же переменной (требуется `mut`) |
| Python   | Изменение одной и той же переменной                   |
| C/C++    | Изменение одной и той же переменной                   |

Дизайн YaoXiang ближе к человеческой интуиции — «для каждого элемента в коллекции выполнить что-то»
— каждый элемент является независимой сущностью.

## Резюме

| Пункт                       | Описание                                                                       |
| --------------------------- | ------------------------------------------------------------------------------ |
| Обход диапазона             | `for i in 0..5`, полуоткрытый интервал                                         |
| Обход коллекции             | `for item in list`, поэлементное извлечение                                    |
| Семантика связывания        | Новое связывание на каждой итерации, а не изменение одной переменной           |
| Неизменяемость по умолчанию | Переменная цикла не может быть изменена, что предотвращает случайные изменения |
| `for mut`                   | Явное объявление при необходимости изменения                                   |
| Запрет затенения            | Переменная цикла не может иметь то же имя, что и внешняя переменная            |
