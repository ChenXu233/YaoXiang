# Основы match

`match` — это наиболее мощная управляющая конструкция в YaoXiang. Она позволяет выбрать различные пути обработки в зависимости от **формы** значения. Если вы использовали `switch` в других языках, вы обнаружите, что `match` — это его значительно улучшенная версия.

## Базовый синтаксис

Определение выражения `match` в грамматике языка:

```
match Expr { MatchArm+ }
MatchArm : Pattern ('|' Pattern)* ('if' Expr)? '=>' Expr ','
```

Разберём по частям:

- после `match` следует значение для сопоставления
- в `{}` содержится одна или несколько **ветвей сопоставления** (MatchArm)
- каждая ветвь: **паттерн** затем `=>`, затем **выражение-результат**
- каждая ветвь завершается запятой

Простейший пример:

```yaoxiang
number = 2

text = match number {
    0 => "ноль",
    1 => "один",
    2 => "два",
}
print(text)  // "два"
```

## match — это выражение

Как и `if`, `match` является **выражением** — оно вычисляет значение. Типы возвращаемых значений всех ветвей должны совпадать:

```yaoxiang
score = 85

grade = match score {
    90..100 => "A",    // диапазонный паттерн (продвинутая тема)
    80..89 => "B",
    70..79 => "C",
    60..69 => "D",
    _ => "F",          // подстановочный знак: все остальные случаи
}
print(grade)  // "B"
```

> **Примечание**: диапазонные паттерны вроде `90..100` относятся к продвинутым темам и подробно рассматриваются в разделе [Продвинутое сопоставление с образцом](../pattern-matching/index.md). В этой главе мы сосредоточимся на базовых паттернах.

## Базовые паттерны

### Литеральные паттерны

Сопоставление с конкретными значениями:

```yaoxiang
response = 404

message = match response {
    200 => "OK",
    301 => "Moved",
    404 => "Not Found",
    500 => "Server Error",
    _ => "Unknown",
}
print(message)  // "Not Found"
```

### Идентификаторные паттерны

Использование имён переменных для захвата сопоставленного значения:

```yaoxiang
result: Result(Int, String) = ok(42)

description = match result {
    ok(value) => "Успех, значение: " + value.to_string(),
    err(error) => "Ошибка, причина: " + error,
}
print(description)  // "Успех, значение: 42"
```

`value` в `ok(value)` — это идентификаторный паттерн, который захватывает фактическое значение внутри `ok`. Вы можете использовать его в выражении после `=>`.

### Подстановочный паттерн

`_` — это подстановочный знак, который соответствует **любому значению**. Обычно его помещают в конец как запасной вариант:

```yaoxiang
command = "exit"

action = match command {
    "start" => "Запуск сервиса",
    "stop" => "Остановка сервиса",
    "restart" => "Перезапуск сервиса",
    _ => "Неизвестная команда: " + command,
}
print(action)  // "Неизвестная команда: exit"
```

## Сопоставление должно быть исчерпывающим

`match` в YaoXiang требует покрытия всех возможных случаев — если компилятор обнаружит, что вы пропустили какие-то возможные значения, он выдаст ошибку. Это проявление безопасности `match`.

```yaoxiang
// Этот код не скомпилируется
// value = true
// result = match value {
//     true => "Да",
//     // отсутствует ветвь false — ошибка компиляции!
// }

// Правильно — используем _ как запасной вариант
value = true
result = match value {
    true => "Да",
    _ => "Нет",      // _ гарантирует обработку false
}
```

Когда вы точно знаете, что существует ограниченное количество вариантов (например, при сопоставлении перечислений), компилятор поможет проверить, покрыт ли каждый вариант. Это мощный инструмент против ошибок, связанных с пропущенными ветвями.

## Комбинация нескольких паттернов

Одна ветвь сопоставления может соответствовать нескольким паттернам, разделённым `|`:

```yaoxiang
day = "sunday"

type = match day {
    "monday" | "tuesday" | "wednesday" | "thursday" | "friday" => "Будний день",
    "saturday" | "sunday" => "Выходной",
    _ => "Недействительный",
}
print(type)  // "Выходной"
```

## Ветви сопоставления выполняются по порядку

`match` начинает попытки сопоставления с первой ветви, и **первая успешно сопоставленная ветвь срабатывает** — остальные не выполняются:

```yaoxiang
number = 5

result = match number {
    _ => "Другое",     // подстановочный знак соответствует всему, здесь будет сопоставление
    5 => "Пять",       // никогда не выполнится — уже сопоставлено выше
}
print(result)  // "Другое"
```

Эта особенность означает, что **размещение подстановочного знака `_` в конце** — хорошая практика.

## Итоги

| Пункт         | Описание                                           |
| ------------- | -------------------------------------------------- |
| Синтаксис     | `match значение { паттерн => выражение, ... }`    |
| Выражение     | `match` вычисляет значение, все ветви одного типа |
| Литеральный   | Точное соответствие значению: `200 => "OK"`        |
| Идентификатор | Захват значения в переменную: `ok(value) => ...`  |
| Подстановочный| Соответствует любому значению, как запасной вариант|
| Исчерпывающесть| Должно покрывать все возможности, компилятор проверяет |
| Несколько паттернов | `паттерн1 \| паттерн2 => выражение`      |
| Порядок выполнения | Сверху вниз, первое сопоставление побеждает  |

> **Следующий шаг**: в этой статье рассмотрены базовые возможности `match`. Более продвинутые паттерны (вложенные паттерны, охранные выражения, деструктуризация структоров и т.д.) описаны в разделе [Продвинутое сопоставление с образцом](../pattern-matching/index.md).
