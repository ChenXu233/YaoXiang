# if-else-if-else

`if-else-if-else` — это самый базовый инструмент принятия решений в программировании. Его логика
очень интуитивна: **если условие выполняется, выполняется определённый блок кода; иначе проверяется
следующее условие; если ни одно не выполнено — выбирается путь по умолчанию**.

## Базовый синтаксис

Определения выражения `if` и инструкции `if` в спецификации синтаксиса полностью идентичны:

```
if Expr Block ('else' 'if' Expr Block)* ('else' Block)?
```

Переводя на обычный язык: начинается с `if`, за которым следует условное выражение и блок кода,
после чего может идти от нуля до нескольких конструкций `else if условие блок`, и в конце —
необязательный `else блок`.

Самая простая форма — только `if`:

```yaoxiang
if temperature > 30 {
    print("天热了，开空调吧")
}
```

Добавляем `else`:

```yaoxiang
if is_raining {
    print("带伞")
} else {
    print("不用带伞")
}
```

Несколько условий через `else if`:

```yaoxiang
score = 85

if score >= 90 {
    print("优秀")
} else if score >= 80 {
    print("良好")
} else if score >= 60 {
    print("及格")
} else {
    print("需要努力")
}
```

## if как выражение

Это одна из самых важных особенностей потока управления в YaoXiang: **`if` может использоваться как
выражение, вычисляющее значение**.

```yaoxiang
// if 表达式：各分支的值会赋给 result
result = if x > 0 {
    "正数"
} else if x < 0 {
    "负数"
} else {
    "零"
}
// result 现在是 "正数"、"负数" 或 "零" 中的一个
```

Когда `if` используется как выражение, типы возвращаемых значений всех ветвей должны совпадать:

```yaoxiang
score = 88

// 所有分支都返回 String，类型一致，没问题
grade = if score >= 90 {
    "A"
} else if score >= 80 {
    "B"
} else if score >= 60 {
    "C"
} else {
    "D"
}
print(grade)  // "B"
```

В блоке кода каждой ветви **значение последнего выражения является возвращаемым значением этой
ветви**. Можно также явно использовать `return`, но в ветвях обычно достаточно просто написать
выражение.

```yaoxiang
// 直接写表达式——推荐
category = if age < 18 { "未成年" } else { "成年" }

// 也可以显式 return——效果相同
category = if age < 18 {
    return "未成年"
} else {
    return "成年"
}
```

Если вы используете `if` только для проверки условий и вам не нужно значение, это обычная инструкция
— она полностью совместима с формой выражения.

## Вложенный if

Внутри `if` можно написать ещё один `if`, чтобы обрабатывать многоуровневые условные проверки:

```yaoxiang
age = 25
has_ticket = true

if age >= 18 {
    if has_ticket {
        print("欢迎入场")
    } else {
        print("请先购票")
    }
} else {
    print("未成年人需家长陪同")
}
```

При вложении выражений в YaoXiang нет неоднозначности «висящего else», как в языке C — каждый `else`
всегда относится к ближайшему непарному `if`.

## Комбинирование условий с логическими операторами

В условиях можно использовать `and`, `or`, `not` для объединения нескольких проверок:

```yaoxiang
username = "admin"
password = "123456"

// and：两个条件都成立
if username == "admin" and password == "123456" {
    print("登录成功")
}

// or：任一条件成立
if role == "admin" or role == "moderator" {
    print("有管理权限")
}

// not：取反
if not is_banned {
    print("允许发言")
}

// 组合使用
if (age >= 18 and age <= 60) or is_vip {
    print("可以参加活动")
}
```

По приоритету операторов `not` выше, чем `and`, а `and` выше, чем `or`. Если сомневаетесь — ставьте
скобки, чтобы намерение было яснее.

## Итоги

| Пункт                       | Описание                                                                     |
| --------------------------- | ---------------------------------------------------------------------------- |
| Базовая структура           | `if условие { ... } else if условие { ... } else { ... }`                    |
| else if                     | В YaoXiang для многовариантного ветвления используется `else if`             |
| Выражение                   | `if` может возвращать значение, типы всех ветвей должны совпадать            |
| Возвращаемое значение ветви | Значение последнего выражения в блоке ветви является возвращаемым значением  |
| Вложенность                 | Внутри `if` можно написать ещё один `if`, нет неоднозначности с висящим else |
| Логические операции         | `and`, `or`, `not` для комбинирования условий                                |
