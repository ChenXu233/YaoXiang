# F-строка

f-строка — это **шаблонная строка** в YaoXiang. Вы можете напрямую встраивать переменные и выражения в строку, а компилятор автоматически выполнит преобразование типов и конкатенацию.

## Основы использования

Добавьте префикс `f` перед строкой и используйте `{выражение}` для подстановки значений:

```yaoxiang
name = "Alice"
age = 25

greeting = f"Hello {name}, you are {age} years old"
print(greeting)  // Hello Alice, you are 25 years old
```

Сравнение с традиционным способом конкатенации наглядно демонстрирует преимущества f-строки:

```yaoxiang
// ❌ Традиционная конкатенация: многословно и подвержено ошибкам
message = "Hello ".concat(name).concat(", age: ").concat(age.to_string())

// ✅ f-строка: наглядно и кратко
message = f"Hello {name}, age: {age}"
```

## Интерполяция выражений

Внутри `{}` можно использовать не только переменные — допускаются любые выражения:

```yaoxiang
x = 10
y = 20

print(f"Sum: {x + y}")         // Sum: 30
print(f"Product: {x * y}")     // Product: 200
print(f"Is positive? {x > 0}") // Is positive? true
```

## Спецификаторы формата

После выражения добавьте `:` и спецификатор формата для управления выводом:

```yaoxiang
pi = 3.14159265

print(f"Pi: {pi}")       // Pi: 3.14159265
print(f"Pi: {pi:.2f}")   // Pi: 3.14 (2 знака после запятой)
print(f"Pi: {pi:.4f}")   // Pi: 3.1416 (4 знака после запятой)
```

Популярные спецификаторы формата:

| Спецификатор | Значение         | Пример                 | Вывод           |
| ------ | ------------- | ------------------ | -------------- |
| `:.2f` | Число с плавающей точкой, 2 знака | `f"{3.14159:.2f}"` | `3.14`         |
| `:d`   | Целое число в десятичной системе    | `f"{42:d}"`        | `42`           |
| `:x`   | Шестнадцатеричный формат      | `f"{255:x}"`       | `ff`           |
| `:e`   | Экспоненциальная запись    | `f"{1000:e}"`      | `1.000000e+03` |
| `:s`   | Строка        | `f"{name:s}"`      | `hello`        |

## Вызов методов

Внутри `{}` можно вызывать методы:

```yaoxiang
name = "alice"

print(f"Upper: {name.uppercase()}")   // Upper: ALICE
print(f"Length: {name.len()}")        // Length: 5
```

## Экранирование фигурных скобок

Если нужно вывести литеральные `{` или `}`, **удвойте** их:

```yaoxiang
print(f"{{literal braces}}")     // {literal braces}
print(f"Set: {{1, 2, 3}}")       // Set: {1, 2, 3}

// Смешанный режим: двойные для литерала {, одинарные для интерполяции
name = "YaoXiang"
print(f"{{name}} is {name}")     // {name} is YaoXiang
```

## Многострочная f-строка

f-строка может занимать несколько строк:

```yaoxiang
name = "Alice"
age = 25
city = "Beijing"

info = f"""
Name: {name}
Age: {age}
City: {city}
"""

print(info)
// Name: Alice
// Age: 25
// City: Beijing
```

## Как работает f-строка

Когда компилятор встречает f-строку, он преобразует её в эффективную конкатенацию строк:

```yaoxiang
// То, что вы пишете
f"Hello {name}, age: {age}"

// Результат преобразования компилятором
"Hello ".concat(name.to_string()).concat(", age: ").concat(age.to_string())
```

Это означает, что f-строка не только удобнее в написании, но и работает с производительностью, аналогичной ручной конкатенации — **нулевые дополнительные затраты**.
