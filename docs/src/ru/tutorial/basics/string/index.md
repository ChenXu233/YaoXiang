# F-string

f-string — это **шаблонная строка** в YaoXiang — вы можете встраивать переменные и выражения прямо в
строку, и компилятор автоматически выполняет преобразование типов и конкатенацию.

## Базовое использование

Добавьте префикс `f` перед строкой и используйте `{выражение}` для вставки значений:

```yaoxiang
name = "Alice"
age = 25

greeting = f"Hello {name}, you are {age} years old"
print(greeting)  // Hello Alice, you are 25 years old
```

По сравнению с традиционным способом конкатенации, разница с f-string очевидна:

```yaoxiang
// ❌ 传统拼接：冗长且容易出错
message = "Hello ".concat(name).concat(", age: ").concat(age.to_string())

// ✅ f-string：直观、简洁
message = f"Hello {name}, age: {age}"
```

## Интерполяция выражений

Внутри `{}` допускаются не только переменные — можно помещать любое выражение:

```yaoxiang
x = 10
y = 20

print(f"Sum: {x + y}")         // Sum: 30
print(f"Product: {x * y}")     // Product: 200
print(f"Is positive? {x > 0}") // Is positive? true
```

## Спецификаторы форматирования

Добавьте `:` и спецификатор формата после выражения, чтобы управлять форматом вывода:

```yaoxiang
pi = 3.14159265

print(f"Pi: {pi}")       // Pi: 3.14159265
print(f"Pi: {pi:.2f}")   // Pi: 3.14（保留2位小数）
print(f"Pi: {pi:.4f}")   // Pi: 3.1416（保留4位小数）
```

Распространённые спецификаторы форматирования:

| Спецификатор | Значение                          | Пример             | Вывод          |
| ------------ | --------------------------------- | ------------------ | -------------- |
| `:.2f`       | Число с плавающей точкой, 2 знака | `f"{3.14159:.2f}"` | `3.14`         |
| `:d`         | Десятичное целое                  | `f"{42:d}"`        | `42`           |
| `:x`         | Шестнадцатеричное                 | `f"{255:x}"`       | `ff`           |
| `:e`         | Экспоненциальная запись           | `f"{1000:e}"`      | `1.000000e+03` |
| `:s`         | Строка                            | `f"{name:s}"`      | `hello`        |

## Вызов методов

Методы можно вызывать внутри `{}`:

```yaoxiang
name = "alice"

print(f"Upper: {name.uppercase()}")   // Upper: ALICE
print(f"Length: {name.len()}")        // Length: 5
```

## Экранирование фигурных скобок

Если нужно вывести литеральные `{` или `}`, просто **удвойте** их:

```yaoxiang
print(f"{{literal braces}}")     // {literal braces}
print(f"Set: {{1, 2, 3}}")       // Set: {1, 2, 3}

// 混合：双写输出字面量 {，单写是插值
name = "YaoXiang"
print(f"{{name}} is {name}")     // {name} is YaoXiang
```

## Многострочные f-string

f-string может занимать несколько строк:

```yaoxiang
name = "Alice"
age = 25
city = "Beijing"

info = f"""
Name: {name}
Age: {age}
City: {city}
"""

print(info)
// Name: Alice
// Age: 25
// City: Beijing
```

## Как работает f-string

Когда компилятор встречает f-string, он преобразует её в эффективную конкатенацию строк:

```yaoxiang
// 你写的
f"Hello {name}, age: {age}"

// 编译器转换结果
"Hello ".concat(name.to_string()).concat(", age: ").concat(age.to_string())
```

Это означает, что f-string не только проще в написании, но и по производительности во время
выполнения сопоставим с ручной конкатенацией — **без дополнительных накладных расходов**.
