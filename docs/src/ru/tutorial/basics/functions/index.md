# Определение и вызов функций

В предыдущей главе вы научились объявлять переменные. В этой главе вы освоите основы YaoXiang —
функции. Синтаксис функций YaoXiang использует ту же модель `name: type = value`, что и объявление
переменных, поэтому всё должно показаться знакомым.

## Функции — это Lambda

Самая важная концепция: **в YaoXiang функция по сути является lambda-выражением**. Нет специального
ключевого слова `fn`, нет сложных церемоний. Определить функцию — значит просто дать имя
lambda-выражению.

```
# Любая функция по сути представляет собой комбинацию из четырёх компонентов:
name: (params) -> Return = body
 ^       ^        ^        ^
 |       |        |        +-- Тело функции (lambda-выражение или блок кода)
 |       |        +-- Возвращаемый тип
 |       +-- Список параметров (сигнатура)
 +-- Имя функции
```

Это полностью соответствует модели `name: type = value`, которую вы изучали в предыдущей главе —
только здесь "тип" является функциональным типом.

## Выражение-форма: возврат значения напрямую

Простейшие функции не требуют ключевого слова `return`. Когда тело функции представляет собой
единственное выражение, оно напрямую используется как возвращаемое значение:

```yaoxiang
// Выражение-форма — возврат значения напрямую, без return
add: (a: Int, b: Int) -> Int = a + b
square: (x: Int) -> Int = x * x
greet: (name: String) -> String = "Привет, " + name
```

Вызов функций:

```yaoxiang
sum = add(3, 5)          // sum = 8
sq = square(4)           // sq = 16
msg = greet("Мир")       // msg = "Привет, Мир"
```

Это называется **выражение-форма**. Когда тело функции является выражением (не блоком `{ }`), его
значение напрямую используется как возвращаемое. Писать `return` не нужно — более того, это будет
ошибкой.

```yaoxiang
// Правильно: выражение напрямую как возвращаемое значение
double: (x: Int) -> Int = x * 2

// Ошибка: return в выражение-форме — синтаксическая ошибка
// double: (x: Int) -> Int = return x * 2   // ❌
```

## Блок-форма: явный return

Когда функция содержит многошаговые вычисления, тело функции оборачивается в блок `{ }`. **В блоке
необходимо использовать оператор `return`**:

```yaoxiang
// Блок-форма — обязателен return для возврата значения
factorial: (n: Int) -> Int = {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

// Вычисление результата
f5 = factorial(5)        // f5 = 120
```

Правило простое: **выражение-форма возвращает значение напрямую; блок-форма требует явного
`return`**. Если забыть `return` в блоке, функция по умолчанию возвращает `Void`.

```yaoxiang
// Внимание: эта функция с ошибкой
// bad_add: (a: Int, b: Int) -> Int = {
//     a + b   // нет return! блок по умолчанию возвращает Void, но сигнатура требует Int → ошибка типа
// }

// Правильный вариант
good_add: (a: Int, b: Int) -> Int = {
    return a + b
}
```

Итоговая таблица:

| Форма           | Синтаксис             | Возврат значения            |
| --------------- | --------------------- | --------------------------- |
| Выражение-форма | `name: ... = expr`    | Значение выражения напрямую |
| Блок-форма      | `name: ... = { ... }` | Обязательный явный `return` |

## Определение параметров

### Базовые параметры

Параметры указываются в сигнатуре функции, каждый параметр может иметь тип:

```yaoxiang
// Два параметра, оба с типами
multiply: (a: Int, b: Int) -> Int = a * b
```

### Типы параметров должны быть указаны либо в сигнатуре, либо в заголовке lambda

Правило YaoXiang: **при наличии входных параметров их тип должен быть явно указан хотя бы в одном
месте — в сигнатуре или в заголовке lambda**. Отсутствие типа с обеих сторон отклоняется
компилятором.

```yaoxiang
// Способ первый: типы параметров в сигнатуре (заголовок lambda опущен)
add: (a: Int, b: Int) -> Int = a + b

// Способ второй: типы параметров в заголовке lambda (сигнатура опущена)
add = (a: Int, b: Int) => a + b

// Способ третий: полная форма (и в сигнатуре, и в заголовке lambda)
add: (a: Int, b: Int) -> Int = (a, b) => a + b

// Ошибка: типы не указаны нигде
// add = (a, b) => a + b   // ❌ компилятор не может вывести типы параметров
```

**Рекомендуется использовать способ первый** — типы параметров в сигнатуре, без заголовка lambda.
Это самая лаконичная и понятная запись.

## Возвращаемое значение

Возвращаемый тип функции указывается после `->`. Символ `->` является маркером функционального типа
и не может быть опущен (иначе он будет распознан как другой тип).

```yaoxiang
// Возвращает Int
add_one: (x: Int) -> Int = x + 1

// Возвращает String
to_string: (n: Int) -> String = n.to_string()

// Возвращает Void (без возвращаемого значения)
log: (msg: String) -> Void = {
    print(msg)    // без return, по умолчанию возвращает Void
}
```

Возвращаемый тип также можно опустить, позволив выводу типов HM сделать это за вас:

```yaoxiang
// Компилятор выводит возвращаемый тип как Int
add = (a: Int, b: Int) => a + b

// Компилятор выводит возвращаемый тип как String
greet = (name: String) => "Привет, " + name
```

## Вызов функций

### Позиционные аргументы

Базовый способ вызова — передача аргументов по порядку:

```yaoxiang
add: (a: Int, b: Int) -> Int = a + b

result = add(1, 2)        // result = 3
```

Согласно грамматике, форма вызова функции определяется так:

```
Expr '(' ArgList? ')'
```

Переводя на обычный язык: выражение, за которым следуют круглые скобки, внутри которых может быть
список аргументов.

### Именованные аргументы

Помимо передачи по позиции, YaoXiang поддерживает **именованные аргументы** — значение указывается с
именем параметра, порядок не важен:

```yaoxiang
// Именованные аргументы — имя параметра, затем знак равно, затем значение
result = add(a = 3, b = 5)     // result = 8
result = add(b = 5, a = 3)     // порядок произвольный, результат одинаковый

// Можно комбинировать с позиционными, но позиционные должны быть впереди
result = add(3, b = 5)        // OK
```

Именованные аргументы делают вызов более читаемым, особенно когда параметров много:

```yaoxiang
// Сигнатура функции
send: (to: String, title: String, body: String) -> String = to + "|" + title + "|" + body

// Именованные аргументы делают смысл вызова очевидным
msg = send(
    to = "alice@example.com",
    title = "Уведомление о встрече",
    body = "Встреча завтра в 15:00"
)
```

Неправильное имя параметра или повторное указание вызывают ошибку компиляции, без молчаливого
принятия по позиции:

```yaoxiang
// ❌ у add нет параметра c → E1014
result = add(b = 5, c = 1)

// ❌ a передан и позиционно, и по имени → E1015
result = add(1, a = 2)

// ❌ не передан один параметр → E1010
result = add(a = 1)
```

## Функции без параметров

Для функций без параметров список параметров можно опустить:

```yaoxiang
// Полная форма: явное указание пустых параметров
hello: () -> Void = {
    print("Привет!")
}

// Минимальная форма: сигнатура опущена, компилятор сам выводит () -> Void
hello = {
    print("Привет!")
}

// Вызов функции без параметров
hello()
```

Функция `main` — наиболее распространённый пример функции без параметров:

```yaoxiang
// Несколько способов написания функции main

// Полная форма
main: () -> Void = {
    print("Привет, YaoXiang!")
}

// Минимальная форма (рекомендуется)
main: () -> Void = {
    print("Привет, YaoXiang!")
}
```

## Многострочные функции

Когда логика функции достаточно сложная, используется блок-код. YaoXiang требует обязательного
использования 4 пробелов для отступа:

```yaoxiang
// Многошаговые вычисления
calculate_stats: (numbers: List(Int)) -> Float = {
    // Объявление локальных переменных
    mut total = 0
    mut count = 0

    // Цикл накопления суммы
    for n in numbers {
        total = total + n
        count = count + 1
    }

    // Защита от деления на ноль
    if count == 0 {
        return 0.0
    }

    // Возврат среднего значения
    return total:as(Float) / count:as(Float)
}
```

В многострочных функциях можно использовать `#` для комментариев, объявлять `mut` локальные
переменные, использовать `for` и `if` для построения логики.

## pub и автоматическое связывание

В модуле функции, объявленные с ключевым словом `pub`, могут быть импортированы другими модулями.
Что ещё интереснее, **функции `pub` автоматически связываются с типами, определёнными в том же
файле**, позволяя использовать объектно-ориентированный стиль вызова.

```yaoxiang
// point.yx

// Определение типа
Point: Type = { x: Float, y: Float }

// pub функция: компилятор автоматически свяжет её как Point.distance
pub distance: (p1: Point, p2: Point) -> Float = {
    dx = p1.x - p2.x
    dy = p1.y - p2.y
    return (dx * dx + dy * dy).sqrt()
}

// Оба способа вызова работают
p1 = Point(3.0, 4.0)
p2 = Point(1.0, 2.0)

d1 = distance(p1, p2)       // Функциональный вызов
d2 = p1.distance(p2)        // ООП-стиль (синтаксический сахар)
```

Компилятор видит `pub distance(p1: Point, p2: Point)`, находит `Point`, определённый в том же файле,
и автоматически создаёт связывание `Point.distance`. Не нужно писать никакой дополнительный код
`impl`.

## Краткая справка

```yaoxiang
// ── Обзор синтаксиса определения функций ──

// Выражение-форма (самая распространённая)
add: (a: Int, b: Int) -> Int = a + b

// Блок-форма (многошаговая логика)
factorial: (n: Int) -> Int = {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

// Без параметров (минимальная форма)
main: () -> Void = { print("Привет!") }

// С параметрами — сигнатура опущена
double = (x: Int) => x * 2

// С параметрами — заголовок lambda опущён (рекомендуется)
triple: (x: Int) -> Int = x * 3

// pub экспорт + автоматическое связывание
pub add: (a: Int, b: Int) -> Int = a + b

// ── Синтаксис вызова ──

result = add(1, 2)          // Позиционные аргументы
result = add(a = 1, b = 2)   // Именованные аргументы
result = add(1, b = 2)      // Комбинированные (позиционные впереди)
```

## Итоги

Вы освоили ключевые знания о функциях в YaoXiang:

- **Единый синтаксис**: `name: (params) -> Return = body`, та же модель, что и для переменных
  `name: type = value`
- **Выражение-форма**: `= expr`, значение выражения напрямую как возвращаемое, без `return`
- **Блок-форма**: `= { ...; return expr }`, внутри блока обязателен явный `return`
- **Типы параметров**: указываются в сигнатуре или в заголовке lambda, рекомендуется в сигнатуре
- **Вызов**: позиционные или именованные аргументы, порядок для именованных произвольный
- **Автоматическое связывание pub**: функции `pub` автоматически связываются с типами того же файла,
  поддерживают вызов `obj.method()`
- **Минимальная форма без параметров**: `name = { ... }`, компилятор автоматически выводит
  `() -> Void`
