# Определение и вызов функций

В предыдущей главе вы научились объявлять переменные. В этой главе вы освоите основу YaoXiang — функции. Синтаксис функций в YaoXiang использует ту же модель `name: type = value`, что и объявление переменных, поэтому всё должно быть вам знакомо.

## Функция — это Lambda

Начнём с самого важного понятия: **в YaoXiang функция по своей сути является lambda-выражением**. Никаких специальных ключевых слов `fn`, никаких сложных церемоний. Определить функцию — значит просто дать имя lambda-выражению.

```
# Любая функция — это комбинация четырёх элементов:
name: (params) -> Return = body
 ^       ^        ^        ^
 |       |        |        +-- тело функции (lambda-выражение или блок кода)
 |       |        +-- тип возвращаемого значения
 |       +-- список параметров (сигнатура)
 +-- имя функции
```

Это полностью соответствует модели `name: type = value`, которую вы изучили в предыдущей главе — просто здесь "тип" оказался типом функции.

## Выражение формы: прямое возвращение значения

Простейшие функции не требуют ключевого слова `return`. Когда тело функции представляет собой одиночное выражение, оно напрямую используется как возвращаемое значение:

```yaoxiang
// выражение формы — прямое возвращение значения, без return
add: (a: Int, b: Int) -> Int = a + b
square: (x: Int) -> Int = x * x
greet: (name: String) -> String = "你好, " + name
```

Вызов:

```yaoxiang
sum = add(3, 5)          // sum = 8
sq = square(4)           // sq = 16
msg = greet("世界")       // msg = "你好, 世界"
```

Это называется **выражение формы**. Когда тело функции является выражением (а не блоком `{ }`), его значение напрямую становится возвращаемым значением функции. Не нужно писать `return`, более того — написание `return` будет ошибкой.

```yaoxiang
// правильно: выражение напрямую как возвращаемое значение
double: (x: Int) -> Int = x * 2

// ошибка: return в выражении формы — синтаксическая ошибка
// double: (x: Int) -> Int = return x * 2   // ❌
```

---

## Блок формы: явный return

Когда функция выполняет несколько вычислений, тело функции заключается в блок `{ }`. **В блоке необходимо использовать оператор `return` для возврата значения**:

```yaoxiang
// блок формы — обязателен return для возврата значения
factorial: (n: Int) -> Int = {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

// результат вычисления
f5 = factorial(5)        // f5 = 120
```

Правило простое: **выражение формы возвращает значение напрямую; блок формы требует явного `return`**. Если забыть написать `return` в блоке, функция по умолчанию возвращает `Void`.

```yaoxiang
// внимание: эта функция с ошибкой
// bad_add: (a: Int, b: Int) -> Int = {
//     a + b   // нет return! блок по умолчанию возвращает Void, но сигнатура требует Int → ошибка типа
// }

// правильный вариант
good_add: (a: Int, b: Int) -> Int = {
    return a + b
}
```

Итоговая таблица:

| Форма       | Синтаксис              | Способ возврата значения        |
| ---------- | --------------------- | ------------------------ |
| Выражение формы | `name: ... = expr`    | значение выражения напрямую   |
| Блок формы | `name: ... = { ... }` | обязательный явный `return` |

## Определение параметров

### Базовые параметры

Параметры записываются в сигнатуре функции, каждый параметр может иметь аннотацию типа:

```yaoxiang
// два параметра, оба с аннотацией типа
multiply: (a: Int, b: Int) -> Int = a * b
```

### Типы параметров должны быть указаны либо в сигнатуре, либо в заголовке Lambda

Правило YaoXiang таково: **при наличии входных параметров типы должны быть явно указаны хотя бы в одном месте — в сигнатуре или в заголовке Lambda**. Отсутствие типов в обоих местах отклоняется компилятором.

```yaoxiang
// способ первый: типы параметров в сигнатуре (заголовок Lambda опущен)
add: (a: Int, b: Int) -> Int = a + b

// способ второй: типы параметров в заголовке Lambda (сигнатура опущена)
add = (a: Int, b: Int) => a + b

// способ третий: полная форма (и сигнатура, и заголовок Lambda)
add: (a: Int, b: Int) -> Int = (a, b) => a + b

// ошибка: типы не указаны нигде
// add = (a, b) => a + b   // ❌ компилятор не может вывести типы параметров
```

**Рекомендуется использовать способ первый** — типы параметров в сигнатуре с опущенным заголовком Lambda. Это самый краткий и понятный стиль.

## Возвращаемое значение

Тип возвращаемого значения функции записывается после `->`. Символ `->` является маркером типа функции и не может быть опущен (иначе будет распознан как другой тип).

```yaoxiang
// возвращает Int
add_one: (x: Int) -> Int = x + 1

// возвращает String
to_string: (n: Int) -> String = n.to_string()

// возвращает Void (без возвращаемого значения)
log: (msg: String) -> Void = {
    print(msg)    // без return, по умолчанию возвращает Void
}
```

Тип возвращаемого значения также можно опустить, позволив выведению типов HM сделать это за вас:

```yaoxiang
// компилятор выводит тип возвращаемого значения как Int
add = (a: Int, b: Int) => a + b

// компилятор выводит тип возвращаемого значения как String
greet = (name: String) => "你好, " + name
```

## Вызов функции

### Позиционные параметры

Базовый способ вызова — передача параметров по порядку:

```yaoxiang
add: (a: Int, b: Int) -> Int = a + b

result = add(1, 2)        // result = 3
```

Согласно грамматике, вызов функции определяется так:

```
Expr '(' ArgList? ')'
```

Переводя на обычный язык: выражение, за которым следуют круглые скобки, внутри которых может быть список аргументов.

### Именованные параметры

Помимо передачи параметров по позиции, YaoXiang поддерживает **именованные параметры** — значения указываются с именем параметра, порядок не важен:

```yaoxiang
// именованные параметры — после имени параметра ставится двоеточие, затем значение
result = add(a: 3, b: 5)     // result = 8
result = add(b: 5, a: 3)     // порядок произвольный, результат тот же

// можно комбинировать с позиционными, но позиционные должны идти первыми
result = add(3, b: 5)        // OK
```

Именованные параметры делают вызов более читаемым и особенно полезны при большом количестве параметров:

```yaoxiang
// сигнатура функции
send: (to: String, title: String, body: String) -> Void = {
    print("发送给: " + to)
    print("标题: " + title)
    print("正文: " + body)
}

// именованные параметры делают вызов понятным
send(
    to: "alice@example.com",
    title: "会议通知",
    body: "明天下午 3 点开会"
)
```

## Функции без параметров

Для функций без параметров список параметров можно опустить:

```yaoxiang
// полная форма: явно объявлены пустые параметры
hello: () -> Void = {
    print("Hello!")
}

// кратчайшая форма: сигнатура опущена, компилятор выводит () -> Void
hello = {
    print("Hello!")
}

// вызов функции без параметров
hello()
```

Функция `main` — самый распространённый пример функции без параметров:

```yaoxiang
// несколько вариантов функции main

// полная форма
main: () -> Void = {
    print("Hello, YaoXiang!")
}

// кратчайшая форма (рекомендуется)
main = {
    print("Hello, YaoXiang!")
}
```

## Многострочные функции

Когда логика функции достаточно сложна, используется блоковая форма для организации кода. YaoXiang требует обязательного использования 4 пробелов для отступов:

```yaoxiang
// многошаговые вычисления
calculate_stats: (numbers: List(Int)) -> Float = {
    // объявление локальных переменных
    mut total = 0
    mut count = 0

    // цикл накопления суммы
    for n in numbers {
        total = total + n
        count = count + 1
    }

    // избегаем деления на ноль
    if count == 0 {
        return 0.0
    }

    // возвращаем среднее значение
    return total:as(Float) / count:as(Float)
}
```

В многострочных функциях можно использовать `#` для комментариев, объявлять `mut` локальные переменные, использовать `for` и `if` для построения логики.

## pub и автоматическое связывание

В модулях функции, объявленные с ключевым словом `pub`, могут импортироваться и использоваться из других модулей. Что ещё интереснее, **функции `pub` автоматически связываются с типами, определёнными в том же файле**, позволяя вызывать их в объектно-ориентированном стиле.

```yaoxiang
// point.yx

// определение типа
Point: Type = { x: Float, y: Float }

// pub функция: компилятор автоматически связывает её как Point.distance
pub distance: (p1: Point, p2: Point) -> Float = {
    dx = p1.x - p2.x
    dy = p1.y - p2.y
    return (dx * dx + dy * dy).sqrt()
}

// оба способа вызова работают
p1 = Point(3.0, 4.0)
p2 = Point(1.0, 2.0)

d1 = distance(p1, p2)       // функциональный вызов
d2 = p1.distance(p2)        // ООП-стиль вызова (синтаксический сахар)
```

Компилятор, увидев `pub distance(p1: Point, p2: Point)`, обнаруживает, что `Point` определён в том же файле, и автоматически создаёт связывание `Point.distance`. Вам не нужно писать никакой дополнительный код `impl`.

## Быстрая справка

```yaoxiang
// ── Обзор синтаксиса определения функций ──

// выражение формы (наиболее распространено)
add: (a: Int, b: Int) -> Int = a + b

// блок формы (многошаговая логика)
factorial: (n: Int) -> Int = {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

// без параметров (кратчайшая форма)
main = { print("Hello!") }

// с параметрами — сигнатура опущена
double = (x: Int) => x * 2

// с параметрами — заголовок Lambda опущен (рекомендуется)
triple: (x: Int) -> Int = x * 3

// pub экспорт + автоматическое связывание
pub add: (a: Int, b: Int) -> Int = a + b

// ── Синтаксис вызова ──

result = add(1, 2)          // позиционные параметры
result = add(a: 1, b: 2)    // именованные параметры
result = add(1, b: 2)       // комбинирование (позиционные первыми)
```

## Итоги

Вы освоили основные знания о функциях в YaoXiang:

- **Единый синтаксис**: `name: (params) -> Return = body`, тот же источник, что и у объявления переменных `name: type = value`
- **Выражение формы**: `= expr`, значение выражения напрямую как возвращаемое, `return` не нужен
- **Блок формы**: `= { ...; return expr }`, внутри блока обязателен явный `return`
- **Аннотация типов параметров**: типы указываются либо в сигнатуре, либо в заголовке Lambda, рекомендуется в сигнатуре
- **Вызов**: позиционные или именованные параметры, порядок именованных произвольный
- **pub автоматическое связывание**: функции `pub` автоматически связываются с типами в том же файле, поддерживают вызов `obj.method()`
- **без параметров — кратчайшая форма**: `name = { ... }`, компилятор автоматически выводит `() -> Void`

Далее вы можете продолжить изучение главы [Управление потоком](./control-flow.md), чтобы узнать, как использовать `if`, `for` и `while` в функциях.
