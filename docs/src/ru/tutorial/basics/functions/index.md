# Определение и вызов функций

В предыдущей главе вы научились объявлять переменные. Эта глава познакомит вас с ядром YaoXiang —
функциями. Синтаксис функций в YaoXiang разделяет с объявлением переменных одну и ту же модель
`name: type = value`, так что вам всё должно быть знакомо.

## Функция — это Lambda

Сначала самое важное: **в YaoXiang функция по сути является лямбда-выражением**. Нет специального
ключевого слова `fn`, нет сложных церемоний. Определить функцию — значит дать имя лямбде.

```
# Любая функция по сути является комбинацией этих четырёх вещей:
name: (params) -> Return = body
 ^       ^        ^        ^
 |       |        |        +-- тело функции (лямбда-выражение или блок кода)
 |       |        +-- тип возвращаемого значения
 |       +-- список параметров (сигнатура)
 +-- имя функции
```

Это полностью согласуется с изученным в прошлой главе `name: type = value` — просто «типом» здесь
оказывается функциональный тип.

## Форма выражения: прямое возвращение значения

Самая простая функция не требует ключевого слова `return`. Когда тело функции — это одно выражение,
оно напрямую становится возвращаемым значением:

```yaoxiang
// Форма выражения — значение возвращается напрямую, без return
add: (a: Int, b: Int) -> Int = a + b
square: (x: Int) -> Int = x * x
greet: (name: String) -> String = "Привет, " + name
```

Вызовем их:

```yaoxiang
sum = add(3, 5)          // sum = 8
sq = square(4)           // sq = 16
msg = greet("мир")       // msg = "Привет, мир"
```

Это называется **формой выражения**. Когда тело функции является выражением (а не блоком `{ }`), его
значение напрямую становится возвращаемым значением функции. Писать `return` не нужно, а если
написать — это будет ошибкой.

```yaoxiang
// Правильно: выражение напрямую становится возвращаемым значением
double: (x: Int) -> Int = x * 2

// Неправильно: использование return в форме выражения — синтаксическая ошибка
// double: (x: Int) -> Int = return x * 2   // ❌
```

## Форма блока: явный return

Когда функция содержит несколько шагов вычислений, оберните тело функции в блок `{ }`. **Внутри
блока для возврата значения необходимо использовать оператор `return`**:

```yaoxiang
// Форма блока — возвращаемое значение обязательно через return
factorial: (n: Int) -> Int = {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

// Вычисление результата
f5 = factorial(5)        // f5 = 120
```

Правило простое: **в форме выражения значение возвращается напрямую; в форме блока требуется явный
`return`**. Если в блоке забыть написать `return`, функция по умолчанию вернёт `Void`.

```yaoxiang
// Внимание: в этой функции есть баг
// bad_add: (a: Int, b: Int) -> Int = {
//     a + b   // нет return! блок по умолчанию вернёт Void, но сигнатура требует Int → ошибка типа
// }

// Правильный вариант
good_add: (a: Int, b: Int) -> Int = {
    return a + b
}
```

Резюме:

| Форма           | Синтаксис             | Способ возврата значения                 |
| --------------- | --------------------- | ---------------------------------------- |
| Форма выражения | `name: ... = expr`    | значение выражения возвращается напрямую |
| Форма блока     | `name: ... = { ... }` | требуется явный `return`                 |

## Определение параметров

### Базовые параметры

Параметры записываются в сигнатуре функции, и для каждого можно указать тип:

```yaoxiang
// Два параметра, оба с указанием типа
multiply: (a: Int, b: Int) -> Int = a * b
```

### Тип параметра должен быть указан либо в сигнатуре, либо в заголовке лямбды

Правило в YaoXiang таково: **при наличии входных параметров тип каждого из них должен быть явно
указан хотя бы в одном месте — в сигнатуре или в заголовке лямбды**. Если опустить типы с обеих
сторон, компилятор отклонит такой код.

```yaoxiang
// Способ 1: типы параметров в сигнатуре (заголовок лямбды опущен)
add: (a: Int, b: Int) -> Int = a + b

// Способ 2: типы параметров в заголовке лямбды (сигнатура опущена)
add = (a: Int, b: Int) => a + b

// Способ 3: полная форма (сигнатура + заголовок лямбды)
add: (a: Int, b: Int) -> Int = (a, b) => a + b

// Неправильно: типы не указаны нигде
// add = (a, b) => a + b   // ❌ компилятор не может вывести типы параметров
```

**Рекомендуется способ 1** — типы параметров указываются в сигнатуре, заголовок лямбды опускается.
Это самая лаконичная и ясная запись.

## Возвращаемое значение

Тип возвращаемого значения функции записывается после `->`. Символ `->` — признак функционального
типа, его нельзя опускать (без него выражение будет разобрано как другой тип).

```yaoxiang
// Возвращает Int
add_one: (x: Int) -> Int = x + 1

// Возвращает String
to_string: (n: Int) -> String = n.to_string()

// Возвращает Void (без возвращаемого значения)
log: (msg: String) -> Void = {
    print(msg)    // нет return, по умолчанию возвращается Void
}
```

Тип возвращаемого значения тоже можно опустить — пусть вывод типов HM сделает свою работу:

```yaoxiang
// Компилятор выводит тип возвращаемого значения как Int
add = (a: Int, b: Int) => a + b

// Компилятор выводит тип возвращаемого значения как String
greet = (name: String) => "Привет, " + name
```

## Вызов функций

### Позиционные аргументы

Самый базовый способ вызова — передача аргументов по порядку:

```yaoxiang
add: (a: Int, b: Int) -> Int = a + b

result = add(1, 2)        // result = 3
```

Определение формы вызова в грамматике выглядит так:

```
Expr '(' ArgList? ')'
```

Переводя на обычный язык: за выражением следуют круглые скобки, внутри которых может находиться
список аргументов.

### Именованные аргументы

Помимо передачи по позиции, YaoXiang поддерживает **именованные аргументы** — значение указывается
по имени параметра, порядок не важен:

```yaoxiang
// Именованные аргументы — после имени параметра ставится знак равенства, затем значение
result = add(a = 3, b = 5)     // result = 8
result = add(b = 5, a = 3)     // порядок произвольный, результат тот же

// Можно смешивать с позиционными, но позиционные должны идти первыми
result = add(3, b = 5)        // OK
```

Именованные аргументы делают вызов более читаемым, что особенно полезно при большом числе
параметров:

```yaoxiang
// Сигнатура функции
send: (to: String, title: String, body: String) -> String = to + "|" + title + "|" + body

// Именованные аргументы делают намерение вызова очевидным
msg = send(
    to = "alice@example.com",
    title = "Уведомление о встрече",
    body = "Завтра в 3 часа дня совещание"
)
```

Ошибка в имени параметра или повторное указание будут обнаружены во время компиляции, без тихой
подстановки по позиции:

```yaoxiang
// ❌ у add нет формального параметра c → E1014
result = add(b = 5, c = 1)

// ❌ a передан и позиционно, и по имени → E1015
result = add(1, a = 2)

// ❌ пропущен один аргумент → E1010
result = add(a = 1)
```

## Функции без параметров

Для функций без параметров список параметров можно опустить:

```yaoxiang
// Полная форма: явно указаны пустые параметры
hello: () -> Void = {
    print("Hello!")
}

// Самая краткая форма: сигнатура опущена, компилятор автоматически выводит () -> Void
hello = {
    print("Hello!")
}

// Вызов функции без параметров
hello()
```

Функция `main` — самый распространённый пример функции без параметров:

```yaoxiang
// Несколько вариантов записи функции main

// Полная форма
main: () -> Void = {
    print("Hello, YaoXiang!")
}

// Самая краткая форма (рекомендуется)
main: () -> Void = {
    print("Hello, YaoXiang!")
}
```

## Многострочные функции

Когда логика функции достаточно сложна, используйте форму блока для организации кода. YaoXiang
требует отступ в 4 пробела:

```yaoxiang
// Многошаговое вычисление
calculate_stats: (numbers: List(Int)) -> Float = {
    // Объявление локальных переменных
    mut total = 0
    mut count = 0

    // Накопление в цикле
    for n in numbers {
        total = total + n
        count = count + 1
    }

    // Избежание деления на ноль
    if count == 0 {
        return 0.0
    }

    // Возврат среднего значения
    return total:as(Float) / count:as(Float)
}
```

В многострочных функциях можно использовать `#` для комментариев, объявлять локальные переменные
`mut`, применять `for` и `if` для построения логики.

## pub и автоматическое связывание

Внутри модуля функции, объявленные с ключевым словом `pub`, могут импортироваться и использоваться
другими модулями. Что ещё интереснее — **`pub`-функции автоматически привязываются к типам,
определённым в том же файле**, что позволяет вызывать их в ООП-стиле.

```yaoxiang
// point.yx

// Определение типа
Point: Type = { x: Float, y: Float }

// pub-функция: компилятор автоматически привязывает её как Point.distance
pub distance: (p1: Point, p2: Point) -> Float = {
    dx = p1.x - p2.x
    dy = p1.y - p2.y
    return (dx * dx + dy * dy).sqrt()
}

// Оба способа вызова работают
p1 = Point(3.0, 4.0)
p2 = Point(1.0, 2.0)

d1 = distance(p1, p2)       // функциональный вызов
d2 = p1.distance(p2)        // вызов в ООП-стиле (синтаксический сахар)
```

Компилятор, видя `pub distance(p1: Point, p2: Point)`, обнаруживает, что `Point` определён в том же
файле, и автоматически создаёт привязку `Point.distance`. Писать какой-либо дополнительный
`impl`-код не нужно.

## Краткий справочник

```yaoxiang
// ── Сводка по синтаксису определения функций ──

// Форма выражения (самая распространённая)
add: (a: Int, b: Int) -> Int = a + b

// Форма блока (многошаговая логика)
factorial: (n: Int) -> Int = {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

// Функция без параметров (самая краткая)
main: () -> Void = { print("Hello!") }

// С параметрами — сигнатура опущена
double = (x: Int) => x * 2

// С параметрами — заголовок лямбды опущен (рекомендуется)
triple: (x: Int) -> Int = x * 3

// pub-экспорт + автоматическое связывание
pub add: (a: Int, b: Int) -> Int = a + b

// ── Синтаксис вызова ──

result = add(1, 2)          // позиционные аргументы
result = add(a = 1, b = 2)   // именованные аргументы
result = add(1, b = 2)      // смешанный вызов (позиционные впереди)
```

## Итоги

Вы освоили ключевые знания о функциях в YaoXiang:

- **Единый синтаксис**: `name: (params) -> Return = body`, того же происхождения, что и
  `name: type = value` для переменных
- **Форма выражения**: `= expr`, значение выражения возвращается напрямую, `return` не нужен
- **Форма блока**: `= { ...; return expr }`, внутри блока требуется явный `return`
- **Указание типов параметров**: тип должен быть указан хотя бы в одном месте — в сигнатуре или в
  заголовке лямбды; рекомендуется указывать в сигнатуре
- **Вызов**: позиционные или именованные аргументы, порядок именованных произвольный
- **Автоматическое связывание pub**: `pub`-функции автоматически привязываются к типам из того же
  файла, поддерживая вызов вида `obj.method()`
- **Самая краткая форма без параметров**: `name = { ... }`, компилятор автоматически выводит
  `() -> Void`

Дальше вы можете перейти к главе о
[потоке управления](../../../design/formatter/formatting-rules/control-flow.md), чтобы узнать, как
использовать `if`, `for` и `while` внутри функций.
