# Определение и вызов функций

В предыдущей главе вы научились объявлять переменные. Эта глава познакомит вас с ядром YaoXiang —
функциями. Синтаксис функций YaoXiang разделяет ту же модель `name: type = value`, что и объявление
переменных, поэтому вам должно быть знакомо это ощущение.

## Функция — это Lambda

Прежде всего, самая важная концепция: **в YaoXiang функция по сути является лямбда-выражением**. Нет
специального ключевого слова `fn`, нет сложных церемоний. Определить функцию — значит дать лямбде
имя.

```
# 任何函数本质上都是这四样东西的组合：
name: (params) -> Return = body
 ^       ^        ^        ^
 |       |        |        +-- 函数体（lambda 表达式或代码块）
 |       |        +-- 返回值类型
 |       +-- 参数列表（签名）
 +-- 函数名
```

Это полностью согласуется с изученной в предыдущей главе моделью `name: type = value` — просто
«типом» здесь оказывается функциональный тип.

---

## Форма выражения: прямое возвращение значения

Самые простые функции не нуждаются в ключевом слове `return`. Когда тело функции представляет собой
одно выражение, оно напрямую становится возвращаемым значением:

```yaoxiang
// 表达式形式——直接返回值，无需 return
add: (a: Int, b: Int) -> Int = a + b
square: (x: Int) -> Int = x * x
greet: (name: String) -> String = "你好, " + name
```

Вызовем их:

```yaoxiang
sum = add(3, 5)          // sum = 8
sq = square(4)           // sq = 16
msg = greet("世界")       // msg = "你好, 世界"
```

Это называется **формой выражения**. Когда тело функции является выражением (а не блоком кода
`{ }`), его значение напрямую становится возвращаемым значением функции. Писать `return` не нужно —
и наоборот, это было бы ошибкой.

```yaoxiang
// 正确：表达式直接作为返回值
double: (x: Int) -> Int = x * 2

// 错误：表达式形式中写 return 是语法错误
// double: (x: Int) -> Int = return x * 2   // ❌
```

---

## Блочная форма: явный return

Когда функция содержит несколько шагов вычислений, тело функции оборачивается в блок кода `{ }`. **В
блоке кода для возврата значения необходимо использовать оператор `return`**:

```yaoxiang
// 代码块形式——必须用 return 返回值
factorial: (n: Int) -> Int = {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

// 计算结果
f5 = factorial(5)        // f5 = 120
```

Правило простое: **форма выражения возвращает значение напрямую; блочная форма требует явного
`return`**. Если в блоке кода забыть написать `return`, функция по умолчанию вернёт `Void`.

```yaoxiang
// 注意：这个函数有 bug
// bad_add: (a: Int, b: Int) -> Int = {
//     a + b   // 没有 return！块默认返回 Void，但签名要求 Int → 类型错误
// }

// 正确写法
good_add: (a: Int, b: Int) -> Int = {
    return a + b
}
```

Итог:

| Форма           | Синтаксис             | Способ возврата значения                            |
| --------------- | --------------------- | --------------------------------------------------- |
| Форма выражения | `name: ... = expr`    | Значение выражения напрямую становится возвращаемым |
| Блочная форма   | `name: ... = { ... }` | Необходимо явно использовать `return`               |

## Определение параметров

### Основные параметры

Параметры записываются в сигнатуре функции, и каждый параметр может быть аннотирован типом:

```yaoxiang
// 两个参数，都标注了类型
multiply: (a: Int, b: Int) -> Int = a * b
```

### Тип параметра должен быть указан либо в сигнатуре, либо в заголовке Lambda

Правило YaoXiang: **при наличии входных параметров тип параметра должен быть явно указан хотя бы в
одном из мест: в сигнатуре или в заголовке Lambda**. Пропуск в обоих местах будет отвергнут
компилятором.

```yaoxiang
// 方式一：参数类型写在签名中（省略 Lambda 头）
add: (a: Int, b: Int) -> Int = a + b

// 方式二：参数类型写在 Lambda 头中（省略签名）
add = (a: Int, b: Int) => a + b

// 方式三：完整形式（签名 + Lambda 头都有）
add: (a: Int, b: Int) -> Int = (a, b) => a + b

// 错误：两边都不写类型
// add = (a, b) => a + b   // ❌ 编译器无法推断参数类型
```

**Рекомендуется использовать способ 1** — типы параметров записываются в сигнатуре, а заголовок
Lambda опускается. Это самый лаконичный и понятный вариант записи.

## Возвращаемое значение

Тип возвращаемого значения функции записывается после `->`. Стрелка `->` является признаком
функционального типа и не может быть пропущена (при пропуске он будет интерпретирован как другой
тип).

```yaoxiang
// 返回 Int
add_one: (x: Int) -> Int = x + 1

// 返回 String
to_string: (n: Int) -> String = n.to_string()

// 返回 Void（无返回值）
log: (msg: String) -> Void = {
    print(msg)    // 无 return，默认返回 Void
}
```

Тип возвращаемого значения также можно опустить, позволив вывод типов HM сделать это за вас:

```yaoxiang
// 编译器推断返回类型为 Int
add = (a: Int, b: Int) => a + b

// 编译器推断返回类型为 String
greet = (name: String) => "你好, " + name
```

## Вызов функций

### Позиционные аргументы

Самый базовый способ вызова — передача аргументов по порядку:

```yaoxiang
add: (a: Int, b: Int) -> Int = a + b

result = add(1, 2)        // result = 3
```

Формальное определение вызова функции в спецификации синтаксиса таково:

```
Expr '(' ArgList? ')'
```

Говоря обычным языком: после выражения идёт пара круглых скобок, внутри которых может располагаться
список аргументов.

### Именованные аргументы

Помимо передачи аргументов по позиции, YaoXiang также поддерживает **именованные аргументы** —
указание значений с помощью имён параметров в любом порядке:

```yaoxiang
// 命名参数——参数名后面跟等号，然后是值
result = add(a = 3, b = 5)     // result = 8
result = add(b = 5, a = 3)     // 顺序任意，结果相同

// 可以和位置参数混用，但位置参数必须在前面
result = add(3, b = 5)        // OK
```

Именованные аргументы делают вызов более читаемым, что особенно полезно при большом количестве
параметров:

```yaoxiang
// 函数签名
send: (to: String, title: String, body: String) -> String = to + "|" + title + "|" + body

// 命名参数让调用意图一目了然
msg = send(
    to = "alice@example.com",
    title = "会议通知",
    body = "明天下午 3 点开会"
)
```

Ошибка в имени параметра или его повторное указание вызовет ошибку на этапе компиляции — не будет
молчаливо принято по позиции:

```yaoxiang
// ❌ add 没有名为 c 的形参 → E1014
result = add(b = 5, c = 1)

// ❌ a 既由位置传入又由命名传入 → E1015
result = add(1, a = 2)

// ❌ 少传一个参数 → E1010
result = add(a = 1)
```

## Функции без аргументов

Функции, не требующие аргументов, могут опускать список параметров:

```yaoxiang
// 完整形式：显式声明空参数
hello: () -> Void = {
    print("Hello!")
}

// 最简形式：省略签名，编译器自动推断为 () -> Void
hello = {
    print("Hello!")
}

// 调用无参函数
hello()
```

Функция `main` — самый распространённый пример функции без аргументов:

```yaoxiang
// main 函数的几种写法

// 完整形式
main: () -> Void = {
    print("Hello, YaoXiang!")
}

// 最简形式（推荐）
main: () -> Void = {
    print("Hello, YaoXiang!")
}
```

## Многострочные функции

Когда логика функции достаточно сложна, для организации кода используется блочная форма. YaoXiang
требует отступ в 4 пробела:

```yaoxiang
// 多步计算
calculate_stats: (numbers: List(Int)) -> Float = {
    // 声明局部变量
    mut total = 0
    mut count = 0

    // 循环累加
    for n in numbers {
        total = total + n
        count = count + 1
    }

    // 避免除零
    if count == 0 {
        return 0.0
    }

    // 返回平均值
    return total:as(Float) / count:as(Float)
}
```

В многострочных функциях можно использовать `#` для комментариев, объявлять локальные переменные
`mut`, а также использовать `for` и `if` для построения логики.

## pub и автоматическое связывание

В модуле функции, объявленные с ключевым словом `pub`, могут быть импортированы и использованы
другими модулями. Что ещё интереснее, **функции `pub` автоматически связываются с типами,
определёнными в том же файле**, что позволяет вызывать их в стиле ООП.

```yaoxiang
// point.yx

// 定义类型
Point: Type = { x: Float, y: Float }

// pub 函数：编译器自动将其绑定为 Point.distance
pub distance: (p1: Point, p2: Point) -> Float = {
    dx = p1.x - p2.x
    dy = p1.y - p2.y
    return (dx * dx + dy * dy).sqrt()
}

// 两种调用方式都可以
p1 = Point(3.0, 4.0)
p2 = Point(1.0, 2.0)

d1 = distance(p1, p2)       // 函数式调用
d2 = p1.distance(p2)        // OOP 风格调用（语法糖）
```

Компилятор, видя `pub distance(p1: Point, p2: Point)` и обнаруживая, что `Point` определён в том же
файле, автоматически создаёт связывание `Point.distance`. Вам не нужно писать никакого
дополнительного кода `impl`.

## Краткий справочник

```yaoxiang
// ── 函数定义语法一览 ──

// 表达式形式（最常用）
add: (a: Int, b: Int) -> Int = a + b

// 代码块形式（多步逻辑）
factorial: (n: Int) -> Int = {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

// 无参函数（最简）
main: () -> Void = { print("Hello!") }

// 有参—省略签名
double = (x: Int) => x * 2

// 有参—省略 Lambda 头（推荐）
triple: (x: Int) -> Int = x * 3

// pub 导出 + 自动绑定
pub add: (a: Int, b: Int) -> Int = a + b

// ── 调用语法 ──

result = add(1, 2)          // 位置参数
result = add(a = 1, b = 2)   // 命名参数
result = add(1, b = 2)      // 混用（位置在前）
```

## Резюме

Вы освоили основные знания о функциях YaoXiang:

- **Единый синтаксис**: `name: (params) -> Return = body`, имеющий общие корни с объявлением
  переменных `name: type = value`
- **Форма выражения**: `= expr`, значение выражения напрямую становится возвращаемым, без
  необходимости в `return`
- **Блочная форма**: `= { ...; return expr }`, внутри блока необходимо явно использовать `return`
- **Аннотация типов параметров**: тип должен быть указан хотя бы в одном из мест — в сигнатуре или в
  заголовке Lambda, рекомендуется в сигнатуре
- **Вызов**: позиционные или именованные аргументы, именованные аргументы могут идти в любом порядке
- **Автоматическое связывание pub**: функции `pub` автоматически связываются с типами того же файла,
  поддерживается вызов `obj.method()`
- **Кратчайшая форма без аргументов**: `name = { ... }`, компилятор автоматически выводит тип
  `() -> Void`

Следующим шагом вы можете перейти к изучению главы [Управление потоком](./control-flow.md), чтобы
узнать, как использовать `if`, `for` и `while` внутри функций.
