# Определение и вызов функций

В предыдущей главе вы научились объявлять переменные. Эта глава познакомит вас с основой YaoXiang —
функциями. Синтаксис функций в YaoXiang разделяет ту же модель `name: type = value` с объявлением
переменных, поэтому вам всё должно быть знакомо.

## Функция — это лямбда

Сначала самая важная концепция: **в YaoXiang функция по сути является лямбда-выражением**. Никакого
специального ключевого слова `fn`, никаких сложных церемоний. Определить функцию — значит дать
лямбде имя.

```
# Любая функция — это по сути комбинация этих четырёх вещей:
name: (params) -> Return = body
 ^       ^        ^        ^
 |       |        |        +-- тело функции (лямбда-выражение или блок кода)
 |       |        +-- тип возвращаемого значения
 |       +-- список параметров (сигнатура)
 +-- имя функции
```

Это полностью совпадает с изученным ранее `name: type = value` — просто «тип» здесь как раз является
типом функции.

---

## Форма выражения: прямое возвращение значения

Простейшие функции не требуют ключевого слова `return`. Когда тело функции — это одно выражение, оно
напрямую становится возвращаемым значением:

```yaoxiang
// Форма выражения — прямое возвращение значения, без return
add: (a: Int, b: Int) -> Int = a + b
square: (x: Int) -> Int = x * x
greet: (name: String) -> String = "你好, " + name
```

Их вызов:

```yaoxiang
sum = add(3, 5)          // sum = 8
sq = square(4)           // sq = 16
msg = greet("世界")       // msg = "你好, 世界"
```

Это называется **формой выражения**. Когда тело функции является выражением (а не блоком кода
`{ }`), его значение напрямую становится возвращаемым значением функции. Писать `return` не нужно —
наоборот, это будет ошибкой.

```yaoxiang
// Правильно: выражение напрямую становится возвращаемым значением
double: (x: Int) -> Int = x * 2

// Ошибка: использование return в форме выражения — синтаксическая ошибка
// double: (x: Int) -> Int = return x * 2   // ❌
```

## Форма блока кода: явный return

Когда функция содержит несколько шагов вычислений, оберните тело функции в блок `{ }`. **В блоке
кода для возврата значения необходимо использовать оператор `return`**:

```yaoxiang
// Форма блока кода — возвращаемое значение обязательно через return
factorial: (n: Int) -> Int = {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

// Вычисление результата
f5 = factorial(5)        // f5 = 120
```

Правило простое: **форма выражения возвращает значение напрямую; форма блока кода требует явного
`return`**. Если в блоке кода забыть написать `return`, функция по умолчанию вернёт `Void`.

```yaoxiang
// Внимание: в этой функции есть ошибка
// bad_add: (a: Int, b: Int) -> Int = {
//     a + b   // Нет return! Блок по умолчанию возвращает Void, но сигнатура требует Int → ошибка типа
// }

// Правильный вариант
good_add: (a: Int, b: Int) -> Int = {
    return a + b
}
```

Резюме:

| Форма            | Синтаксис             | Способ возврата значения              |
| ---------------- | --------------------- | ------------------------------------- |
| Форма выражения  | `name: ... = expr`    | Значение выражения сразу возвращается |
| Форма блока кода | `name: ... = { ... }` | Необходим явный `return`              |

## Определение параметров

### Базовые параметры

Параметры записываются в сигнатуре функции, и каждый параметр может быть аннотирован типом:

```yaoxiang
// Два параметра, оба аннотированы типами
multiply: (a: Int, b: Int) -> Int = a * b
```

### Тип параметра должен быть указан в сигнатуре или в заголовке лямбды

Правило YaoXiang таково: **при наличии входных параметров их типы должны быть явно указаны хотя бы в
одном из мест — в сигнатуре или в заголовке лямбды**. Пропуск типов в обоих местах будет отвергнут
компилятором.

```yaoxiang
// Способ 1: типы параметров в сигнатуре (заголовок лямбды опущен)
add: (a: Int, b: Int) -> Int = a + b

// Способ 2: типы параметров в заголовке лямбды (сигнатура опущена)
add = (a: Int, b: Int) => a + b

// Способ 3: полная форма (сигнатура + заголовок лямбды)
add: (a: Int, b: Int) -> Int = (a, b) => a + b

// Ошибка: типы не указаны ни в одном из мест
// add = (a, b) => a + b   // ❌ компилятор не может вывести типы параметров
```

**Рекомендуется использовать способ 1** — типы параметров указываются в сигнатуре, заголовок лямбды
опускается. Это самая краткая и ясная запись.

## Возвращаемое значение

Тип возвращаемого значения функции записывается после `->`. `->` — это маркер типа функции, его
нельзя опускать (без него выражение будет разобрано как другой тип).

```yaoxiang
// Возвращает Int
add_one: (x: Int) -> Int = x + 1

// Возвращает String
to_string: (n: Int) -> String = n.to_string()

// Возвращает Void (без возвращаемого значения)
log: (msg: String) -> Void = {
    print(msg)    // Нет return, по умолчанию возвращается Void
}
```

Тип возвращаемого значения также можно опустить, позволив вывод типов HM сделать всю работу:

```yaoxiang
// Компилятор выводит тип возврата как Int
add = (a: Int, b: Int) => a + b

// Компилятор выводит тип возврата как String
greet = (name: String) => "你好, " + name
```

## Вызов функций

### Позиционные аргументы

Самый базовый способ вызова — передача аргументов по порядку:

```yaoxiang
add: (a: Int, b: Int) -> Int = a + b

result = add(1, 2)        // result = 3
```

Формальное определение вызова функции в спецификации синтаксиса:

```
Expr '(' ArgList? ')'
```

Переводя на повседневный язык: после выражения идёт пара круглых скобок, внутри которых может
располагаться список аргументов.

### Именованные аргументы

Помимо передачи аргументов по позиции, YaoXiang также поддерживает **именованные аргументы** —
значение указывается через имя параметра, порядок не важен:

```yaoxiang
// Именованные аргументы — после имени параметра ставится двоеточие, затем значение
result = add(a: 3, b: 5)     // result = 8
result = add(b: 5, a: 3)     // Порядок произвольный, результат одинаковый

// Можно смешивать с позиционными аргументами, но позиционные должны идти первыми
result = add(3, b: 5)        // OK
```

Именованные аргументы делают вызов более читаемым, что особенно полезно при большом количестве
параметров:

```yaoxiang
// Сигнатура функции
send: (to: String, title: String, body: String) -> Void = {
    print("发送给: " + to)
    print("标题: " + title)
    print("正文: " + body)
}

// Именованные аргументы делают намерение вызова совершенно ясным
send(
    to: "alice@example.com",
    title: "会议通知",
    body: "明天下午 3 点开会"
)
```

## Функции без параметров

Для функций, не требующих параметров, список параметров можно опустить:

```yaoxiang
// Полная форма: явное объявление пустых параметров
hello: () -> Void = {
    print("Hello!")
}

// Самая краткая форма: сигнатура опущена, компилятор автоматически выводит () -> Void
hello = {
    print("Hello!")
}

// Вызов функции без параметров
hello()
```

Функция `main` — самый распространённый пример функции без параметров:

```yaoxiang
// Несколько вариантов записи функции main

// Полная форма
main: () -> Void = {
    print("Hello, YaoXiang!")
}

// Самая краткая форма (рекомендуется)
main: () -> Void = {
    print("Hello, YaoXiang!")
}
```

## Многострочные функции

Когда логика функции достаточно сложна, используйте форму блока кода для организации кода. YaoXiang
требует отступ в 4 пробела:

```yaoxiang
// Многошаговое вычисление
calculate_stats: (numbers: List(Int)) -> Float = {
    // Объявление локальных переменных
    mut total = 0
    mut count = 0

    // Цикл для накопления
    for n in numbers {
        total = total + n
        count = count + 1
    }

    // Защита от деления на ноль
    if count == 0 {
        return 0.0
    }

    // Возврат среднего значения
    return total:as(Float) / count:as(Float)
}
```

В многострочных функциях можно писать комментарии с помощью `#`, объявлять локальные переменные с
`mut`, использовать `for` и `if` для построения логики.

## pub и автоматическое связывание

В модуле функции, объявленные с ключевым словом `pub`, могут быть импортированы и использованы
другими модулями. Что ещё интереснее, **функции `pub` автоматически связываются с типами,
определёнными в том же файле**, что позволяет вызывать их в ООП-стиле.

```yaoxiang
// point.yx

// Определение типа
Point: Type = { x: Float, y: Float }

// Функция pub: компилятор автоматически связывает её как Point.distance
pub distance: (p1: Point, p2: Point) -> Float = {
    dx = p1.x - p2.x
    dy = p1.y - p2.y
    return (dx * dx + dy * dy).sqrt()
}

// Оба способа вызова допустимы
p1 = Point(3.0, 4.0)
p2 = Point(1.0, 2.0)

d1 = distance(p1, p2)       // Функциональный вызов
d2 = p1.distance(p2)        // Вызов в ООП-стиле (синтаксический сахар)
```

Когда компилятор видит `pub distance(p1: Point, p2: Point)` и обнаруживает, что `Point` определён в
том же файле, он автоматически создаёт связывание `Point.distance`. Вам не нужно писать никакого
дополнительного кода `impl`.

## Краткий справочник

```yaoxiang
// ── Сводка синтаксиса определения функций ──

// Форма выражения (самая распространённая)
add: (a: Int, b: Int) -> Int = a + b

// Форма блока кода (многошаговая логика)
factorial: (n: Int) -> Int = {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

// Функция без параметров (самая краткая)
main: () -> Void = { print("Hello!") }

// С параметрами — сигнатура опущена
double = (x: Int) => x * 2

// С параметрами — заголовок лямбды опущен (рекомендуется)
triple: (x: Int) -> Int = x * 3

// pub-экспорт + автоматическое связывание
pub add: (a: Int, b: Int) -> Int = a + b

// ── Синтаксис вызова ──

result = add(1, 2)          // Позиционные аргументы
result = add(a: 1, b: 2)    // Именованные аргументы
result = add(1, b: 2)       // Смешанный вызов (позиционные первыми)
```

## Итоги

Вы освоили ключевые знания о функциях в YaoXiang:

- **Единый синтаксис**: `name: (params) -> Return = body`, имеющий общую основу с объявлением
  переменных `name: type = value`
- **Форма выражения**: `= expr`, значение выражения сразу становится возвращаемым, `return` не
  требуется
- **Форма блока кода**: `= { ...; return expr }`, внутри блока требуется явный `return`
- **Аннотация типов параметров**: типы должны быть указаны хотя бы в одном из мест — в сигнатуре или
  в заголовке лямбды; рекомендуется указывать в сигнатуре
- **Вызов**: позиционные или именованные аргументы, порядок именованных произвольный
- **Автоматическое связывание pub**: функции `pub` автоматически связываются с типами того же файла,
  поддерживается вызов вида `obj.method()`
- **Самая краткая форма без параметров**: `name = { ... }`, компилятор автоматически выводит
  `() -> Void`

Следующим шагом вы можете перейти к главе [Управление потоком](./control-flow.md), чтобы узнать, как
использовать `if`, `for` и `while` внутри функций.
