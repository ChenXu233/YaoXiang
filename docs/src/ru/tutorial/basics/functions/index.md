# Определение и вызов функций

В предыдущей главе вы научились объявлять переменные. Эта глава познакомит вас с основой YaoXiang —
функциями. Синтаксис функций в YaoXiang использует ту же модель `name: type = value`, что и
объявление переменных, так что вы почувствуете знакомые нотки.

## Функция — это Lambda

Начнём с самого важного понятия: **в YaoXiang функция по сути является lambda-выражением**. Никаких
специальных ключевых слов `fn`, никаких сложных церемоний. Определить функцию — значит дать имя
lambda-выражению.

```
# Любая функция по сути является комбинацией этих четырёх частей:
name: (params) -> Return = body
 ^       ^        ^        ^
 |       |        |        +-- Тело функции (lambda-выражение или блок кода)
 |       |        +-- Тип возвращаемого значения
 |       +-- Список параметров (сигнатура)
 +-- Имя функции
```

Это полностью согласуется с изученной ранее моделью `name: type = value` — просто здесь «тип»
оказывается функциональным типом.

## Форма выражения: прямое возвращение значения

Самая простая функция не требует ключевого слова `return`. Когда тело функции представляет собой
одно выражение, оно напрямую становится возвращаемым значением:

```yaoxiang
// Форма выражения — прямое возвращение значения, без return
add: (a: Int, b: Int) -> Int = a + b
square: (x: Int) -> Int = x * x
greet: (name: String) -> String = "你好, " + name
```

Вызовем их:

```yaoxiang
sum = add(3, 5)          // sum = 8
sq = square(4)           // sq = 16
msg = greet("世界")       // msg = "你好, 世界"
```

Это называется **формой выражения**. Когда тело функции является выражением (а не блоком кода
`{ }`), его значение напрямую становится возвращаемым значением функции. Писать `return` не нужно, а
если написать — это будет ошибкой.

```yaoxiang
// Правильно: выражение напрямую становится возвращаемым значением
double: (x: Int) -> Int = x * 2

// Ошибка: в форме выражения писать return — синтаксическая ошибка
// double: (x: Int) -> Int = return x * 2   // ❌
```

---

## Форма блока кода: явный return

Когда функция содержит несколько шагов вычисления, оберните тело функции в блок `{ }`. **В блоке
кода для возврата значения необходимо использовать оператор `return`**:

```yaoxiang
// Форма блока кода — для возврата значения нужно использовать return
factorial: (n: Int) -> Int = {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

// Вычисление результата
f5 = factorial(5)        // f5 = 120
```

Правило простое: **форма выражения возвращает значение напрямую; форма блока кода требует явного
`return`**. Если в блоке кода забыть написать `return`, функция по умолчанию вернёт `Void`.

```yaoxiang
// Внимание: в этой функции есть ошибка
// bad_add: (a: Int, b: Int) -> Int = {
//     a + b   // Нет return! Блок по умолчанию вернёт Void, но сигнатура требует Int → ошибка типа
// }

// Правильное написание
good_add: (a: Int, b: Int) -> Int = {
    return a + b
}
```

Итог:

| Форма           | Синтаксис             | Способ возврата значения    |
| --------------- | --------------------- | --------------------------- |
| Форма выражения | `name: ... = expr`    | Значение выражения напрямую |
| Форма блока     | `name: ... = { ... }` | Необходим явный `return`    |

## Определение параметров

### Базовые параметры

Параметры записываются в сигнатуре функции, каждый параметр может быть аннотирован типом:

```yaoxiang
// Два параметра, оба аннотированы типами
multiply: (a: Int, b: Int) -> Int = a * b
```

### Тип параметра должен быть указан в сигнатуре или в заголовке Lambda

Правило в YaoXiang: **при наличии входных параметров их типы должны быть явно указаны как минимум в
одном из мест — в сигнатуре или в заголовке Lambda**. Если типы опущены в обоих местах, компилятор
отклонит такой код.

```yaoxiang
// Способ 1: типы параметров в сигнатуре (заголовок Lambda опущен)
add: (a: Int, b: Int) -> Int = a + b

// Способ 2: типы параметров в заголовке Lambda (сигнатура опущена)
add = (a: Int, b: Int) => a + b

// Способ 3: полная форма (и сигнатура, и заголовок Lambda присутствуют)
add: (a: Int, b: Int) -> Int = (a, b) => a + b

// Ошибка: типы не указаны ни в одном из мест
// add = (a, b) => a + b   // ❌ Компилятор не может вывести типы параметров
```

**Рекомендуется использовать способ 1** — типы параметров указываются в сигнатуре, заголовок Lambda
опускается. Это самая лаконичная и понятная запись.

## Возвращаемое значение

Тип возвращаемого значения функции записывается после `->`. Стрелка `->` — это признак
функционального типа, её нельзя опускать (без неё выражение будет разобрано как другой тип).

```yaoxiang
// Возвращает Int
add_one: (x: Int) -> Int = x + 1

// Возвращает String
to_string: (n: Int) -> String = n.to_string()

// Возвращает Void (без возвращаемого значения)
log: (msg: String) -> Void = {
    print(msg)    // нет return, по умолчанию возвращается Void
}
```

Тип возвращаемого значения также можно опустить, позволив HM-выводу типов сделать работу за вас:

```yaoxiang
// Компилятор выводит тип возвращаемого значения как Int
add = (a: Int, b: Int) => a + b

// Компилятор выводит тип возвращаемого значения как String
greet = (name: String) => "你好, " + name
```

## Вызов функций

### Позиционные аргументы

Самый базовый способ вызова — передача аргументов по порядку:

```yaoxiang
add: (a: Int, b: Int) -> Int = a + b

result = add(1, 2)        // result = 3
```

Формальное определение вызова функции в спецификации синтаксиса:

```
Expr '(' ArgList? ')'
```

В бытовом языке это означает: после выражения идёт пара круглых скобок, внутри которых может
располагаться список аргументов.

### Именованные аргументы

Помимо передачи аргументов по позиции, YaoXiang также поддерживает **именованные аргументы** —
значение указывается с именем параметра, порядок не имеет значения:

```yaoxiang
// Именованные аргументы — после имени параметра идёт двоеточие, затем значение
result = add(a: 3, b: 5)     // result = 8
result = add(b: 5, a: 3)     // порядок произвольный, результат одинаков

// Можно смешивать с позиционными аргументами, но позиционные должны идти первыми
result = add(3, b: 5)        // OK
```

Именованные аргументы делают вызов более читаемым, что особенно полезно при большом количестве
параметров:

```yaoxiang
// Сигнатура функции
send: (to: String, title: String, body: String) -> Void = {
    print("发送给: " + to)
    print("标题: " + title)
    print("正文: " + body)
)

// Именованные аргументы делают намерение вызова очевидным
send(
    to: "alice@example.com",
    title: "会议通知",
    body: "明天下午 3 点开会"
)
```

## Функции без параметров

Для функций, не требующих параметров, список параметров можно опустить:

```yaoxiang
// Полная форма: явное объявление пустого списка параметров
hello: () -> Void = {
    print("Hello!")
}

// Самая краткая форма: сигнатура опущена, компилятор автоматически выводит () -> Void
hello = {
    print("Hello!")
}

// Вызов функции без параметров
hello()
```

Функция `main` — самый распространённый пример функции без параметров:

```yaoxiang
// Несколько вариантов написания функции main

// Полная форма
main: () -> Void = {
    print("Hello, YaoXiang!")
}

// Самая краткая форма (рекомендуется)
main: () -> Void = {
    print("Hello, YaoXiang!")
}
```

## Многострочные функции

Когда логика функции достаточно сложна, для организации кода используется форма блока. YaoXiang
требует отступ в 4 пробела:

```yaoxiang
// Многошаговое вычисление
calculate_stats: (numbers: List(Int)) -> Float = {
    // Объявление локальных переменных
    mut total = 0
    mut count = 0

    // Цикл для накопления
    for n in numbers {
        total = total + n
        count = count + 1
    }

    // Избежание деления на ноль
    if count == 0 {
        return 0.0
    }

    // Возврат среднего значения
    return total:as(Float) / count:as(Float)
}
```

В многострочных функциях можно использовать `#` для комментариев, объявлять локальные переменные с
`mut`, использовать `for` и `if` для построения логики.

## pub и автоматическое связывание

В модуле функции, объявленные с ключевым словом `pub`, могут быть импортированы и использоваться
другими модулями. Что ещё интереснее, **функции `pub` автоматически привязываются к типам,
определённым в том же файле**, что позволяет вызывать их в ООП-стиле.

```yaoxiang
// point.yx

// Определение типа
Point: Type = { x: Float, y: Float }

// pub-функция: компилятор автоматически привязывает её к Point.distance
pub distance: (p1: Point, p2: Point) -> Float = {
    dx = p1.x - p2.x
    dy = p1.y - p2.y
    return (dx * dx + dy * dy).sqrt()
}

// Оба способа вызова работают
p1 = Point(3.0, 4.0)
p2 = Point(1.0, 2.0)

d1 = distance(p1, p2)       // Вызов в функциональном стиле
d2 = p1.distance(p2)        // Вызов в ООП-стиле (синтаксический сахар)
```

Когда компилятор видит `pub distance(p1: Point, p2: Point)` и обнаруживает, что `Point` определён в
том же файле, он автоматически создаёт привязку `Point.distance`. Вам не нужно писать никакого
дополнительного кода `impl`.

## Краткий справочник

```yaoxiang
// ── Обзор синтаксиса определения функций ──

// Форма выражения (наиболее часто используемая)
add: (a: Int, b: Int) -> Int = a + b

// Форма блока кода (многошаговая логика)
factorial: (n: Int) -> Int = {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}

// Функция без параметров (самая краткая)
main: () -> Void = { print("Hello!") }

// С параметрами — сигнатура опущена
double = (x: Int) => x * 2

// С параметрами — заголовок Lambda опущен (рекомендуется)
triple: (x: Int) -> Int = x * 3

// pub-экспорт + автоматическое связывание
pub add: (a: Int, b: Int) -> Int = a + b

// ── Синтаксис вызова ──

result = add(1, 2)          // Позиционные аргументы
result = add(a: 1, b: 2)    // Именованные аргументы
result = add(1, b: 2)       // Смешанные (позиционные первые)
```

## Итоги

Вы освоили основные знания о функциях в YaoXiang:

- **Единый синтаксис**: `name: (params) -> Return = body`, имеющий общие корни с объявлением
  переменных `name: type = value`
- **Форма выражения**: `= expr`, значение выражения напрямую становится возвращаемым, без `return`
- **Форма блока кода**: `= { ...; return expr }`, внутри блока необходим явный `return`
- **Аннотация типов параметров**: типы должны быть указаны как минимум в одном из мест — в сигнатуре
  или в заголовке Lambda, рекомендуется указывать в сигнатуре
- **Вызов**: позиционные или именованные аргументы, именованные — в произвольном порядке
- **Автоматическое связывание pub**: функции `pub` автоматически связываются с типами из того же
  файла, поддерживая вызов `obj.method()`
- **Самая краткая форма без параметров**: `name = { ... }`, компилятор автоматически выводит
  `() -> Void`

Следующим шагом вы можете перейти к главе [Поток управления](./control-flow.md), чтобы узнать, как
использовать `if`, `for` и `while` внутри функций.
