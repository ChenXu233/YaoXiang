# Объявление переменных

В этой главе рассматривается основной синтаксис объявления переменных в YaoXiang. Если у вас есть опыт работы с другими языками программирования, вы заметите, что система переменных YaoXiang очень проста — все объявления используют единую синтаксическую модель.

## Единая модель синтаксиса

Философия дизайна YaoXiang — «всё едино». Объявление целого числа, определение функции или создание типа — всё использует один и тот же синтаксис:

```
name: type = value
```

Это ключевой принцип дизайна YaoXiang. Несколько примеров помогут понять эту согласованность:

```yaoxiang
// Объявление переменной
x: Int = 42
name: String = "YaoXiang"

// Определение функции
add: (a: Int, b: Int) -> Int = a + b

// Определение типа
Point: Type = { x: Float, y: Float }
```

В формальной грамматике объявление переменной определяется так:

```
('mut')? Identifier (':' TypeExpr)? '=' Expr
```

Переводя на человеческий язык: может быть необязательное ключевое слово `mut`, затем имя переменной, затем необязательное `: тип`, и в конце `= значение`. Эта структура проходит через весь язык — учишь один раз, хватает надолго.

## Неизменяемые переменные (поведение по умолчанию)

В YaoXiang все переменные **неизменяемы по умолчанию**. После присваивания значения изменить его нельзя. Это сделано для безопасности языка.

```yaoxiang
x = 10
// x = 20   // Ошибка компиляции! x неизменяем
```

При объявлении с помощью `=` компилятор ищет переменную с таким же именем во внешних областях видимости. Если находит — присваивает ей значение; если не находит — создаёт новую неизменяемую переменную в текущей области видимости.

```yaoxiang
x = 1       // Во внешней области x нет, поэтому создаётся новая переменная
x = 2       // Найдена внешняя x, попытка присваивания → Ошибка компиляции! x неизменяем
```

Это может показаться неинтуитивным — если вы изучали другие языки, может возникнуть вопрос: «Раз нашёл, почему нельзя присвоить?». Причина в том, что YaoXiang ставит безопасность на первое место: неизменяемость по умолчанию означает, что вам не нужно беспокоиться о случайном изменении переменной в каком-то уголке кода.

## mut — изменяемые переменные

Когда действительно нужно изменить переменную, используйте ключевое слово `mut` для явного объявления:

```yaoxiang
mut counter = 0
counter = counter + 1   // Можно изменить
counter = 100           // Тоже можно
```

У `mut` есть несколько важных правил:

**Правило первое**: `mut` — это явное создание новой переменной, компилятор не ищет одноимённую переменную во внешних областях видимости.

```yaoxiang
mut x = 10      // создаёт новую изменяемую переменную x в текущей области
mut x = 20      // Ошибка компиляции! x уже объявлена в той же области
```

**Правило второе**: переменная, объявленная с `mut`, не может иметь то же имя, что и переменная во внешней области видимости (запрет затенения).

```yaoxiang
x = 10
{
    mut x = 20   // Ошибка компиляции! x уже объявлена во внешней области, затенение запрещено
}
```

**Правило третье**: в одной области видимости каждое имя можно объявить только один раз — независимо от того, используется `=` или `mut`.

```yaoxiang
x = 10
mut x = 20   // Ошибка компиляции! x уже объявлена
```

Эти правила гарантируют, что каждое имя переменной уникально в текущей области видимости, и вы никогда не столкнётесь с путаницей «какая именно переменная имеется в виду».

## Вывод типов vs явные аннотации типа

YaoXiang использует алгоритм вывода типов Хиндли-Милнера (HM). Компилятор может автоматически определить тип по записанному значению, поэтому в большинстве случаев не нужно указывать тип вручную.

```yaoxiang
x = 42              // Компилятор выводит Int
name = "YaoXiang"   // Выводится String
pi = 3.14159        // Выводится Float
is_valid = true     // Выводится Bool
```

Когда нужно явно указать тип (например, для улучшения читаемости кода или когда компилятор не может вывести тип), используется синтаксис `: Type`:

```yaoxiang
count: Int = 100
greeting: String = "Hello"
ratio: Float = 0.618
```

Оба варианта полностью эквивалентны. Можно начинать писать код без типов, а затем добавлять аннотации по необходимости. Это ускоряет прототипирование, но не снижает типобезопасность финального кода.

## Обзор базовых типов

В YaoXiang встроено несколько базовых типов, покрывающих большинство повседневных сценариев программирования.

### Int (целое число)

```yaoxiang
a = 42              // десятичное
b = 0o52            // восьмеричное (префикс 0o)
c = 0x2A            // шестнадцатеричное (префикс 0x)
d = 0b101010        // двоичное (префикс 0b)
e = 1_000_000       // можно использовать подчёркивания для удобства чтения
```

### Float (число с плавающей точкой)

```yaoxiang
pi = 3.14159
speed = 2.998e8         // научная нотация: 2.998 × 10^8
tiny = 1.6e-19
```

### String (строка)

```yaoxiang
name = "YaoXiang"
empty = ""              // пустая строка
escape = "Hello\nWorld" // поддержка экранирования: \n перевод строки, \t табуляция, \\ обратная косая, \" кавычка
unicode = "\u{4F60}\u{597D}"  // Unicode-экранирование
```

### Bool (логический тип)

```yaoxiang
is_ready = true
is_done = false
```

Логические значения обычно используются в условных конструкциях:

```yaoxiang
if is_ready {
    print("Начинаем обработку")
}
```

## Область видимости переменных

Область видимости определяет, где переменная доступна. Правила области видимости в YaoXiang очень просты: **каждый блок `{}` создаёт новую область видимости**.

### Основные правила

```yaoxiang
{
    x = 10
    print(x)   // можно обратиться: x в текущей области видимости
}
// print(x)    // ошибка: x за пределами области видимости
```

Внутренняя область видимости имеет доступ к переменным внешней области:

```yaoxiang
outer = "Я снаружи"
{
    print(outer)   // можно обратиться к outer из внешней области
    inner = "Я внутри"
}
// print(inner)    // ошибка: inner за пределами области видимости
```

### Область видимости параметров функции

```yaoxiang
greet: (name: String) -> Void = {
    print("Привет, " + name)
    // name доступна внутри этого тела функции
}
// name недоступна вне функции
```

### Блоки как выражения

Блок `{}` в YaoXiang также является выражением и может возвращать значение:

```yaoxiang
result = {
    x = 10
    y = 20
    return x + y   // возвращает 30 в вызывающую область видимости
}
// result равен 30
// x и y недоступны вне блока
```

Подробнее о возврате значений из блоков см. в главе о функциях. Пока запомните главное: **фигурные скобки создают область видимости, внутренняя область видимости видит внешнюю, а внешняя не видит внутреннюю**.

## Итоги

Вы освоили ключевые концепции системы переменных YaoXiang:

| Концепция             | Ключевой момент                                            |
| --------------------- | ---------------------------------------------------------- |
| Единая модель синтаксиса | `name: type = value`, переменные, функции, типы — всё одно |
| По умолчанию неизменяемо | после `x = 10` переменная `x` нельзя изменить              |
| Изменяемые переменные   | `mut` для явного объявления: `mut x = 10`                  |
| Запрет затенения        | одно имя в одной области видимости можно объявить только один раз |
| Вывод типов            | алгоритм HM выводит тип автоматически,也可以写 `: Type` для явного указания |
| Область видимости       | каждый `{}` создаёт область, внутренняя видит внешнюю, внешняя не видит внутреннюю |
