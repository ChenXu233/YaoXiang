# Объявление переменных

Эта глава знакомит с основным синтаксисом объявления переменных в YaoXiang. Если у вас есть опыт
работы с другими языками программирования, вы обнаружите, что система переменных в YaoXiang очень
лаконична — все объявления используют единую синтаксическую модель.

## Единая синтаксическая модель

Философия дизайна YaoXiang — «всё едино». Будь то объявление целого числа, определение функции или
создание типа — все они используют один и тот же синтаксис:

```
name: type = value
```

Это самая центральная концепция дизайна YaoXiang. Несколько примеров помогут вам ощутить эту
согласованность:

```yaoxiang
// Объявление переменной
x: Int = 42
name: String = "YaoXiang"

// Определение функции
add: (a: Int, b: Int) -> Int = a + b

// Определение типа
Point: Type = { x: Float, y: Float }
```

Формальное определение объявления переменной в спецификации синтаксиса:

```
('mut')? Identifier (':' TypeExpr)? '=' Expr
```

Проще говоря: может иметь необязательное ключевое слово `mut`, затем имя переменной, затем
необязательное `: тип`, и наконец `= значение`. Эта структура пронизывает весь язык — достаточно
выучить её один раз.

## Неизменяемые переменные (поведение по умолчанию)

В YaoXiang все переменные **по умолчанию неизменяемы**. После присваивания их нельзя изменить. Это
решение в пользу безопасности языка.

```yaoxiang
x = 10
// x = 20   // Ошибка компиляции! x является неизменяемым
```

Для переменных, объявленных с помощью `=`, компилятор ищет переменную с тем же именем по цепочке
областей видимости наружу. Если находит — присваивает ей значение; если не находит — создаёт новую
неизменяемую переменную в текущей области видимости.

```yaoxiang
x = 1       // Во внешней области видимости нет x, поэтому объявляется новая переменная
x = 2       // Найден внешний x, попытка присваивания → Ошибка компиляции! x неизменяем
```

Это может показаться контринтуитивным — если вы изучали другие языки, вы можете подумать: «Раз x
найден, почему нельзя присвоить значение?». Это потому что YaoXiang ставит безопасность на первое
место: неизменяемость по умолчанию означает, что вам не нужно беспокоиться о случайном изменении
переменной в каком-то уголке кода.

## mut — изменяемые переменные

Когда вам действительно нужно изменить переменную, используйте ключевое слово `mut` для явного
объявления:

```yaoxiang
mut counter = 0
counter = counter + 1   // можно изменить
counter = 100           // тоже можно
```

`mut` имеет несколько важных правил:

**Правило первое**: `mut` — это явное новое объявление, компилятор не ищет переменные с тем же
именем во внешних областях видимости.

```yaoxiang
mut x = 10      // Создаёт новую изменяемую переменную x в текущей области видимости
mut x = 20      // Ошибка компиляции! x уже объявлен в той же области видимости
```

**Правило второе**: переменные, объявленные с `mut`, не могут иметь то же имя, что и переменные во
внешней области видимости (запрет затенения).

```yaoxiang
x = 10
{
    mut x = 20   // Ошибка компиляции! x уже объявлен во внешней области, затенение запрещено
}
```

**Правило третье**: в одной области видимости каждое имя может быть объявлено только один раз —
независимо от того, используется `=` или `mut`.

```yaoxiang
x = 10
mut x = 20   // Ошибка компиляции! x уже объявлен
```

Эти правила гарантируют, что каждое имя переменной уникально в текущей области видимости, и вам
никогда не придётся гадать, на какую из одноимённых переменных ссылается код.

## Вывод типов против явных аннотаций типов

YaoXiang использует алгоритм вывода типов Хиндли-Милнера (HM). Компилятор может автоматически
вывести тип из записанного вами значения, и в большинстве случаев указывать тип вручную не
требуется.

```yaoxiang
x = 42              // Компилятор выводит Int
name = "YaoXiang"   // Выводится String
pi = 3.14159        // Выводится Float
is_valid = true     // Выводится Bool
```

Когда вы хотите явно указать тип (например, для повышения читаемости кода или когда компилятор не
может вывести тип), используйте синтаксис `: Type`:

```yaoxiang
count: Int = 100
greeting: String = "Hello"
ratio: Float = 0.618
```

Оба варианта записи полностью эквивалентны. Вы можете начать писать код без указания типов и
добавить аннотации типов при необходимости. Это делает разработку прототипов очень быстрой, при этом
не жертвуя типобезопасностью финального кода.

## Обзор основных типов

YaoXiang имеет несколько встроенных основных типов, охватывающих подавляющее большинство
повседневных задач программирования.

### Int (целое число)

```yaoxiang
a = 42              // десятичное
b = 0o52            // восьмеричное (префикс 0o)
c = 0x2A            // шестнадцатеричное (префикс 0x)
d = 0b101010        // двоичное (префикс 0b)
e = 1_000_000       // можно разделять цифры подчёркиванием для удобства чтения
```

### Float (число с плавающей запятой)

```yaoxiang
pi = 3.14159
speed = 2.998e8         // экспоненциальная запись: 2.998 × 10^8
tiny = 1.6e-19
```

### String (строка)

```yaoxiang
name = "YaoXiang"
empty = ""              // пустая строка
escape = "Hello\nWorld" // поддерживает экранирование: \n — перевод строки, \t — табуляция, \\ — обратная косая черта, \" — двойная кавычка
unicode = "\u{4F60}\u{597D}"  // экранирование Unicode
```

### Bool (логический)

```yaoxiang
is_ready = true
is_done = false
```

Логические значения обычно используются в условных операторах:

```yaoxiang
if is_ready {
    print("Начинаем обработку")
}
```

## Область видимости переменных

Область видимости определяет диапазон, в котором переменная доступна. Правила областей видимости в
YaoXiang очень просты: **каждый блок `{}` создаёт новую область видимости**.

### Базовые правила

```yaoxiang
{
    x = 10
    print(x)   // доступ: x находится в текущей области видимости
}
// print(x)    // ошибка: x не виден за пределами области видимости
```

Вложенная область может обращаться к переменным внешней области:

```yaoxiang
outer = "Я снаружи"
{
    print(outer)   // доступ к outer из внешней области
    inner = "Я внутри"
}
// print(inner)    // ошибка: inner не виден за пределами области видимости
```

### Область видимости параметров функции

```yaoxiang
greet: (name: String) -> Void = {
    print("Привет, " + name)
    // name виден внутри тела этой функции
}
// name не виден за пределами тела функции
```

### Блочные выражения

Блоки `{}` в YaoXiang также являются выражениями и могут возвращать значения:

```yaoxiang
result = {
    x = 10
    y = 20
    return x + y   // возвращает 30 во внешнюю область видимости
}
// значение result равно 30
// x и y не видны за пределами блока
```

Подробности о возвращаемых значениях блоков см. в последующей главе о функциях. Здесь нужно
запомнить только одно: **фигурные скобки создают область видимости, внутренняя видит внешнюю,
внешняя не видит внутреннюю**.

## Резюме

Вы освоили основные концепции системы переменных YaoXiang:

| Концепция                    | Ключевые моменты                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| Единая синтаксическая модель | `name: type = value` — используется для переменных, функций и типов                          |
| Неизменяемость по умолчанию  | после `x = 10` изменить x нельзя                                                             |
| Изменяемые переменные        | явное объявление с `mut`: `mut x = 10`                                                       |
| Запрет затенения             | одно имя может быть объявлено только один раз в одной области видимости                      |
| Вывод типов                  | автоматический вывод по алгоритму HM, либо явное указание `: Type`                           |
| Область видимости            | каждый `{}` создаёт область видимости: внутренняя видит внешнюю, внешняя не видит внутреннюю |
