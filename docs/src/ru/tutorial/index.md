# Добро пожаловать во вселенную YaoXiang!

> «Небытие порождает великий предел. Великий предел приходит в движение и рождает ян, успокаивается и рождает инь.» — Чжоу Дуньи «Рассуждение о диаграмме великого предела»

Здесь находится центр вселенной YaoXiang.

В восточной философии «яо» — это основной символ, составляющий гексаграммы, в котором заключены все изменения инь и ян. «Сян» — это внешнее проявление сущности вещей, у всего в мире есть свои закономерности.

**Язык программирования YaoXiang** — это попытка интегрировать эту древнюю мудрость в современную систему типов.

## Что такое YaoXiang?

Представьте, что вы собираете конструктор LEGO:

| Концепция    | LEGO             | YaoXiang              |
| ------------ | ---------------- | --------------------- |
| Базовая      | Блок             | **Тип**               |
| единица      |                  |                       |
| Способ       | Соединение       | **Функциональное     |
| объединения  |                  | отображение**        |
| Результат    | Самолёт,         | **Программа**         |
|              | автомобиль       |                       |

В мире YaoXiang **всё является типом**:

- Числа — это типы, текст — это типы
- Сами типы тоже являются типами (метатипы)
- Функции — это мосты от типа к типу

## Ключевые особенности

| Особенность      | YaoXiang              | Примеры в других языках |
| ---------------- | --------------------- | ---------------------- |
| Система типов    | Зависимые типы +      | TypeScript             |
|                  | параметрический       |                        |
|                  | полиморфизм           |                        |
| Управление       | Модель владения       | Rust                   |
| памятью          | (без GC)              |                        |
| Асинхронное      | Модель спавна         | async/await            |
| программирование | (бесшовный параллелизм)                   |
| Стиль синтаксиса | Стиль Python          | Python                 |

**В двух словах**: такая же плавность, как у Python, такая же безопасность, как у Rust.

## Кому подходит изучение YaoXiang?

- ✅ Исследователям, желающим понять проектирование языков программирования
- ✅ Любителям функционального программирования
- ✅ Практикам, интересующимся системами типов
- ✅ Разработчикам, желающим попробовать «бесшовный параллелизм»
- ❌ Командам, которым нужно срочно запускать проекты в продакшн (язык всё ещё на экспериментальной стадии)

> «Путь, который можно назвать, не есть постоянный путь.» — YaoXiang всё ещё находится на ранней стадии развития, и каждый первопроходец формирует его будущее.
