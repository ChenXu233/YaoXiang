# Добро пожаловать во Вселенную YaoXiang!

> «Бесконечность порождает Великий предел. Великий предел, двигаясь, рождает Ян, в покое — рождает Инь.» — Чжоу Дуньи «Рассуждение о диаграмме Великого предела»

Здесь находится центр Вселенной YaoXiang.

В восточной философии «яо» — это основной символ, составляющий гексаграммы, в котором заключены все изменения инь и ян. «Сян» — это внешнее проявление сущности вещей, у всего многообразия явлений есть свои закономерности.

**Язык программирования YaoXiang** — это попытка интегрировать эту древнюю мудрость в современную систему типов.

## Что такое YaoXiang?

Представьте, что вы собираете конструктор LEGO:

| Концепция   | LEGO           | YaoXiang            |
| ----------- | -------------- | ------------------- |
| Базовый блок | Блок LEGO      | **Тип**             |
| Способ соединения | Скрепление | **Функциональное отображение** |
| Результат   | Самолёт, машина | **Программа**       |

В мире YaoXiang **всё является типом**:

- Числа — это типы, текст — это типы
- Сами типы тоже являются типами (метатип)
- Функции — это мосты от типа к типу

## Основные возможности

| Возможность | YaoXiang              | Примеры из других языков |
| ----------- | --------------------- | ------------------------ |
| Система типов | Зависимые типы + параметрический полиморфизм | TypeScript |
| Управление памятью | Модель владения (без GC) | Rust |
| Асинхронное программирование | Модель spawn (незаметный параллелизм) | async/await |
| Стиль синтаксиса | Стиль Python | Python |

**Одной фразой**: так же плавно, как на Python, так же безопасно, как в Rust.

## Кому подходит YaoXiang?

- ✅ Исследователям, желающим понять проектирование языков программирования
- ✅ Любителям функционального программирования
- ✅ Практикам, интересующимся системами типов
- ✅ Разработчикам, желающим попробовать «незаметный параллелизм»
- ❌ Командам, которым нужно срочно запускать проекты в продакшен (язык всё ещё на экспериментальной стадии)

> «Путь, который можно выразить словами, не есть постоянный путь.» — YaoXiang всё ещё на ранней стадии развития, и каждый пионер формирует его будущее.
