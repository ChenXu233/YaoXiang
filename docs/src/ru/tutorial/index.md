# Добро пожаловать во вселенную YaoXiang!

> «Из небытия рождается Высший Предел. Когда Высший Предел приходит в движение, рождается Ян; когда
> он пребывает в покое, рождается Инь.» — Чжоу Дуньи, «Описание Великого Предела»

Это центр вселенной YaoXiang.

В восточной философии «яо» (爻) — это основной символ, из которого складываются триграммы и
гексаграммы; в нём заключены все превращения Инь и Ян. «Сян» (象) — это внешнее проявление сущности
вещей; во всех явлениях и вещах можно найти свои закономерности.

**Язык программирования YaoXiang** — это попытка воплотить эту древнюю мудрость в современной
системе типов.

## Что такое YaoXiang?

Представьте, что вы собираете конструктор Lego:

| Концепция             | Lego                | YaoXiang                |
| --------------------- | ------------------- | ----------------------- |
| Базовая единица       | Кирпичик            | **тип**                 |
| Способ комбинирования | Соединение          | **отображение функций** |
| Готовый продукт       | Самолёт, автомобиль | **программа**           |

В мире YaoXiang **всё является типом**:

- Числа — это тип, текст — это тип
- Сам тип тоже является типом (метатип)
- Функция — это мост от типа к типу

## Основные особенности

| Особенность                  | YaoXiang                                     | Примеры других языков |
| ---------------------------- | -------------------------------------------- | --------------------- |
| Система типов                | Зависимые типы + параметрический полиморфизм | TypeScript            |
| Управление памятью           | Модель владения (без GC)                     | Rust                  |
| Асинхронное программирование | Модель spawn (невидимая конкурентность)      | async/await           |
| Стиль синтаксиса             | В духе Python                                | Python                |

**Одной фразой**: так же плавно, как Python; так же безопасно, как Rust.

## Кому подходит изучение YaoXiang?

- ✅ Исследователям, желающим разобраться в дизайне языков программирования
- ✅ Любителям функционального программирования
- ✅ Практикам, увлечённым системами типов
- ✅ Разработчикам, которым хочется испытать «невидимую конкурентность»
- ❌ Командам, которым нужно немедленно запускать проект в продакшн (язык всё ещё на
  экспериментальной стадии)

> «Дао, которое может быть названо, — не есть вечное Дао.» — YaoXiang всё ещё находится на ранней
> стадии исследования, и каждый первопроходец формирует его будущее.
