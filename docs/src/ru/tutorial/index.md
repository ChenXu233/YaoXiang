# Добро пожаловать во вселенную YaoXiang!

> «Из Беспредельного рождается Предельное. Когда Предельное движется, рождается Ян; когда пребывает
> в покое — рождается Инь.» — Чжоу Дуньи, «Описание схемы Предельного»

Здесь находится центр вселенной YaoXiang.

В восточной философии «яо» (爻) — основной символ, из которого складываются гексаграммы; в нём
заключены все превращения Инь и Ян. «Сян» (象) — внешнее проявление сущности вещей; у каждого из
десяти тысяч явлений есть свои закономерности.

**Язык программирования YaoXiang** — это попытка воплотить эту древнюю мудрость в современной
системе типов.

## Что такое YaoXiang?

Представьте, что вы собираете конструктор LEGO:

| Понятие               | LEGO                | YaoXiang                |
| --------------------- | ------------------- | ----------------------- |
| Базовый элемент       | Блок                | **Тип**                 |
| Способ комбинирования | Соединение          | **Отображение функций** |
| Готовый продукт       | Самолёт, автомобиль | **Программа**           |

В мире YaoXiang **всё является типом**:

- Число — это тип, текст — это тип
- Сам тип тоже является типом (метатип)
- Функция — это мост от типа к типу

## Ключевые особенности

| Особенность                  | YaoXiang                                     | Примеры других языков |
| ---------------------------- | -------------------------------------------- | --------------------- |
| Система типов                | Зависимые типы + параметрический полиморфизм | TypeScript            |
| Управление памятью           | Модель ownership (без GC)                    | Rust                  |
| Асинхронное программирование | Модель spawn (прозрачная конкурентность)     | async/await           |
| Стиль синтаксиса             | Стиль Python                                 | Python                |

**Одной фразой**: удобство Python, безопасность Rust.

## Кому подходит изучение YaoXiang?

- ✅ Исследователям, интересующимся дизайном языков программирования
- ✅ Любителям функционального программирования
- ✅ Практикам, интересующимся системами типов
- ✅ Разработчикам, желающим испытать «прозрачную конкурентность»
- ❌ Командам, которым нужно немедленно внедрять язык в продакшн (язык всё ещё на экспериментальной
  стадии)

> «Дао, которое может быть названо, — не вечное Дао.» — YaoXiang всё ещё находится на ранней стадии
> исследования; каждый первопроходец формирует его будущее.
