# 警告码

 本页由 `scripts/docs/gen-error-code-docs.py` 从 `src/util/diagnostic/codes/` 的 `define_codes!` 注册表与 `locales/zh.json` 生成，请勿手工编辑。改文案请改 `locales/*.json`，改码表请改 `define_codes!`，然后重跑 `python scripts/docs/gen-error-code-docs.py`。

警告码以 `W` 开头，提示代码中可能存在的问题；默认发射级别为 warn，不会阻止编译。例外：`W1090` 的发射级别为 error（2026-10-13 用户裁决的同码升 E，见其条目说明），触发即计入 error_count 并改变退出码，会阻止编译。当前注册表共 **12** 个警告码，完整索引见[错误码首页](../error-code/index.md)。

## 配置

可以通过 `yaoxiang.toml` 配置死代码警告的行为：

```toml
[lint]
# 死代码警告级别：off | warn | deny
dead-code = "warn"
```

- `off`：禁用警告
- `warn`：显示警告（默认）
- `deny`：将警告视为错误，阻止编译

- **帮助**：本地模块解析优先级最高（RFC-014）：'./src/{module}' 覆盖 .yaoxiang/vendor/ 中的依赖包 '{dependency}'。若遮蔽非本意请重命名本地模块；可用 --deny-shadowing 将其升级为错误
- **发射点**：`src/driver/arms.rs:653`、`src/util/diagnostic/command.rs:78`

### W1007：模块导入环

- **类别**：`Warning`
- **span 豁免**：否
- **模板**：`模块导入环 {cycle}：环内初始化顺序不可判定，环内先后只按路径字典序作确定性约定（非语义保证）`
- **帮助**：初始化顺序按 use 依赖的拓扑序决定；环内先后只有「环内路径字典序」这一确定性约定，不是语义保证。打破环（把环上某条 use 移出环，或改为函数体里的延迟求值）即可让初始化顺序可判定。与 E3019 的分工：E3019 判单元内顶层绑定之间的初始化成环，本码判模块之间的导入成环。
- **发射点**：`src/driver/arms.rs:1752`

### W1081：终止性义务未判定

- **span 豁免**：否

- **帮助**：安装 Z3 求解器后重新检查，以获得终止性判定；「未判定」不等于「不终止」，但义务的判定被跳过了
- **发射点**：`src/frontend/core/typecheck/checker.rs:1534`

### W1082：所有权分析降级

- **类别**：`Warning`
- **span 豁免**：否
- **模板**：`所有权分析降级：本次编译没有函数体检查器（类型账本与调用点所有权表缺失），所有权判定按空账本进行、不检测借用冲突`
- **帮助**：这是编译器内部的阶段契约缺陷，不是你的程序写错了：所有权层运行时拿不到函数体检查器提供的类型账本与调用点所有权表，于是「什么都不冲突」地放行——借用冲突检查被整体跳过。请把这条诊断连同最小复现程序报成 issue。
- **发射点**：`src/frontend/core/typecheck/checker.rs:1620`

### W1090：义务已产出但无消费者

- **类别**：`Warning`
- **span 豁免**：是
- **模板**：`义务字段 \`{field}\` 在 {file} 已产出但从未被消费：{detail}`
- **帮助**：这是编译器内部的阶段契约缺陷，不是你的程序写错了：某阶段产出的义务字段没有被下一阶段读取，义务的效果可能已被静默丢弃。请把这条诊断连同字段名与文件路径报成 issue，并附最小复现程序。  本码属 **W 族**（码号前缀 W），但**发射级别为 error**：2026-10-13 用户裁决（WBS 4.3.2，RFC-039 D5 的终态）**同码升 E**——不新增 E 码（同一事实两个码即平行表示），发射级别由显式 severity 决定；触发即计入 error_count 并改变退出码。注意：健康程序零发射（义务全部有交付标记时不报），因此升级只在此缺陷真的出现时影响构建结果。
- **发射点**：`src/driver/obligations.rs:105`、`src/driver/obligations.rs:535`

## 警告级别

| 级别 | 效果 |
| --- | --- |
| `off` | 完全禁用此类警告 |
| `warn` | 显示警告但继续编译（默认） |
| `deny` | 将警告视为错误，阻止编译 |

## 与错误码的区别

- **错误（`E` 前缀）**：阻止编译，必须修复。
- **警告（`W` 前缀）**：提示潜在问题；默认发射级别为 warn，可选择修复。例外：`W1090` 发射级别为 error，触发即计入 error_count 并改变退出码，会阻止编译，必须修复（见其条目说明）。

## 死代码告警的判定口径

`W1001`–`W1005` 报的是**未使用的私有**（非 `pub`）函数 / 类型 / 变量 / 方法。`pub` 声明是对外接口，编译器无从得知外部是否有消费者，因此永不触发这些告警（#321 定案 B）。若看到「未使用」的告警，去掉对应的 `pub` 即可消除；反过来，需要被外部调用的声明请保留 `pub`。
