# while ループ

`for` は「既知のコレクションを走査する」ような場面に適しており、`while`
は別の状況——**何回ループするかわからないが、いつ停止すべきかだけわかっている**——に適しています。

## 基本構文

文法仕様における `while` 文の定義：

```
while Expr Block
```

構造はとてもシンプルです。`while`
の後に条件式を書き、その後にループ本体のコードブロックを書きます。条件が `true`
である限り、ループ本体は繰り返し実行されます。

```yaoxiang
mut count = 1

while count <= 5 {
    print(count)
    count = count + 1
}
// 出力：1 2 3 4 5
```

ここで `mut count` と変数を宣言している点に注目してください。`count`
はループ内で変更する必要があるためです。もし `count = 1`（不変）と書くと、ループ本体内の
`count = count + 1` でエラーになります。

## while の実行フロー

`while` ループの実行ステップは以下のとおりです。

1. 条件式を評価する
2. 条件が `true` なら、ループ本体を実行し、ステップ 1 に戻る
3. 条件が `false` なら、ループを終了し、後のコードに進む

条件は**各イテレーションの開始前**に評価されます。最初から条件が `false`
であれば、ループ本体は一度も実行されません。

```yaoxiang
mut n = 0
while n > 0 {
    print("このメッセージは決して表示されない")
    n = n - 1
}
// 条件 n > 0 は最初から false なので、ループ本体はスキップされる
```

## break：ループを途中で抜ける

時にはループの途中で抜け出す必要があります。たとえば、検索対象を見つけた場合などです。

```yaoxiang
numbers = [3, 7, 2, 9, 5]
mut found = false
mut index = 0

while index < 5 {
    if numbers[index] == 9 {
        found = true
        break      // 見つかったので、これ以上探す必要はない
    }
    index = index + 1
}

print("見つかりましたか？" + found.to_string())  // "見つかりましたか？true"
```

`break` を使うことで、プログラムは即座に現在のループを抜け出し、ループの後のコードに進みます。

## continue：現在のイテレーションをスキップする

`continue` は `break`
とは異なります。ループを抜けるのではなく、現在のイテレーションの残りの部分をスキップし、次の条件評価に直接進みます。

```yaoxiang
mut n = 0
while n < 5 {
    n = n + 1
    if n == 3 {
        continue   // 3 をスキップして表示しない
    }
    print(n)
}
// 出力：1 2 4 5
```

このコードでは、`n` が 3 のとき `continue` によって `println(n)` がスキップされ、`while n < 5`
の条件評価に直接戻ります。

## 無限ループを避ける

`while` を使う際は特に注意が必要です。ループ条件がいつかは `false`
になることを保証しないと、プログラムは永久に停止しなくなります。

```yaoxiang
// 危険！無限ループ——条件が常に true
// mut x = 1
// while x > 0 {
//     x = x + 1     // x はどんどん大きくなり、決して <= 0 にならない
// }

// 正しい例——明確な終了条件がある
mut x = 1
while x <= 5 {
    print(x)
    x = x + 1        // x は徐々に大きくなり、最終的に x > 5 でループ終了
}
```

## while を使って入力を読み取る

`while`
の典型的な使い方のひとつは、長さが不定の入力を処理することです。ユーザが何回入力するかわからないが、「入力が空なら停止する」という条件だけがわかっている場合です。

```yaoxiang
// 擬似コードの例——while の典型的な使い方を示す
// read_line は空行を読むと空文字列を返す
mut line = read_line()
while line != "" {
    process(line)
    line = read_line()
}
```

この「条件を評価 → データを処理 → 条件を更新」というパターンは、`while`
の中心的な使い方のパラダイムです。

## まとめ

| ポイント   | 説明                                                          |
| ---------- | ------------------------------------------------------------- |
| 適用場面   | ループ回数がわからず、終了条件だけがわかっている場合          |
| 構文       | `while 条件 { ... }`                                          |
| 実行フロー | 条件を先に評価し、その後ループ本体を実行する                  |
| `break`    | 即座にループを抜ける                                          |
| `continue` | 現在のイテレーションをスキップし、条件評価に戻る              |
| 注意事項   | 条件がいつかは `false` になることを保証し、無限ループを避ける |
