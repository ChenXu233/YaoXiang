# 制御フロー

前の章では関数を定義する方法を学びました。さて、ここではコードに「判断する」能力和「繰り返し実行する」能力を持たせる方法を学びます——これが**制御フロー**です。

YaoXiang は 5 種類の制御フロー構造を提供しており、それぞれが固有の役割を果たします。

| 制御フロー           | 用途         | 一言説明                                             |
| -------------------- | ------------ | ---------------------------------------------------- |
| `if-else-if-else`    | 条件判断     | 条件に応じて実行経路を選択する                       |
| `for`                | 走査ループ   | コレクションの各要素を順に処理する                   |
| `while`              | 条件ループ   | 条件が成立する限り繰り返す                           |
| `break` / `continue` | ループ制御   | ループを途中で抜ける、または現在の反復をスキップする |
| `match`              | パターン照合 | 値の構造に応じて分岐処理する                         |

まずは簡単に触れてみましょう。

```yaoxiang
// if は式であり、値を返すことができる
status = if score >= 60 { "及格" } else { "不及格" }

// for で範囲を走査する
for i in 0..5 {
    print(i)
}

// while で条件ループ
mut n = 3
while n > 0 {
    print(n)
    n = n - 1
}

// match でパターン照合
description = match number {
    0 => "零",
    1 => "一",
    _ => "其他",
}
```

これらの制御フロー構造はすべて**式**として使用できます——つまり、値を計算することができます。これは YaoXiang と多くの従来型言語との重要な違いです。
