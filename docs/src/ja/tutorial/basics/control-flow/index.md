# 制御フロー

前の章では関数の定義方法を学びました。次は、コードに「意思決定」と「反復実行」の能力を与える方法を学びます——これが**制御フロー**です。

YaoXiang は5つの制御フロー構造を提供し、それぞれが明確な役割を持ちます：

| 制御フロー           | 用途         | 一言説明                               |
| -------------------- | ------------ | -------------------------------------- |
| `if-else-if-else`    | 条件分岐     | 条件に応じて実行パスを選択             |
| `for`                | 反復ループ   | コレクションの各要素を順に処理         |
| `while`              | 条件ループ   | 条件が成立している間ループ             |
| `break` / `continue` | ループ制御   | ループを早期終了または現在のをスキップ |
| `match`              | パターン照合 | 値の構造に応じて分岐処理               |

第一印象を感じてみましょう：

```yaoxiang
// if は式であり、値を返せる
status = if score >= 60 { "合格" } else { "不合格" }

// for で範囲を反復
for i in 0..5 {
    print(i)
}

// while 条件ループ
mut n = 3
while n > 0 {
    print(n)
    n = n - 1
}

// match パターン照合
description = match number {
    0 => "零",
    1 => "一",
    _ => "その他",
}
```

これらの制御フロー構造は式として使用できます——つまり、値を計算できます。これは YaoXiang と多くの従来言語の重要な違いです。
