# for ループ

一連の要素に対して個別に同じことを行いたい場合、`for` ループが最適なツールです。YaoXiang の `for`
ループは簡潔で精確に設計されています。

## 基本構文

文法仕様における `for` 文の形式定義：

```
for 'mut'? Identifier 'in' Expr Block
```

つまり、`for` で始まり、オプションの `mut`、続いてループ変数名、次に `in`
と反復対象の式、最後にループ本体のコードブロックです。

## 数値範囲の反復

最も一般的な使い方は `..` で範囲を作成し、`for` で反復することです：

```yaoxiang
// 0 から 4 まで（5 を含まない）
for i in 0..5 {
    print(i)
}
// 出力：0 1 2 3 4
```

`0..5`
は 0 から始まり（含）5 で終わる（含まない）範囲を表します。これはコンピュータサイエンス分野の一般的な慣例——半開区間です。

変数を使って範囲の始点と終点を定義することもできます：

```yaoxiang
start = 10
end = 15
for n in start..end {
    print(n)
}
// 出力：10 11 12 13 14
```

## リストの反復

`for` は数値範囲だけでなく、リストや配列などのコレクションも直接反復できます：

```yaoxiang
colors = ["红", "橙", "黄", "绿", "蓝"]

for color in colors {
    print("当前颜色: " + color)
}
// 出力：
// 当前颜色: 红
// 当前颜色: 橙
// ... 以下同様
```

## for 独特の意味：各イテレーションで新しいバインディングを作成

YaoXiang の `for`
ループには他の言語と異なる設計があります：**各イテレーションは同じ変数を変更するのではなく、新しいバインディングを作成します**。

表で理解すると：

| イテレーション | 起ここと                                                                     |
| -------------- | ---------------------------------------------------------------------------- |
| 第 1 回        | 新しいバインディング `i = 0` を作成し、本体実行後バインディング破棄          |
| 第 2 回        | 新しいバインディング `i = 1`（全新のバインディング）を作成し、本体実行後破棄 |
| 第 3 回        | 新しいバインディング `i = 2` を作成し、本体実行後破棄                        |
| ...            | ...                                                                          |
| ループ終了     | 範囲を使い切り、ループ終了                                                   |

つまり、各イテレーションのループ変数は独立した新しい値です。これは安全性に非常に役立ちます——ループ変数が誤って変更される心配がありません：

```yaoxiang
for i in 1..5 {
    // i = i + 1   // エラー：デフォルトでは不変、 i を変更できない
    print(i)
}
```

## for mut：変更が必要な場合は明示的に宣言

ループ本体内でループ変数を変更する必要がある場合（例えばアキュムレータとして）、`for mut`
を使います：

```yaoxiang
// for mut を使ってループ本体内でバインディングの変更を許可
for mut i in 0..5 {
    i = i * 2
    print(i)
}
// 出力：0 2 4 6 8
```

注意：`for mut` を使用しても、各イテレーションは依然として新しいバインディングです。`for mut`
は新しいバインディング自体を可変にするだけで、前のイテレーションの変更が次のイテレーションに引き継がれるわけではありません。

```yaoxiang
for mut i in 1..5 {
    i = i + 100
    print(i)        // 毎回 101, 102, 103, 104 を出力
}
// 各イテレーションで i は範囲値から始まり、前回の変更は次回に影響しない
```

## ループ変数は外側の変数をシャドーイングできない

YaoXiang では変数のシャドーイングは禁止されています。`for`
のループ変数は外側のスコープの変数と同じ名前にできません：

```yaoxiang
// 間違った例
i = 10
// for i in 1..5 {     // コンパイルエラー！i は既に外側で宣言されている
//     print(i)
// }

// 正しい書き方——別の名前にする
i = 10
for j in 1..5 {
    print(j)
}
```

このルールにより、「現在のコードの変数が実際にどれを指しているのか」で混乱することがなくなります。

## 他の言語との比較

| 言語     | for ループ変数の意味                 |
| -------- | ------------------------------------ |
| YaoXiang | 各イテレーションで新しい値をバインド |
| Rust     | 同じ変数を変更（mut が必要）         |
| Python   | 同じ変数を変更                       |
| C/C++    | 同じ変数を変更                       |

YaoXiang の設計は人間の直感により近い——「コレクションの各要素に対して何かを行う」——各要素は独立した存在です。

## まとめ

| ポイント           | 説明                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| 範囲の反復         | `for i in 0..5`、半開区間                                                  |
| コレクションの反復 | `for item in list`、要素を一つずつ取り出す                                 |
| バインディング意味 | 各イテレーションで新しいバインディングを作成、同じ変数を変更するのではない |
| デフォルト不変     | ループ変数は変更不可、事故を防止                                           |
| `for mut`          | 変更が必要な場合は明示的に宣言                                             |
| シャドーイング禁止 | ループ変数は外側の変数と同じ名前にできない                                 |
