# 変数宣言

この章では、YaoXiangにおける変数宣言の核となる構文を紹介します。他のプログラミング言語の経験があれば、YaoXiangの変数システムは非常に簡潔であると感じるでしょう——すべての宣言が同じ構文モデルを共有しています。

## 統一構文モデル

YaoXiangの設計哲学は「すべてが統一されている」です。整数の宣言、関数の定義、型の作成、いずれも同じ構文を使用します：

```
name: type = value
```

これはYaoXiangの最も重要な設計理念です。いくつかの例を見れば、この一貫性を実感できるでしょう：

```yaoxiang
// 変数宣言
x: Int = 42
name: String = "YaoXiang"

// 関数定義
add: (a: Int, b: Int) -> Int = a + b

// 型定義
Point: Type = { x: Float, y: Float }
```

構文仕様における変数宣言の形式定義は以下の通りです：

```
('mut')? Identifier (':' TypeExpr)? '=' Expr
```

分かりやすく言い換えると：オプションの`mut`キーワード、続いて変数名、次にオプションの`: 型`、最後に`= 値`となります。この構造は言語全体を通じて一貫しており、一度学べば十分です。

## 不変変数（デフォルトの動作）

YaoXiangでは、すべての変数は**デフォルトで不変**です。一度代入したら、二度と変更できません。これは言語の安全性を重視した設計です。

```yaoxiang
x = 10
// x = 20   // コンパイルエラー！x は不変です
```

`=`で宣言された変数に対して、コンパイラはスコープチェーンを外側に向かって検索し、同名の変数を探します。見つかれば代入し、見つからなければ現在のスコープに新しい不変変数を作成します。

```yaoxiang
x = 1       // 外側のスコープに x がないため、新しい変数として宣言
x = 2       // 外側の x が見つかった、代入を試みる → コンパイルエラー！x は不変
```

これは直感に反するように思えるかもしれません——他の言語を学んだことがあれば「見つかったのにどうして代入できないの？」と思うでしょう。これはYaoXiangが安全性を最優先しているためです：デフォルトで不変ということは、コードのどこかで変数が誤って変更される心配がないということです。

## mut 可変変数

変数を変更する必要がある場合は、`mut`キーワードを使って明示的に宣言します：

```yaoxiang
mut counter = 0
counter = counter + 1   // 変更可能
counter = 100           // これも可能
```

`mut`にはいくつかの重要なルールがあります：

**ルール1**：`mut`は明示的な新規宣言であり、コンパイラは外側のスコープで同名の変数を検索しません。

```yaoxiang
mut x = 10      // 現在のスコープに新しい可変変数 x を作成
mut x = 20      // コンパイルエラー！同じスコープ内で x は既に宣言されている
```

**ルール2**：`mut`で宣言された変数は、外側のスコープの変数と同名にできません（シャドーイング禁止）。

```yaoxiang
x = 10
{
    mut x = 20   // コンパイルエラー！x は外側で既に宣言されており、シャドーイングは許可されない
}
```

**ルール3**：同じスコープ内で、各名前は一度しか宣言できません——`=`でも`mut`でも関係ありません。

```yaoxiang
x = 10
mut x = 20   // コンパイルエラー！x は既に宣言されている
```

これらのルールにより、各スコープ内で変数名が一意であることが保証され、同名の変数がどれを指しているのかという混乱に遭遇することは決してありません。

## 型推論 vs 明示的な型注釈

YaoXiangはHindley-Milner（HM）型推論アルゴリズムを使用しています。コンパイラは記述された値から自動的に型を推論できるため、ほとんどの場合、手動で型を書く必要はありません。

```yaoxiang
x = 42              // コンパイラが Int と推論
name = "YaoXiang"   // String と推論
pi = 3.14159        // Float と推論
is_valid = true     // Bool と推論
```

型を明示的に記述したい場合（例えばコードの可読性を高めるためや、コンパイラが型を推論できない場合）は、`: Type`構文を使用します：

```yaoxiang
count: Int = 100
greeting: String = "Hello"
ratio: Float = 0.618
```

両方の書き方は完全に等価です。型を省略してコードを書き始め、必要に応じて型注釈を追加することができます。これにより、プロトタイプの開発が非常に速くなり、最終的なコードの型安全性を損なうこともありません。

## 基本型一覧

YaoXiangには、日常のプログラミングのほとんどのシナリオをカバーするいくつかの基本型が組み込まれています。

### Int（整数型）

```yaoxiang
a = 42              // 十進数
b = 0o52            // 八進数（0o プレフィックス）
c = 0x2A            // 十六進数（0x プレフィックス）
d = 0b101010        // 二進数（0b プレフィックス）
e = 1_000_000       // アンダースコアで数字を区切ることができ、可読性が向上
```

### Float（浮動小数点型）

```yaoxiang
pi = 3.14159
speed = 2.998e8         // 科学的記数法：2.998 × 10^8
tiny = 1.6e-19
```

### String（文字列型）

```yaoxiang
name = "YaoXiang"
empty = ""              // 空文字列
escape = "Hello\nWorld" // エスケープ対応：\n 改行、\t タブ、\\ バックスラッシュ、\" ダブルクォート
unicode = "\u{4F60}\u{597D}"  // Unicode エスケープ
```

### Bool（ブール型）

```yaoxiang
is_ready = true
is_done = false
```

ブール値は通常、条件判定に使用されます：

```yaoxiang
if is_ready {
    print("処理開始")
}
```

## 変数スコープ

スコープは変数の可視範囲を決定します。YaoXiangのスコープルールは非常にシンプルです：**各`{}`ブロックが新しいスコープを作成する**。

### 基本ルール

```yaoxiang
{
    x = 10
    print(x)   // アクセス可能：x は現在のスコープ内にある
}
// print(x)    // エラー：x はスコープ外では見えない
```

内側のスコープから外側の変数にアクセスできます：

```yaoxiang
outer = "私は外側にいます"
{
    print(outer)   // 外側の outer にアクセス可能
    inner = "私は内側にいます"
}
// print(inner)    // エラー：inner はスコープ外では見えない
```

### 関数パラメータのスコープ

```yaoxiang
greet: (name: String) -> Void = {
    print("こんにちは, " + name)
    // name はこの関数本体内で見える
}
// name は関数の外側では見えない
```

### ブロック式

YaoXiangの`{}`ブロックは式でもあり、値を返すことができます：

```yaoxiang
result = {
    x = 10
    y = 20
    return x + y   // 30 を外側のスコープに返す
}
// result の値は 30
// x と y はブロック外では見えない
```

ブロックの戻り値の詳細については、後続の関数の章を参照してください。ここで覚えておく必要があるのは：**波括弧はスコープを作成し、内側から外側は見えるが、外側から内側は見えない**ということです。

## まとめ

YaoXiangの変数システムの核となるコンセプトを習得しました：

| コンセプト         | 要点                                                       |
| ------------------ | ---------------------------------------------------------- |
| 統一構文モデル     | `name: type = value`、変数、関数、型すべてに使用           |
| デフォルトで不変   | `x = 10` の後、`x` は変更不可                              |
| 可変変数           | `mut` を使って明示的に宣言 `mut x = 10`                    |
| シャドーイング禁止 | 同じスコープ内で同じ名前を一度しか宣言できない             |
| 型推論             | HM アルゴリズムが自動推論、`: Type` で明示も可能           |
| スコープ           | 各 `{}` がスコープを作成、内から外が見える、外から内は不可 |
