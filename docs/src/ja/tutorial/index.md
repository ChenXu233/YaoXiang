# YaoXiangユニバースへようこそ！

> 「無極より太極生ず。太極動すれば陽を生じ、静すれば陰を生ず。」—— 周敦颐『太極図説』

ここはYaoXiangユニバースの中心です。

東洋哲学において、「爻」は卦象を構成する基本的な記号であり、陰陽の変化がその中に尽くされています。「象」は事物の本質が外在に表れたものであり、万象万物、すべてに规律があります。

**爻象プログラミング言語**は、この古来の知恵を現代の型システムに溶け込ませようとする試みです。

## 爻象とは？

レゴブロックを組み立てることを想像してみてください：

| 概念         | レゴ           | 爻象               |
| ------------ | -------------- | ------------------ |
| 基本単位     | ブロック       | **型**             |
| 組み合わせ方 | 連結           | **関数マッピング** |
| 完成品       | 飛行機、自動車 | **プログラム**     |

爻象の世界では、**すべてが型**です：

- 数値は型であり、テキストも型です
- 型自体も型です（メタタイプ）
- 関数は型から型への橋です

## コア機能

| 機能                 | 爻象                                | 他言語の例  |
| -------------------- | ----------------------------------- | ----------- |
| 型システム           | 依存型 + パラメータ多相             | TypeScript  |
| メモリ管理           | 所有権モデル（GCなし）              | Rust        |
| 非同期プログラミング | spawnモデル（シームレスな並行処理） | async/await |
| 構文スタイル         | Python風                            | Python      |

**一言でまとめると**：Pythonのように流暢に、Rustのように安全に。
