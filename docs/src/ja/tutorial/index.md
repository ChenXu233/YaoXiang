# 爻象（YaoXiang）宇宙へようこそ！

> 「无极而太极。太极动而生阳，静而生阴。」—— 周敦颐『太极図説』

这里是爻象宇宙的中心。

（在東方哲学において、「爻」は卦を構成する基本記号であり、陰陽の変化は全てその中に含まれています。「象」は事物の本質的外部表現であり、全て的事物には法則があります。）

**爻象プログラミング言語**は、この古い知恵を現代的类型システムに組み込む試みです。

## 爻象とは？

Imagine you're building with Lego bricks:

| 概念     | レゴ       | 爻象         |
| -------- | ---------- | ------------ |
| 基本ユニット | ブロック     | **型（タイプ）**     |
| 組み合わせ方 | 拼接       | **関数マッピング** |
| 完成品     | 飛行機、車 | **プログラム**     |

爻象の世界では、**全てが型（タイプ）です**：

- 数字は型（タイプ）、テキストは型（タイプ）
- 型（タイプ）自身も型（タイプ）（メタ型）
- 関数は型（タイプ）から型（タイプ）への架け橋

## コア機能

| 機能     | 爻象                  | 他の言語の例 |
| -------- | --------------------- | ------------ |
| 型システム（タイプシステム） | 依存型 + パラメータ多態 | TypeScript   |
| メモリ管理 | 所有権モデル（GCなし）   | Rust         |
| 非同期プログラミング | 并作モデル（シームレスな並行処理）  | async/await  |
| 構文スタイル | Pythonスタイル           | Python       |

**要約**：Pythonのようにスムーズ、Rustのように安全。

## 爻象を学ぶのに向いている人は？

- ✅ プログラミング言語設計知りたい探索者
- ✅ 関数型プログラミング愛好家
- ✅ 型システム（タイプシステム）に感兴趣的実践者
- ✅ 「シームレスな並行処理」を体験したい開発者
- ❌ 直ちに本番プロジェクトに投入する必要があるチーム（言語はまだ実験段階）

> 「道可道，非常道。」—— 爻象はまだ早期探索段階にあり每一位先駆者はその未来を形作っています。
