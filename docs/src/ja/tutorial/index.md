# 爻象宇宙へようこそ！

> 「無極にして太極。太極動いて陽を生じ、静かにして陰を生ず。」—— 周敦颐『太極図説』

ここは爻象宇宙の中心です。

東洋哲学において、「爻」は卦象を構成する基本的な記号であり、陰陽の変化はすべてその中に宿っています。「象」は事物の本質が外在に現れたものであり、万象万物にはすべて法則があります。

**爻象プログラミング言語**は、この古来の智慧を現代の型システムに融合させる試みです。

## 爻象とは何か？

レゴブロックを組み立てることを想像してみてください：

| 概念         | レゴ       | 爻象               |
| ------------ | ---------- | ------------------ |
| 基本単位     | ブロック   | **型**             |
| 組み合わせ方 | 組み立て   | **関数マッピング** |
| 完成品       | 飛行機、車 | **プログラム**     |

爻象の世界では、**すべてが型**です：

- 数字は型であり、テキストは型です
- 型自体も型です（メタ型）
- 関数は型と型を繋ぐ橋です

## 核心的な特徴

| 特徴                 | 爻象                                 | 他の言語の例 |
| -------------------- | ------------------------------------ | ------------ |
| 型システム           | 依存型 + パラメータ化多相            | TypeScript   |
| メモリ管理           | ownership モデル（GC なし）          | Rust         |
| 非同期プログラミング | spawn モデル（シームレスな並行処理） | async/await  |
| 構文スタイル         | Python 風                            | Python       |

**一言でまとめると**：Python のように流暢に、Rust のように安全に。

## 爻象を学ぶのに向いているのは誰？

- ✅ プログラミング言語設計について学びたい探究者
- ✅ 関数型プログラミングを愛する愛好家
- ✅ 型システムに興味がある実践者
- ✅ 「シームレスな並行処理」を体験したい開発者
- ❌ すぐにプロダクションプロジェクトに投入したいチーム（言語はまだ実験段階です）

> 「道と云ふべきは、常に道に非ず。」—— 爻象はまだ初期探索段階にあり、すべての先駆者がその未来を形作っています。
