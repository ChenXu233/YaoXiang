# 爻象の世界へようこそ！

> 「无极而太极。太极动而生阳，静而生阴。」—— 周敦颐『太极図説』

这里是爻象宇宙的中心。

在东方哲学中，「爻」是组成卦象的基本符号，阴阳变化，尽在其中。「象」是事物本质的外在表现，万象万物，皆有规律可循。

**爻象プログラミング言語**は、この古い叡智を現代的类型システムに統合する試みである。

## 爻象とは何か？

乐高积木を組み立てるような世界を想像してほしい：

| 概念     | レゴ         | 爻象           |
| -------- | ------------ | -------------- |
| 基本ユニット | ピース     | **型**         |
| 組み合わせ方 | 拼接       | **関数マッピング** |
| 完成品   | 飛行機、車   | **プログラム** |

爻象の世界では、**すべてが型**である：

- 数字は型、テキストは型
- 型自体も型である（メタ型）
- 関数は型から型への架け橋

## 中核機能

| 機能     | 爻象                   | 他言語の例     |
| -------- | ---------------------- | -------------- |
| 型システム | 依存型 + パラメータ多態 | TypeScript     |
| メモリ管理 | 所有権モデル（GC なし） | Rust           |
| 非同期処理 | 並作モデル（透過的並行） | async/await    |
| 構文スタイル | Python 風            | Python         |

**一言で要約**：Python のような流暢さで、Rust のような安全性。

## 爻象を学ぶのに最適な人は？

- ✅ プログラミング言語設計を探求したい人
- ✅ 関数型プログラミングが好きな人
- ✅ 型システムに興味がある実践者
- ✅ 「透過的並行処理」を体験したい開発者
- ❌ 直ちに本番プロジェクトに使いたいチーム（言語はまだ実験段階）
