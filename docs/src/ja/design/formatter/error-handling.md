# エラー処理

---

## §E1 フォーマットエラー

**§E1.1 構文エラー。**
ソースコードに構文エラーが含まれている場合、フォーマッターは以下を行うべきである：

1. `parse()` 関数を使用して解析する
2. 解析にエラーがある場合、エラーメッセージを直接返す
3. プレースホルダーを挿入しない

**§E1.2 設定エラー。** 設定ファイルの形式が正しくない場合、明確なエラーメッセージを返すべきである。

---

## §E2 終了コード

| 終了コード | 意味                                           |
| ---------- | ---------------------------------------------- |
| 0          | 成功                                           |
| 1          | `--check` モードで未フォーマットファイルを検出 |
| 2          | ファイルが見つからない、または設定エラー       |

---

## §E3 エラー処理

**§E3.1 エラー報告。** フォーマッターは `parse()`
関数を使用してソースコードを解析する。解析中にエラーが発生した場合、フォーマッターはエラーメッセージを直接返し、フォーマットを行わない。

**§E3.2 プレースホルダーなし。** フォーマッターはエラー位置にプレースホルダー（例：
`/* error */`）を挿入しない。構文エラーに遭遇した場合、フォーマッターはエラーを直接報告して終了する。
