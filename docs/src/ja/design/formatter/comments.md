# コメント保持

---

## §C1 コメントの種類

**§C1.1 単一行コメント。** `//` で始まり、保持されなければならない。

```
// 这是单行注释
let x = 1;  // 这是行末注释
```

**§C1.2 複数行コメント。** `/* ... */` で囲まれ、ネストに対応し、保持されなければならない。

```
/* 这是多行注释 */
/* 嵌套 /* 注释 */ */
```

**§C1.3 ドキュメンテーションコメント。** `///` で始まり、保持されなければならない。

```
/// 这是文档注释
fn foo() { ... }
```

---

## §C2 コメントの位置

**§C2.1 ファイル先頭コメント。** ファイル先頭のコメントはファイルの先頭に保持されなければならない。

**§C2.2 文間のコメント。** 文間のコメントは元の位置に保持されなければならない。

**§C2.3 行末コメント。** 行末コメントは同じ行の末尾に保持されなければならない。

---

## §C3 空行の保持

**§C3.1 空行の保持。** 元のコード中の空行は、論理ブロックを区切るために保持されるべきである。
