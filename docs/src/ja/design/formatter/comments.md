# コメント保持

---

## §C1 コメントタイプ

**§C1.1 単一行コメント。** `//` で始まり、保存する必要がある。

```
// これは単一行コメント
let x = 1;  // これは行末コメント
```

**§C1.2 複数行コメント。** `/* ... */` で囲まれ、ネストをサポートし、保存する必要がある。

```
/* これは複数行コメント */
/* ネスト /* コメント */ */
```

**§C1.3 ドキュメントコメント。** `///` で始まり、保存する必要がある。

```
/// これはドキュメントコメント
fn foo() { ... }
```

---

## §C2 コメントの位置

**§C2.1 ファイルヘッダーコメント。** ファイル先頭のコメントは、ファイルの先頭に保存する必要がある。

**§C2.2 文間コメント。** 文の間のコメントは元の位置に保存する必要がある。

**§C2.3 行末コメント。** 行末コメントは同一行の末尾に保存する必要がある。

---

## §C3 空行の保持

**§C3.1 空行の保持。** 元のコード内の空行は、論理ブロックを区切るために保持する必要がある。
