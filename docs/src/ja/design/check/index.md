# check コマンド設計ドキュメント

`yaoxiang check`
は YaoXiang コンパイラの静的検査ツールであり、型検査、ファイル横断解析、増分検査機能を提供します。

## 設計原則

1. **誤検知ゼロ**：報告されるすべてのエラーは実際のエラーでなければならない
2. **ファイル横断認識**：モジュールをまたぐ型エラーや未定義参照を正確に検出する
3. **増分優先**：watch モードでは影響を受けるファイルのみを再検査する
4. **自己文書化**：エラーコード、メッセージテンプレート、ヘルプテキストはすべて i18n で管理する

## ドキュメントナビゲーション

- [診断システム](./diagnostic-system.md) — エラーコード体系、Diagnostic データ構造、Emitter 出力
- [ファイル横断解析](./cross-file-analysis.md) — 共有型環境、依存グラフ、トポロジカルソート
- [増分検査](./incremental-checking.md) — CheckSession、affected_modules、watch モード

## 他のシステムとの境界

| システム                      | 役割                                           | check との関係                    |
| ----------------------------- | ---------------------------------------------- | --------------------------------- |
| コンパイラ (`yaoxiang build`) | 完全なコンパイル（解析 → 型検査 → コード生成） | check は最初の 2 ステップのみ実行 |
| LSP                           | エディタ統合（補完、ジャンプ、診断）           | check の診断を再利用可能          |
| フォーマッタ (`yaoxiang fmt`) | コードスタイル                                 | 独立しており、CI 内で並列実行     |
