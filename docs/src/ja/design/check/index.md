# check コマンド設計ドキュメント

`yx check`
は YaoXiang コンパイラの静的検査ツールであり、型検査、ファイル横断解析、インクリメンタル検査機能を提供する。

## 設計原則

1. **誤検知ゼロ**：報告されるすべてのエラーは実際のエラーでなければならない
2. **ファイル横断認識**：モジュール横断の型エラーや未定義参照を正確に検出する
3. **インクリメンタル優先**：watch モードでは影響を受けるファイルのみを再検査する
4. **自動文書化**：エラーコード、メッセージテンプレート、ヘルプテキストはすべて i18n で管理する

## ドキュメントナビゲーション

- [診断システム](./diagnostic-system.md) — エラーコード体系、Diagnostic データ構造、Emitter 出力
- [ファイル横断解析](./cross-file-analysis.md) — 共有型環境、依存グラフ、トポロジカルソート
- [インクリメンタル検査](./incremental-checking.md) — CheckSession、affected_modules、watch モード

## 他システムとの境界

| システム                   | 責務                                           | check との関係                  |
| -------------------------- | ---------------------------------------------- | ------------------------------- |
| コンパイラ (`yx build`)    | 完全コンパイル（パース → 型検査 → コード生成） | check は最初の2ステップのみ実行 |
| LSP                        | エディタ統合（補完、ジャンプ、診断）           | check の診断は再利用可能        |
| フォーマッタ (`yx format`) | コードスタイル                                 | 独立、CI で並列使用             |
