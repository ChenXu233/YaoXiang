# 貢献ガイド

YaoXiang プロジェクトへのコードとドキュメントの貢献を歓迎します！

## 貢献方法

1. リポジトリを **Fork** する
2. 機能ブランチの作成：`git checkout -b feature/xxx`
3. 変更のコミット：`git commit -m "feat: xxx"`
4. ブランチのプッシュ：`git push origin feature/xxx`
5. **Pull Request** の作成

## コード規約

- プロジェクトのコードスタイルに従う
- テストが通ることを確認する
- 関連ドキュメントを更新する

## コミット規約

```
feat: 新功能
fix: 修复 bug
docs: 文档更新
refactor: 重构
test: 测试相关
chore: 构建/工具更新
```
