## 概要

本仕様は YaoXiang プログラミング言語のコア構文と意味論を定義します。これは言語の権威あるリファレンスであり、コンパイラとツールの実装者を対象としています。

### 仕様構造

1. **構文仕様**：言語の語彙構造、構文規則、演算子の優先順位を定義する
2. **型システム**：基本型、複合型、ジェネリクス、trait を含む言語の型システムを定義する
3. **モジュールシステム**：モジュール定義、インポートとエクスポート、スコープを含む言語のモジュールシステムを定義する
4. **並行モデル**：非同期プログラミング、並行プリミティブ、メモリモデルを含む言語の並行モデルを定義する
5. **標準ライブラリ**：コアライブラリ、IO ライブラリ、数学ライブラリを含む言語の標準ライブラリを定義する
