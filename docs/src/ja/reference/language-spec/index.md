## 概要

本仕様は YaoXiang プログラミング言語の中核的な構文と意味論を定義します。これは言語の権威あるリファレンスであり、コンパイラおよびツール実装者を対象としています。

### 仕様構造

1. **構文仕様**：言語の字句構造、構文規則、演算子の優先順位を定義します
2. **型システム**：言語の型システムを定義し、基本型、複合型、ジェネリクス、トレイトを含みます
3. **モジュールシステム**：言語のモジュールシステムを定義し、モジュール定義、インポート/エクスポート、スコープを含みます
4. **並行モデル**：言語の並行モデルを定義し、非同期プログラミング、並行プリミティブ、メモリモデルを含みます
5. **標準ライブラリ**：言語の標準ライブラリを定義し、コアライブラリ、IOライブラリ、数学ライブラリを含みます
