# コマンドラインインターフェース

## yx init

新しい YaoXiang プロジェクトを初期化します。

### 使用法

```bash
yx init <プロジェクト名>
```

### 引数

| 引数           | 説明                   |
| -------------- | ---------------------- |
| プロジェクト名 | 新規プロジェクトの名前 |

### オプション

| オプション | 説明             |
| ---------- | ---------------- |
| `--help`   | ヘルプ情報を表示 |

### 例

```bash
# 新規プロジェクトを作成
yx init my-project

# 結果：
# ✨ プロジェクトが作成されました：my-project
#   my-project/yaoxiang.toml
#   my-project/yaoxiang.lock
#   my-project/src/main.yx
#   my-project/.gitignore
```

## yx add

プロジェクトに依存関係を追加します。

### 使用法

```bash
yx add <パッケージ名> [バージョン]
yx add <パッケージ名> --dev
```

### 引数

| 引数         | 説明                                           |
| ------------ | ---------------------------------------------- |
| パッケージ名 | 追加する依存関係名                             |
| バージョン   | バージョン番号（オプション、デフォルトは `*`） |

### オプション

| オプション    | 説明                   |
| ------------- | ---------------------- |
| `--dev`, `-D` | 開発依存関係として追加 |

### 例

```bash
# 最新バージョンを追加
yx add http

# 指定バージョンを追加
yx add http 1.0.0

# バージョン範囲を追加
yx add json ">=2.0.0"

# 開発依存関係を追加
yx add test-utils --dev
yx add benchmark -D
```

## yx rm

プロジェクトから依存関係を削除します。

### 使用法

```bash
yx rm <パッケージ名>
yx rm <パッケージ名> --dev
```

### 引数

| 引数         | 説明               |
| ------------ | ------------------ |
| パッケージ名 | 削除する依存関係名 |

### オプション

| オプション    | 説明               |
| ------------- | ------------------ |
| `--dev`, `-D` | 開発依存関係を削除 |

### 例

```bash
# 通常の依存関係を削除
yx rm http

# 開発依存関係を削除
yx rm test-utils --dev
```

## yx install

プロジェクトの依存関係をインストールします。

### 使用法

```bash
yx install
```

### 説明

- `yaoxiang.toml` から依存関係の宣言を読み取る
- すべての依存関係を `vendor` ディレクトリにダウンロード
- `yaoxiang.lock` を生成/更新してバージョンを固定
- 依存関係のバージョン競合を検出

### 例

```bash
# すべての依存関係をインストール
yx install

# 出力例：
# 📦 依存関係を解析中...
#   http (1.0.0) [インストール済み]
#   json (2.0.0) [キャッシュ済み]
# ✅ 依存関係がインストールされ、ロックファイルが更新されました
```

## yx update

プロジェクトの依存関係を更新します。

### 使用法

```bash
yx update
yx update <パッケージ名>
```

### 引数

| 引数         | 説明                                 |
| ------------ | ------------------------------------ |
| パッケージ名 | 更新する特定の依存関係（オプション） |

### 説明

- 引数なし：すべての依存関係を更新
- 引数あり：指定された依存関係のみを更新

### 例

```bash
# すべての依存関係を更新
yx update

# 出力例：
# 📦 依存関係を更新中...
#   http (0 → 1.1.0)
# ✅ 1つの依存関係が更新され、ロックファイルが更新されました

# 単一の依存関係を更新
yx update http
```

## yx list

プロジェクトのすべての依存関係を一覧表示します。

### 使用法

```bash
yx list
```

### 説明

すべてのランタイム依存関係と開発依存関係、およびそれらのバージョンとソースを表示します。

### 例

```bash
# 依存関係を一覧表示
yx list

# 出力例：
# 📦 プロジェクトの依存関係
#
# ランタイム依存関係:
#   http        1.0.0    registry
#   json        2.0.0    registry
#
# 開発依存関係:
#   test-utils  0.5.0    registry
```
