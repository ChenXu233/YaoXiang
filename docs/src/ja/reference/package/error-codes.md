# エラーコード

本ドキュメントでは、YaoXiang パッケージマネージャーが返す可能性のあるエラーとその処理方法を一覧します。

## エラー一覧

### E0100: プロジェクトが既に存在します

```
Error: Project already exists: <path>
```

**原因**：作成しようとしたプロジェクトディレクトリが既に存在します。

**処理方法**：

1. 別のプロジェクト名を選択する
2. 既存のディレクトリを削除または移動する

---

### E0101: 有効なプロジェクトではありません

```
Error: Not a YaoXiang project: yaoxiang.toml not found
```

**原因**：現在のディレクトリまたは指定されたディレクトリに `yaoxiang.toml`
ファイルが含まれていません。

**処理方法**：

1. プロジェクトディレクトリ内でコマンドを実行していることを確認する
2. `yx init` を使用して新しいプロジェクトを作成する

---

### E0102: 依存関係が存在しません

```
Error: Dependency not found: <name>
```

**原因**：存在しない依存関係を操作しようとしました。

**処理方法**：

1. 依存関係名のスペルが正しいか確認する
2. `yx list` を使用して既存の依存関係を確認する

---

### E0103: 依存関係が既に存在します

```
Error: Dependency already exists: <name>
```

**原因**：既に存在する依存関係を追加しようとしました。

**処理方法**：

1. バージョンを更新する必要がある場合は、まず `yx rm` で削除する
2. または既存の依存関係を直接使用する

---

### E0104: 無効なマニフェスト形式

```
Error: Invalid yaoxiang.toml format: <details>
```

**原因**：`yaoxiang.toml` ファイルの形式が正しくありません。

**処理方法**：

1. TOML の構文が正しいか確認する
2. すべての必須フィールドが存在することを確認する
3. 構文エラー（引用符やカンマの欠落など）がないか確認する

---

### E0105: IO エラー

```
Error: IO error: <details>
```

**原因**：ファイルの読み書き操作に失敗しました。

**一般的な原因**：

- ディスク容量不足
- 権限不足
- ファイルが他のプログラムによって占有されている

**処理方法**：

1. ディスク容量を確認する
2. ファイルの権限を確認する
3. ファイルを占有している可能性のある他のプログラムを終了する

---

### E0106: TOML 解析エラー

```
Error: TOML parse error: <details>
```

**原因**：TOML ファイルの形式エラーです。

**処理方法**：

1. TOML の構文を検証する
2. 特殊文字が正しくエスケープされているか確認する

---

## よくある問題

### Q: 依存関係のインストールに失敗した場合はどうすればよいですか？

1. ネットワーク接続を確認する
2. 依存関係名とバージョンが正しいことを確認する
3. `yx update` を使用して更新してみる

### Q: バージョンの競合が発生した場合はどうすればよいですか？

`yaoxiang.toml` に互換性のない依存関係のバージョン要件がないか確認します。

### Q: vendor ディレクトリが破損した場合はどうすればよいですか？

`vendor` ディレクトリを削除した後、`yx install` を再実行します。
